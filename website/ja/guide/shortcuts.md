# キーボードショートカット

VMark はキーボードファーストのワークフロー向けに設計されています。ほとんどのショートカットは設定でカスタマイズできます。一部のプリミティブは固定されています：マルチカーソルセレクター `Mod+D`（次の出現を選択）と `Mod+Shift+L`（すべての出現を選択）、およびグローバルな元に戻す／やり直しのバインディング。その他のマルチカーソルショートカット（出現をスキップ、カーソルをソフトアンドゥ、上／下にカーソルを追加）はカスタマイズ可能です。_(コンテキスト依存)_ と表示されているショートカットは、特定の構造（例：タスクリストのチェックボックス切り替え）のためにエディタ内で処理され、カスタマイズレジストリには公開されていません。

## 表記

- **Mod** = macOS では Cmd、Windows/Linux では Ctrl
- **Alt** = macOS では Option

## macOS のファンクションキー

VMark はクイックモード切り替えにファンクションキー（F2〜F10）を使用します。macOS では、これらのキーはデフォルトでシステム機能（輝度、音量など）にマッピングされています。

**Fn キーを押さずに F キーを直接使用するには:**

1. **システム設定** → **キーボード** を開く
2. **「F1、F2 などのキーを標準的なファンクションキーとして使用する」** を有効にする

または、F2〜F10 を押す際に **Fn** キーを押しながら使用して VMark のショートカットをトリガーします。

::: tip
システム機能を F キーに維持したい場合、設定（`Mod + ,`）で VMark のショートカットを別のキーの組み合わせにカスタマイズできます。
:::

::: tip Windows/Linux の注意
隠しファイルの切り替えは Windows と Linux で `Ctrl + H` を使用します。

サイドバーの切り替えは Windows と Linux で `Alt + Shift + 0` を使用します。そこでは `Mod` が Ctrl なので、macOS のキー操作 `Ctrl + Shift + 0` が段落の `Mod + Shift + 0` と衝突してしまうためです。
:::

::: tip 新しいブラウザタブ
`Alt + Mod + Shift + B` は埋め込みブラウザのタブを開きます。この操作は **ファイル** メニューにもあります。埋め込みブラウザは macOS ではデフォルトでオンです。**設定 → 詳細設定 → 埋め込みブラウザ** でオフにすると、オンに戻すまでメニュー項目は（グレーアウトではなく）非表示になります。ブラウザは macOS 専用なので、Windows や Linux ではこの項目は表示されません。

これはキーボードのバインディングだけでなく実際のメニュー項目であり、それが重要です。Web ページがキーボードフォーカスを持つと、ブラウザエンジンが VMark より先にキー入力を消費するため、アプリ内のショートカットは発火できません。メニューのアクセラレーターは macOS 自身がディスパッチするので、ブラウズ中でも機能します。
:::

## スマートタブナビゲーション

Tab と Shift+Tab はコンテキストに応じて動作します——括弧、引用符、フォーマットマーク、リンクからエスケープできます。

| コンテキスト | Tab アクション |
|------------|-------------|
| `)`、`]`、`}`、引用符の前 | 閉じる文字を飛び越える |
| CJK 括弧 `」`、`』` などの前 | 閉じる括弧を飛び越える |
| **太字**、*斜体*、`コード` の中 | フォーマットの後にジャンプ |
| リンクの中 | リンクの後にジャンプ |

| コンテキスト | Shift+Tab アクション |
|------------|------------------|
| `(`、`[`、`{`、引用符の後 | 開く文字の前にジャンプ |
| CJK 括弧 `「`、`『` などの後 | 開く括弧の前にジャンプ |
| **太字**、*斜体*、`コード` の中 | フォーマットの前にジャンプ |
| リンクの中 | リンクの前にジャンプ |

::: tip
CJK 括弧、カーリー引用符、設定を含む完全なガイドは[スマートタブナビゲーション](/ja/guide/tab-navigation)を参照してください。
:::

| ターミナルのフォントを大きく | `Mod + =` |
| ターミナルのフォントを小さく | `Mod + -` |
| ターミナルのフォントをデフォルトサイズに | `Mod + 0` |
| 前のコマンドプロンプト | `Mod + ↑` |
| 次のコマンドプロンプト | `Mod + ↓` |
| 入力行で改行（Claude Code などのツール） | `Shift + Enter` |

ターミナルにフォーカスがある間、`Mod + =`、`Mod + -`、`Mod + 0` はエディタではなくターミナルのフォントサイズを変更します。

プロンプトナビゲーションはスクロールバック内のコマンドプロンプト間を移動するもので、シェル統合（zsh または bash）が必要です。

macOS では、ターミナルは通常のテキスト編集用のキー操作もシェル向けに変換します：

| アクション | ショートカット |
|-----------|--------------|
| 1 単語左 / 右へ移動 | `Option + ←` / `Option + →` |
| 行頭 / 行末へ移動 | `Cmd + ←` / `Cmd + →` |
| 入力行を削除（`Ctrl + U` を送信） | `Cmd + Backspace` |

macOS では、`Ctrl + A`、`Ctrl + R`、`Ctrl + W` などの `Ctrl` キー操作はそのままシェルに送られます。

Linux では、ターミナルは Linux ターミナルの一般的な慣習に従います。単独の `Ctrl` + 英字キーはシェルに渡されるため、`Ctrl + A`、`Ctrl + E`、`Ctrl + K`、`Ctrl + F`、`Ctrl + U`、`Ctrl + W` などの readline キーは他の Linux ターミナルと同じように使えます。ターミナル自身の操作は `Ctrl + Shift` に移ります：`Ctrl + Shift + A` で全選択、`Ctrl + Shift + K` でクリア、`Ctrl + Shift + F` で検索、`Ctrl + Shift + C` / `Ctrl + Shift + V` でコピーと貼り付け。`Ctrl + Insert` と `Shift + Insert` でもコピーと貼り付けができます。例外として 2 つの `Ctrl` キー操作はターミナルが扱います：`Ctrl + C` は選択があればコピーし（選択がなければ SIGINT を送信）、`Ctrl + V` は貼り付けます。`Ctrl + 1` から `Ctrl + 5` は引き続きセッションを切り替えます。

ターミナル検索バーが開いている場合：

| アクション | ショートカット |
|-----------|--------------|
| 次のマッチ | `Enter` |
| 前のマッチ | `Shift + Enter` |
| 検索を閉じる | `Escape` |

::: tip
セレクションなしの `Mod + C` は実行中のプロセスに SIGINT を送信します。完全なガイドは[統合ターミナル](/ja/guide/terminal)を参照してください。
:::

## ショートカットのカスタマイズ

1. `Mod + ,` で設定を開く
2. **ショートカット** タブに移動する（検索ボックスに入力すると、名前、カテゴリ、説明、キーで絞り込めます）
3. ショートカットの横に表示されているキーをクリックする（キーがまだないものは **未割り当て** をクリック）
4. 希望のキーの組み合わせを押し、**割り当て** をクリックする（`Escape` でキャンセル）

組み合わせを割り当てる前に、ダイアログが警告を表示します：

- **競合**——その組み合わせはすでに別のショートカットで使用されており、そのショートカット名が表示されます。それでも **強制的に割り当て** を選ぶことができます。
- **非対応**——VMark はその組み合わせを使用できないため、割り当てられません。別の組み合わせを試してください。

カスタマイズしたショートカットはハイライトされ、**デフォルトにリセット** ボタンが付きます。**すべてリセット** は確認後にすべてのデフォルトを復元します。**エクスポート** はショートカットを JSON ファイル（`vmark-shortcuts.json`）として保存し、**インポート** はそれを読み込みます。ファイル内に無効な項目が 1 つでもあると何もインポートされず、問題点が一覧表示されます。

::: tip
ショートカットは該当する場合はメニューアクセラレーターと同期するため、メニューアイテムにカスタマイズされたショートカットが表示されます。
:::
