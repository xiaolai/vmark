# エクスポートと印刷

VMark はドキュメントをエクスポートして共有する複数の方法を提供します。

## エクスポートで作成されるもの

**ファイル → エクスポート → HTML** は、ドキュメント名を付けたフォルダーを 1 つ書き出します。このフォルダーには常に次の 2 つのファイルが**両方とも**含まれます — 選択するモードはありません:

```text
MyDocument/
├── index.html          ← assets/ 以下のファイルにリンク
├── standalone.html     ← すべてをデータ URI として埋め込み（CSS、JS、画像、フォント）
└── assets/
    ├── vmark-reader.css
    ├── vmark-reader.js
    ├── images/
    │   ├── image1.png
    │   └── ...
    └── fonts/          ← ドキュメントに数式がある場合、または Web フォントを使う場合のみ
```

その時々に合ったファイルを使ってください:

| ファイル | 最適な用途 | トレードオフ |
|------|----------|-----------|
| `index.html` | 静的サイトでのホスティング（クリーンな `/MyDocument/` URL）、別のツールでの編集、サイズを抑えたい場合 | 横に `assets/` フォルダーが必要 |
| `standalone.html` | 画像が失われてはならない 1 つのファイルをメールやメッセージで送る場合 | サイズが大きくなる — すべてのアセットがインライン化される |

どちらのファイルも、エディタが使うのと同じ WYSIWYG レンダラーとスタイルシートで描画され、どちらにも [VMark Reader](#vmark-reader) が含まれます。

## エクスポートの方法

### HTML エクスポート

1. **ファイル → エクスポート → HTML** を使用
2. 保存先を選び、名前を入力します — それがフォルダー名になります（末尾の `.html` は取り除かれます）
3. 新しいフォルダーから `index.html` または `standalone.html` を開く

#### 以前使ったフォルダーへの再エクスポート

HTML エクスポートは、すべて成功するか何も変えないかのどちらかです。すべてのファイルは、まず選択した保存先の中にある一時的な `.vmark-export-…` フォルダーに書き込まれ、すべてのファイルがそろってから所定の場所に移動されます — そのため、途中で失敗したエクスポートが以前のエクスポートを中途半端に上書きすることはなく、以前のエクスポートはそのまま残ります。

次の 2 つを目にすることがあります:

- **「別のエクスポートがすでにこのフォルダーに書き込んでいます。」** 1 つのフォルダーに書き込めるエクスポートは、ウィンドウをまたいで一度に 1 つだけです。もう一方の完了を待つか、ほかに何も実行されていなければ、メッセージに示された `.vmark-export.lock` ファイルを削除してからもう一度お試しください。
- **`.vmark-export-…` フォルダーが残っている。** VMark は完了時にこれを削除します。残るのは、以前のファイルを元に戻す処理も失敗した場合だけで、その場合はそのフォルダーにそれらのファイルが入っており、エラーメッセージに正確な場所が示されます。それが唯一のコピーである間は、何も削除されません。

### 印刷 / PDF エクスポート

macOS、Windows、Linux で利用できます。

**PDF をエクスポート**（**ファイル → エクスポート → PDF**）は、エクスポートダイアログで選んだページサイズ、向き、余白、タイポグラフィを使って PDF を直接書き出します。

**印刷**（`Cmd/Ctrl + P`、または **ファイル → 印刷**）は代わりにシステムの印刷ダイアログを開くため、ドキュメントをプリンターに送ったり、OS 自身の「PDF として保存」を使ったりできます。macOS と Linux では、印刷ジョブが完了すると VMark が短い通知で知らせ、ダイアログをキャンセルした場合は何も表示しません。Windows の印刷 UI は結果を返さないため、Windows では通知は表示されません。

エクスポートダイアログは、3 つのプラットフォームすべてで同じ進行段階 — 読み込み中、生成中、仕上げ中、完了 — を表示します。

::: info macOS でのページサイズ
ダイアログで選んだページサイズと向きが、すべてのプラットフォームでエクスポートされるページを決めます。macOS では、それらがシステムで設定されている用紙サイズより優先されます — Mac のデフォルトが Letter で A4 を選んだ場合、PDF は A4 になります。
:::

**サイドバーの目次。** エクスポートされた PDF には、3 つのプラットフォームすべてで見出しのアウトライン — PDF ビューアーがサイドバーに表示する、クリック可能な目次 — が含まれます。

#### ページ番号

ダイアログの **ページ番号** セクションは、各ページに番号を付けます。デフォルトでオンで、下部中央に配置されます。

| 設定 | オプション |
|---------|---------|
| 位置 | 下中央、右下、またはなし |
| 形式 | `7`、`7 / 12`、または「12 ページ中 7 ページ目」（`Page 7 of 12`） |
| 最初のページを除く | 1 ページ目に番号を付けません。表紙ページでよく使われる扱いです |

番号は選んだ下余白の中に置かれ、本文のフォントサイズに合わせて拡大縮小されます。番号は常に実際のページを反映するため、最初のページを除くと、続くページは番号を振り直すのではなく 2、3、4… になります。

::: info ページ番号はラテン文字を使用します
番号は、どのビューアーでもダウンロードの必要がない標準の PDF フォントで描画されます。これがエクスポートを高速かつ自己完結させている理由ですが、そのフォントは中国語、日本語、韓国語、キリル文字を描画できません。2 つの数値形式はどの言語でも機能します。インターフェース言語で `Page 7 of 12` をそのフォントが描画できない文字体系で書く場合（日本語もその一つです）、VMark は空白や誤った文字の代わりに、数値の `7 / 12` 形式を出力します。
:::

### 他の形式へのエクスポート

VMark は Markdown を追加の形式にエクスポートするために[Pandoc](https://pandoc.org/)（ユニバーサルドキュメントコンバーター）と統合されています。メニューから直接形式を選択します:

**ファイル → エクスポート → Pandoc 経由 →**

| メニュー項目 | 拡張子 |
|-----------|-------|
| Word (.docx) | `.docx` |
| EPUB (.epub) | `.epub` |
| LaTeX (.tex) | `.tex` |
| OpenDocument (.odt) | `.odt` |
| リッチテキスト (.rtf) | `.rtf` |
| プレーンテキスト (.txt) | `.txt` |

**セットアップ:**

1. [pandoc.org/installing](https://pandoc.org/installing.html)から Pandoc をインストールするか、パッケージマネージャーを使用します:
   - macOS: `brew install pandoc`
   - Windows: `winget install pandoc`
   - Linux: `apt install pandoc`
2. VMark を再起動（または **設定 → ファイルと画像 → ドキュメントツール** に移動して **検出** をクリック）
3. **ファイル → エクスポート → Pandoc 経由 → [形式]** でエクスポート

Pandoc がインストールされていない場合、**Pandoc 経由** サブメニューには 1 つの項目 — **「Pandoc をインストールして Word、EPUB、LaTeX… に書き出す」** — だけが表示され、クリックすると Pandoc のインストールガイドが開きます。

Pandoc が検出されているかは **設定 → ファイルと画像 → ドキュメントツール** で確認できます。

### HTML としてコピー

`Cmd/Ctrl + Shift + C`を押すと、レンダリングされたドキュメントを HTML **ソース**としてコピーします。マークアップはスタイルなしのプレーンテキストとしてクリップボードに入るため、HTML コードを受け付ける場所 — CMS の HTML ビュー、テンプレート、コードエディター — に貼り付けてください。Word やメールのようなリッチテキストエディターでは、タグがそのまま表示されます。ローカル画像はデータ URI として埋め込まれるため、HTML を VMark の外に持ち出しても表示されます。

## VMark Reader

すべての HTML エクスポートには **VMark Reader** — 独自の設定、ナビゲーション、ライトボックスを備えたインタラクティブな読書体験 — が含まれます。

### 設定パネル

ギアアイコン（右下）をクリックすると設定パネルが開き、`Esc` で再び閉じます。選択内容はブラウザー（`localStorage`）に記憶されるため、次にファイルを開いたときにも適用されます。

| 設定 | オプション |
|-----|---------|
| フォントサイズ | 12px〜28px |
| 行の高さ | 1.2〜2.4 |
| コンテンツ幅 | 30em〜80em |
| ラテン文字フォント | System、Athelas、Palatino、Georgia、Charter、Literata |
| CJK フォント | System、PingFang、Songti、Kaiti、Noto Serif、Source Han |
| テーマ | White、Paper（デフォルト）、Mint、Sepia、Night |
| CJK 文字間隔 | 0.02em〜0.12em |
| CJK-ラテン間のスペース | CJK とラテン文字の間の自動スペースの切り替え |
| 目次 | 目次サイドバーの切り替え（`T` を押すのと同じ） |
| すべてのセクションを展開 | 折りたたみ可能な `<details>` ブロックをすべて開く |
| デフォルトに戻す | すべての設定を元に戻す |

### 目次

TOC サイドバーは長いドキュメントのナビゲーションに役立ちます:

- **切り替え**: ページの端にあるタブをクリックするか`T`を押す
- **ナビゲート**: 任意の見出しをクリックしてジャンプ
- **ハイライト**: スクロールに応じて現在のセクションがハイライトされます

### 読書の進捗

ページの上部にある微妙なプログレスバーで、ドキュメントをどこまで読んだかが表示されます。

### トップに戻る

スクロールダウンすると浮かぶボタンが表示されます。クリックするとトップに戻ります。

### 画像ライトボックス

任意の画像をクリックしてフルスクリーンのライトボックスで表示します:

- **閉じる**: 外側をクリック、`Esc`を押す、または X ボタンをクリック
- **ズーム**: 画像は自然なサイズで表示されます

### コードブロック

各コードブロックにはインタラクティブなコントロールが含まれます:

| ボタン | 機能 |
|--------|-----|
| 行番号切り替え | このブロックの行番号の表示/非表示 |
| コピーボタン | コードをクリップボードにコピー |

コピーボタンは成功するとチェックマークを表示します。

### 脚注ナビゲーション

脚注は完全にインタラクティブです:

- 脚注参照`[1]`をクリックして定義にジャンプ
- `↩`バックリンクをクリックして読んでいた場所に戻る

### キーボードショートカット

| キー | アクション |
|-----|---------|
| `Esc` | 設定パネルまたはライトボックスを閉じる |
| `T` | 目次の切り替え |
| `+` / `=` | フォントサイズを大きくする |
| `-` | フォントサイズを小さくする |

## エクスポートのショートカット

| アクション | ショートカット |
|-----------|------------|
| HTML エクスポート | _（メニューのみ）_ |
| PDF エクスポート | _（メニューのみ）_ |
| 印刷 | `Mod + P` |
| HTML としてコピー | `Mod + Shift + C` |

## ヒント

### エクスポートされた HTML の配信

フォルダーエクスポート構造は任意の静的ファイルサーバーとうまく連携します:

```bash
# Python
cd MyDocument && python -m http.server 8000

# Node.js (npx)
npx serve MyDocument

# 直接開く
open MyDocument/index.html
```

### オフライン表示

どちらのファイルもオフラインで開けますが、数式を含むドキュメントでは 1 つ違いがあります:

- **`standalone.html`** は完全に自己完結しています — KaTeX のスタイルシートとフォントはエクスポート時にインライン化されるため、接続なしで数式が描画されます。
- **`index.html`** は KaTeX のスタイルシートを CDN（jsDelivr）から読み込むため、ページを開くときに数式の表示にはインターネット接続が必要です。Reader、画像、`assets/` 以下のフォントはローカルにあります。

フォントはエクスポート中にダウンロードされます。ドキュメントに数式があれば KaTeX のフォントを、ラテン文字フォントと等幅フォントが VMark の知っている Web フォント（Literata、JetBrains Mono、Fira Code、IBM Plex Mono）であればそれらをダウンロードします。CJK フォントの設定は埋め込まれず、システムフォントやカスタムのフォントファミリーも埋め込まれません — それらについては、エクスポートされたページは読者のシステムフォントスタックを使います。フォントを埋め込みたい場合はインターネットにアクセスできるマシンでエクスポートしてください — オフラインでのエクスポートはシステムフォントにフォールバックします。

### 埋め込まれる画像

エクスポートされたファイルには実際の画像データが含まれ、エクスポートは共有されるものです — そのため VMark は、そのデータの取得元を制限しています:

| ドキュメントの状態 | 画像の取得元 |
|---|---|
| 開いているワークスペース内にある | そのワークスペース内のどこでも |
| 単独で開かれている | ドキュメント自身のフォルダーとその配下 |
| 未保存（一度もディスクに保存されていない） | どこからも埋め込まない — ワークスペースが開いていても、ローカル画像は埋め込まれません。リモート画像には影響しません |

未保存のドキュメントは、まず保存してからもう一度エクスポートしてください。これは HTML、印刷、PDF、「HTMLとしてコピー」のすべてに当てはまります。

相対パスはエディタと同じようにドキュメントのフォルダーから解決されます — そのため `../images/photo.png` は、対象が上記の範囲内にある限り機能します。範囲外のもの（`~/.ssh/id_rsa`、`/etc/passwd`、ディスク上の別の場所への絶対パス）は拒否され、「Image not found」のプレースホルダーとしてエクスポートされ、エクスポートの警告に件数が含まれます。

`../` の画像がプレースホルダーとしてエクスポートされる場合は、そのフォルダーをワークスペースとして開き、もう一度エクスポートしてください。

### ベストプラクティス

1. **公開するドキュメントは `index.html` をホストする** — 横に `assets/` フォルダーを置いておく
2. **メールやチャットで素早く共有するには `standalone.html` を送る**
3. **アクセシビリティのために説明的な画像の alt 文を含める**
4. **異なるブラウザでエクスポートされた HTML をテストする**
