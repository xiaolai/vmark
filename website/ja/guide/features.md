# 機能

VMark は、人間と AI が協働するプレーンテキストのワークスペースです。中心は Markdown（WYSIWYG、ソースプレビュー、ソースモード付き）ですが、ワークスペースでは YAML、JSON、TOML、Mermaid、SVG、HTML、そして 9 種類のコードビューア形式も開けます——完全な一覧は [サポートされるフォーマット](/ja/guide/formats) を参照してください。

## エディタモード

### リッチテキストモード（WYSIWYG）

デフォルトの編集モードは、真の「見たままが得られる」体験を提供します：

- 入力しながらフォーマットをライブプレビュー
- カーソルホバー時のインラインシンタックス表示
- 直感的なツールバーとコンテキストメニュー
- シームレスな Markdown 構文入力

### ソースモード

完全なシンタックスハイライト付きの生 Markdown 編集に切り替え：

- CodeMirror 6 搭載エディタ
- 完全なシンタックスハイライト
- 数式、リンク、画像、Wiki リンク、メディア用のインタラクティブポップアップ——WYSIWYG と同じ編集体験
- スマートペースト——Web ページや Word ドキュメントからの HTML をクリーンな Markdown に自動変換
- クリップボード画像貼り付け——スクリーンショットやコピーした画像をアセットフォルダに保存し `![](path)` として挿入
- CJK 単語境界サポート付きのコードフェンス対応マルチカーソル
- 上級者に最適

`F6` でモードを切り替えます。

### 分割ビュー（ソース + プレビュー）

左側で生の Markdown ソースを編集しながら、右側で **ライブの読み取り専用 WYSIWYG プレビュー** が更新されます——プレビューは WYSIWYG レンダラー *そのもの* なので、リッチテキストモードで見える表示とずれることはありません。書式コマンドとツールバーはソースペインに作用します。区切り線をドラッグする（または矢印キーを使う）とサイズを変更できます。

- セッションごとに `Shift + F6`、**表示 → Markdown分割ビュー**、またはコマンドパレット（「Markdown分割ビューを切り替え」）で切り替え
- **設定 → Markdown → レイアウト → デフォルトでソース/プレビューを分割** で Markdown ファイルのデフォルトにできます

デフォルトは引き続き WYSIWYG で、分割はオプトインです。3 つのビューは相互に排他的です——`F6` はソースを、`Shift + F6` は分割を切り替え、それぞれ WYSIWYG に戻ります——そのため、ビューの切り替えは常に 1 回のキー操作で済みます。

**表示** メニューには 3 つのモード——**WYSIWYGモード**、**ソースコードモード**、**Markdown分割ビュー**——がチェックマーク付きのグループとして表示されるため、アクティブなモードが常にわかり、相互排他であることも明示されます。**折り返し** と **行番号** はソースエディタにのみ適用されるため、WYSIWYG モードの間はグレーアウトされます。

### 読み取り位置

ドキュメント内の位置は、そのドキュメントを離れても保持されます。別のタブに切り替えて戻ったとき、ソースモードや分割ビューを切り替えたとき、ファイルがディスクから再読み込みされたときのいずれでも、先頭ではなく読んでいた場所に戻ります。

各表示面はそれぞれの位置を記憶するため、リッチテキストとソースは同じファイル内で別々の位置を保持します。同じ表示面に戻るとき（タブの切り替えやファイルの再読み込み）は、カーソルが別の場所にあっても、スクロールしていた位置に戻ります。カーソルは置いたままの場所に残ります。リッチテキストとソースを切り替えるときは、カーソルがあればカーソルに従います。これにより、両者の間で同じ段落が表示されたままになります。

位置はドキュメントごと、セッションごとに保持されます——タブを閉じると忘れられます。

### モードをまたいだ取り消し

取り消しとやり直しは WYSIWYG ⇄ ソースの境界をまたぎます。モードを切り替えるたびにチェックポイントが記録され、現在のエディタ自身の履歴を使い切ると、`Mod + Z` はそれらのチェックポイントをさらにさかのぼります——表示中のビューを切り替えずに以前の内容を復元します。やり直しは同じ連鎖を前方にたどります。新しい編集によって放棄したブランチへのやり直しは、作業の上に適用されるのではなく拒否されます。この連鎖はタブごとに保持され、タブを閉じると消去されます。

### 大きなファイル

VMark は大きなファイルを 1 秒未満で開けるよう自動的にソースモードで開き — 1 MB を超えるファイル、または推定 1,200 ブロック以上のブロック密度の高い Markdown —、5 MB を超えるファイルは操作する前に警告し、50 MB を超えるファイルは開くことを拒否します。しきい値と設定については [大きなファイル](./large-files.md) ガイドを参照してください。

### ソースプレビュー

WYSIWYG モードを離れずに単一ブロックの生 Markdown を編集します。`F5` を押してカーソル位置のブロックのソースプレビューを開きます。

**レイアウト：**
- ブロックタイプラベルとアクションボタンを持つヘッダーバー
- ブロックの Markdown ソースを表示する CodeMirror エディタ
- 元のブロックを暗くしたプレビューとして表示（ライブプレビューが ON の場合）

**コントロール：**
| アクション | ショートカット |
|-----------|--------------|
| 変更を保存 | `Cmd/Ctrl + Enter` |
| キャンセル（元に戻す） | `Escape` |
| ライブプレビューの切り替え | 目のアイコンをクリック |

**ライブプレビュー：**
- **OFF（デフォルト）：** 自由に編集し、変更は保存時にのみ適用
- **ON:** 入力しながら変更が即時適用され、プレビューが下に表示

**除外ブロック：**
一部のブロックは独自の編集メカニズムを持ち、ソースプレビューをスキップします：
- コードブロック（Mermaid、LaTeX を含む）——ダブルクリックで編集
- ブロック画像——画像ポップアップを使用
- フロントマター、HTML ブロック、水平ルール

ソースプレビューは、ビジュアルエディタに留まりながら正確な Markdown 編集（テーブル構文の修正、リストインデントの調整）に便利です。

## マルチカーソル編集

複数の場所を同時に編集——VMark は WYSIWYG モードとソースモードの両方で完全なマルチカーソルをサポートします。

| アクション | ショートカット |
|-----------|--------------|
| 次のマッチにカーソルを追加 | `Mod + D` |
| マッチをスキップして次へジャンプ | `Mod + Shift + D` |
| すべての出現箇所を選択 | `Mod + Shift + L` |
| 上/下にカーソルを追加 | `Mod + Alt + Up/Down` |
| クリックでカーソルを追加 | `Alt + Click` |
| 最後のカーソルを元に戻す | `Alt + Mod + Z` |
| 単一カーソルに戻す | `Escape` |

すべての標準編集（入力、削除、クリップボード、ナビゲーション）は各カーソルで独立して機能します。散文では `Mod + D` と `Mod + Shift + L` はドキュメント全体を検索し、コードブロック内ではそのブロック内にとどまります。`Alt + Mod + Shift + L` は現在のブロック内のすべてのマッチのみを選択します。

[詳細を見る →](/ja/guide/multi-cursor)

## スマート全選択

WYSIWYG モードでは、`Mod + A` はいきなりドキュメント全体を選択するのではなく、コンテナを 1 つずつ広げながら選択を拡大します。テーブル内ではセル、行、テーブル、ドキュメントの順に選択します。`Mod + Z` で拡大を 1 段階戻し、`Escape` で選択をカーソルに折りたたみます。

ソースモードでは、`Mod + A` はまず囲んでいるブロック（コードフェンス、テーブル、引用、リスト）を選択し、次にドキュメント全体を選択します。ここでも `Mod + Z` で拡大を 1 段階戻せます。

このキー割り当てはエディタに属しており、カスタマイズできません。

## 自動ペアリングとタブエスケープ

開き括弧、引用符、またはバッククォートを入力すると、VMark は自動的に閉じるペアを挿入します。**Tab** を押して矢印キーに手を伸ばす代わりに閉じる文字を飛び越えます。

- 括弧：`()` `[]` `{}`
- 引用符：`""` `''` `` ` ` ``
- CJK: `「」` `『』` `（）` `【】` `《》` `〈〉`
- カーリー引用符：`""` `''`
- WYSIWYG のフォーマットマーク：**太字**、*斜体*、`コード`、~~取り消し線~~、リンク

ペアが空の場合、バックスペースで両方の文字を削除します。自動ペアリングとタブブラケットジャンプは両方とも **コードブロックとインラインコード内では無効**——コード内の括弧はリテラルのままです。**設定 → エディタ** で設定できます。

[詳細を見る →](/ja/guide/tab-navigation)

## テキストフォーマット

### 基本スタイル

- **太字**、*斜体*、<u>下線</u>、~~取り消し線~~
- `インラインコード`、==ハイライト==
- 添字と上付き文字
- リンク、Wiki リンク、ブックマークリンク（プレビューポップアップ付き）
- インライン編集付きの脚注
- HTML コメント切り替え（`Mod + /`）
- フォーマットをクリアするコマンド

### テキスト変換

フォーマット → 変換でテキストケースをすばやく変更：

| 変換 | ショートカット |
|------|--------------|
| 大文字（UPPERCASE） | `Ctrl + Shift + U`（macOS）/ `Alt + Shift + U`（Win/Linux） |
| 小文字（lowercase） | `Ctrl + Shift + L`（macOS）/ `Alt + Shift + L`（Win/Linux） |
| タイトルケース（Title Case） | `Ctrl + Shift + T`（macOS）/ `Alt + Shift + T`（Win/Linux） |
| ケースの切り替え（Toggle Case） | — |

### ブロック要素

- 簡単なショートカット付きの見出し 1〜6（`Mod + Alt + ]`/`[` でレベルを上げ下げ）
- ネスト対応の引用ブロック
- シンタックスハイライト付きコードブロック
- 順序付き、順序なし、タスクリスト
- リストタイプの循環切り替え：段落を箇条書き、番号付き、タスクリストの順に変換
- リストをオフに切り替え：アクティブなリストタイプをもう一度クリックするとリストの書式が解除されます
- コードに変換：コードブロックのアクションは、カーソル位置のリスト全体——または複数ブロックにわたる任意の選択（段落、見出し、リスト）——を 1 つのコードブロックに変換します。ブロックまたはリスト項目ごとに 1 行になります
- 水平ルール
- 完全な編集サポート付きテーブル

### 強制改行

段落内に強制改行を挿入するには `Shift + Enter` を押します。
VMark は最大互換性のためにデフォルトで 2 スペーススタイルを使用します。
**設定 > エディタ > 空白文字** で設定できます。

### 行操作

編集 → 行による強力な行操作：

| アクション | ショートカット |
|-----------|--------------|
| 行を上に移動 | `Alt + Up` |
| 行を下に移動 | `Alt + Down` |
| 行を複製 | `Shift + Alt + Down` |
| 行を削除 | `Mod + Shift + K` |
| 行を結合 | `Mod + J` |
| 空白行を削除 | — |
| 行を昇順に並び替え | `F4` _(ソースモードのみ)_ |
| 行を降順に並び替え | `Shift + F4` _(ソースモードのみ)_ |

並び替えはプレーンテキストの行に対して動作するため、ソースモードでのみ使用できます。

## テーブル

フル機能のテーブル編集：

- メニューまたはショートカットでテーブルを挿入
- 行と列の追加/削除
- セルの配置（左、中央、右）
- 列は内容に合わせて自動でサイズ調整され、幅の広いテーブルは横にスクロール
- 幅に合わせる——テーブルをエディタの幅に固定し、列幅を内容に比例させます（設定 → Markdown、または右クリックでテーブルごとに）
- クイックアクション用コンテキストツールバー
- キーボードナビゲーション——`Tab` / `Shift + Tab` でセル間を移動、矢印キーでテーブルの端から外に出る、`Mod + Enter` / `Mod + Shift + Enter` で下 / 上に行を追加

## 画像

包括的な画像サポート：

- ファイルダイアログで挿入
- ファイルシステムからドラッグ＆ドロップ
- クリップボードから貼り付け

## 動画・音声

- [詳細を見る →](/ja/guide/media-support)

## Frontmatter パネル

WYSIWYG モードからソースモードに切り替えずに YAML フロントマターを直接編集できます。

- **デフォルトで折りたたみ**——フロントマターが存在する場合、ドキュメント上部に小さな「Frontmatter」ラベルが表示されます
- **クリックで展開**——YAML コンテンツ用のプレーンテキストエディタが開きます
- **`Mod + Enter`**——変更を保存してパネルを折りたたむ
- **`Escape`**——最後に保存した値に戻して折りたたむ
- **ブラー時の自動保存**——クリックして離れると、短い遅延後に変更が自動保存されます

パネルはエディタ履歴に取り消しポイントを作成するため、`Mod + Z` でフロントマターの変更をいつでも元に戻せます。

### 数学方程式

KaTeX による LaTeX レンダリング：

- インライン数式：`$E = mc^2$`
- 表示数式：`$$...$$` ブロック
- ChatGPT 形式の区切り記号は開くとき・貼り付けるときに認識され、`$` 形式に正規化されます：`\( ... \)` はインライン数式に、単独の `\[ ... \]` は表示ブロックになります
- `$$` ブロックは空行の前に閉じる必要があります（pandoc のルール）——閉じられていない `$$` は後続の段落を飲み込む代わりにリテラルテキストとして表示されます。閉じ記号の直前にある末尾の空行は問題ありません（空の `$$` … `$$` ブロックは数式ブロックのままです）
- 完全な LaTeX 構文サポート
- 構文ヒント付きの親切なエラーメッセージ

### ダイアグラム

- ソースモードのライブプレビューパネル（ドラッグ、サイズ変更、ズーム）
- [詳細を見る →](/ja/guide/mermaid)

同じプレビュー画面で使える Graphviz DOT サポート：

- ` ```dot ` と ` ```graphviz ` のフェンスされたコードブロックをローカルでレンダリング（WASM）
- Mermaid ダイアグラムと同様のパン、ズーム、PNG エクスポート
- [詳細を見る →](/ja/guide/graphviz)

### SVG グラフィックス

`` ```svg `` コードブロックでインラインの生 SVG をレンダリング：

- パン、ズーム、PNG エクスポート付きの即時レンダリング

### インライン目次

**挿入 → 目次** を選ぶと、どちらのモードでもライブの目次がすぐに挿入されます（このメニュー項目にはデフォルトのショートカットがありません。設定 → ショートカットで割り当てられます）。`[TOC]` を単独の行に書くこともできます。ソースモードではその行がそのまま目次になりますが、WYSIWYG で入力した `[TOC]` は、ドキュメントが再度パースされるまで（たとえばソースモードに切り替えて戻ったときや、ファイルを開き直したとき）ただのテキストのままです。他のテキストの中にある `[TOC]` は変換されません：

- ドキュメントの見出しから適切な入れ子構造で自動生成
- 任意の見出しをクリックするとその場所へ直接スクロール
- 編集に合わせてリアルタイムに更新
- WYSIWYG とエクスポート（HTML/PDF）でレンダリングされ、ソースモードとの往復でもきれいに保持

## 検索と置換

`Mod + F` で検索バーを開きます。ウィンドウ下部のバーに表示され、WYSIWYG モードとソースモードの両方で機能します。

**ナビゲーション：**

| アクション | ショートカット |
|-----------|--------------|
| 次のマッチを検索 | `Enter` または `Mod + G` |
| 前のマッチを検索 | `Shift + Enter` または `Mod + Shift + G` |
| 検索にセレクションを使用 | `Mod + E` |
| 検索バーを閉じる | `Escape` |

**検索オプション**——検索バーのボタンで切り替え：

- **大文字小文字を区別**——正確な文字ケースでマッチ
- **単語全体**——部分文字列ではなく完全な単語のみマッチ
- **正規表現**——正規表現パターンを使用（先に設定で有効化が必要）

**置換：**

置換フィールドは検索フィールドの隣にあります。どちらも常に表示されており、`Tab` で一方からもう一方へ移動します。置換テキストを入力し、**置換**（単一マッチ）または **すべて置換**（すべてのマッチを一度に）を使用します。マッチカウンターは現在の位置と合計を表示します（例："3 of 12"）ので、常に現在の位置がわかります。

## Markdown Lint

VMark には、ドキュメントの一般的な構文ミスやアクセシビリティの問題をチェックする組み込み Markdown リンターが含まれています。**設定 > Markdown > Lint** で有効にできます。

**使用方法：**

| アクション | ショートカット |
|-----------|--------------|
| Lint チェックを実行 | `Alt + Mod + V` |
| 次の問題へジャンプ | `F2` |
| 前の問題へジャンプ | `Shift + F2` |

Lint チェックを実行すると、診断結果がインラインハイライトとガターマーカーとして表示されます。問題が見つからない場合は、ドキュメントがクリーンであることをトースト通知で確認できます。問題はエラーまたは警告に分類されます。

**チェックされるルール（全 13 項目）：**

- 未定義の参照リンク
- テーブルの列数の不一致
- 逆転したリンク構文 `(テキスト)[URL]`（正しくは `[テキスト](URL)`）
- 見出しの `#` 後のスペース不足
- 強調マーカー内のスペース
- 空のリンクテキストまたは空のリンク URL
- 重複するリンク/画像定義
- 未使用のリンク/画像定義
- レベルを飛ばす見出しレベルの増分（例：H1 から H3）
- alt テキストのない画像（アクセシビリティ）
- 閉じられていないフェンス付きコードブロック
- 壊れたフラグメントリンク（`#アンカー` がどの見出しとも一致しない）

Lint 結果は入力に合わせて更新されません。ソースモードでは、編集すると結果が消去されます。WYSIWYG モードでは、編集するとハイライトは消えますが、ステータスバーの問題数と `F2` / `Shift + F2` の移動先は、チェックを再実行するかタブを閉じるまで前回の実行結果のまま残ります。`Alt + Mod + V` でいつでもチェックを再実行できます。

## ユニバーサルツールバー

エディタ下部に固定されたフォーマットツールバーで、WYSIWYG モードとソースモードの両方ですべてのフォーマットアクションに素早くアクセスできます。

- **切り替え：** `Mod + Shift + B` でツールバーを開いてフォーカスを与えます。もう一度押すとツールバーを表示したままエディタにフォーカスを戻します。
- **キーボードナビゲーション：** `左`/`右` 矢印キーでグループ間を移動。`Enter` または `Space` でドロップダウンメニューを開きます。矢印キーでメニュー内を移動します。
- **2 段階の Escape：** ドロップダウンメニューが開いている場合、`Escape` は最初にメニューを閉じます。もう一度 `Escape` を押すとツールバー全体を閉じます。
- **セッションメモリ：** ツールバーは現在のセッション中に最後にフォーカスされたボタンを記憶するため、再フォーカス時にその位置から再開します。
- **AI Genie ショートカット：** ツールバーには Genie ピッカーを開く AI Genie ボタンが含まれています（`Mod + Y`）。

## エディタのコンテキストメニュー

エディタ内（WYSIWYG またはソースモード）の任意の場所を右クリックすると、よく使うアクションのコンテキストメニューが開きます。

- **クリップボード：** 切り取り、コピー、貼り付け、すべて選択。macOS ではネイティブのクリップボード処理を使うため、リッチコンテンツ（ブラウザからコピーした HTML など）を貼り付けても書式が保持されます——`Mod + V` と同じです。
- **インライン書式：** 太字、斜体、取り消し線、インラインコード。カーソル位置で有効なマークにはチェックマークが付きます。
- **ブロック操作：** 見出しレベルとリストの種類のサブメニュー、引用、コードブロック——チェックマークは現在のブロックを反映します。
- **リンク：** プレーンテキストでは リンクを挿入...。既存のリンク上では、このセクションが リンクを編集...、リンクをコピー、リンクを削除 に切り替わります。
- **コンテキスト対応：** テーブル内では代わりに専用のテーブルメニューが表示され、画像を右クリックすると画像メニューが開き、コードブロック内ではクリップボード操作だけが提供されます。Markdown 以外のファイル（JSON、YAML、…）ではクリップボードのみの縮小メニューになります。
- **選択の扱い：** 選択範囲の内側を右クリックすると選択が保持され、それ以外の場所を右クリックすると先にカーソルがそこへ移動します（macOS の慣例）。
- **キーボード：** 矢印キーで移動し（無効な項目はスキップされます）、`Right`/`Left` でサブメニューに出入りし、`Escape` はまずサブメニューを、次にメニューを閉じます。ショートカットのヒントはカスタムのキー割り当てを反映します。

## コマンドパレット

`Mod + Shift + P` を押すとコマンドパレットが開きます。クエリが空の場合は、利用可能なすべてのコマンドがカテゴリ別に一覧表示されます——ファイル、ワークスペース、表示、エクスポート、書式、見出し、リスト、テーブル、行、選択、変換、CJK、Lint、履歴、AI など。入力すると絞り込まれ、一致度で並べ替えられます。`↑`/`↓` で移動し、`Enter` でコマンドを実行し、`Escape`（または背景のクリック）で閉じます。表示されるのは今適用できるコマンドだけです——ドキュメントが開いていなければエディタのコマンドが、ワークスペースが開いていなければワークスペースのコマンドが消えます——そしてコマンドはパレットを開いたウィンドウで実行されます。このガイドのページでは、パレットのコマンドを引用符付きで示しています（「Markdown分割ビューを切り替え」、「整合性の内訳」、「ウィンドウの状態」）。パレットにはメニュー項目がなく、ショートカットは **設定 → ショートカット** でカスタマイズできます。

## エクスポートオプション

VMark はドキュメントを共有するための柔軟なエクスポートオプションを提供します。

### HTML エクスポート

**ファイル → エクスポート → HTML** は、`index.html`（リンクされた `assets/` フォルダー付き）と `standalone.html`（すべてを埋め込み）の両方を含むフォルダーを書き出します——選ぶモードはありません。用途に合うほうのファイルを使ってください。

エクスポートされた HTML には[**VMark Reader**](/ja/guide/export#vmark-reader)——設定、目次、画像ライトボックスなどのインタラクティブコントロールが含まれます。

[エクスポートについて詳しく →](/ja/guide/export)

### PDF エクスポート

**ファイル → エクスポート → PDF** は VMark 独自のエクスポートダイアログを開きます——用紙サイズ（A4、Letter、A3、Legal）と向き、余白のプリセットまたはドラッグできるカスタム余白ボックス、フォントサイズ、行の高さ、Latin と CJK のフォント、スタイルのプリセット、ページ番号——そして macOS、Windows、Linux で PDF を書き出し、ビューアのサイドバーにはクリックできる見出しのアウトラインが付きます。**印刷**（`Cmd/Ctrl + P`）はシステムの印刷ダイアログを通る別の経路です。[詳細を見る →](/ja/guide/export#印刷-pdf-エクスポート)

### HTML としてコピー

他のアプリに貼り付けるためにフォーマットされたコンテンツをコピー（`Cmd/Ctrl + Shift + C`）。

### コピーフォーマット

デフォルトでは、WYSIWYG からのコピーはクリップボードにプレーンテキスト（フォーマットなし）を入れます。**設定 > エディタ > 動作** で **Markdown** コピーフォーマットを有効にすると、代わりに Markdown 構文を `text/plain` に入れます——見出しは `#` を保持し、リンクは URL を保持するなど。ターミナル、コードエディタ、チャットアプリへの貼り付けに便利です。

## CJK フォーマット

組み込みの中国語/日本語/韓国語テキストフォーマット：

- 20 以上の設定可能なフォーマットルール
- CJK-English スペーシング
- 全角文字変換
- 句読点の正規化
- アポストロフィ/プライム検出付きのスマート引用符ペアリング
- 技術的構造の保護（URL、バージョン、時刻、小数点）
- コンテキストに応じた引用符変換（CJK にはカーリー、Latin には直線）
- カーソルでの引用符スタイルの切り替え（`Shift + Mod + '`）
- [詳細を見る →](/ja/guide/cjk-formatting)

## ドキュメント履歴

VMark はドキュメントのスナップショットを自動的に保存するため、以前のバージョンを復元できます。

- 設定可能な間隔での**自動保存**がバックグラウンドでスナップショットを取得
- **ドキュメントごとの履歴**が VMark のアプリケーションデータフォルダーにローカル保存（インデックスファイル 1 つと、スナップショットごとに 1 つの Markdown ファイル）
- `Ctrl + Shift + 3` で履歴サイドバーを開いて過去のバージョンを閲覧
- スナップショットは**日ごとにグループ化**され、各バージョンの正確な保存時刻がタイムスタンプで表示
- 任意のスナップショット横の復元ボタンをクリックして以前のバージョンを**復元**（確認ダイアログで誤った復元を防止）
- 不要になった個別のスナップショットをゴミ箱ボタンで**削除**
- 復元前に現在の内容が新しいスナップショットとして保存されるため、作業を失うことはありません
- 履歴にはドキュメントがファイルとして保存されている必要があります（無題のドキュメントには履歴がありません）
- **設定 → ファイルと画像 → 保存**（**ドキュメント履歴を保持**）で履歴追跡を有効または無効にできます

## セッションリカバリ（Hot Exit）

VMark がアップデートのインストールのために再起動した場合や、予期しない終了が発生した場合、作業内容が保存され、次回起動時に復元されます。

**アップデート時の再起動で保存される内容：**
- すべての開いているタブとその内容（未保存の変更を含む）
- カーソル位置と取り消し/やり直し履歴
- UI レイアウト：サイドバーの状態、アウトラインの表示状態、ソース/フォーカス/タイプライターモード、ターミナルの状態
- ウィンドウの位置とサイズ
- アクティブなワークスペースとファイルエクスプローラーの設定

**仕組み：**
- 再起動してアップデートをインストールすることを選ぶと、VMark はまずすべてのウィンドウの完全なセッション状態をキャプチャ
- 再起動時、タブは離れた時と全く同じ状態で復元され、変更済み（未保存）のドキュメントはそのようにマーク
- 未保存の変更は 10 秒ごとにリカバリスナップショットにも書き込まれます。予期しない終了の後、VMark は次回起動時にそれらを未保存のタブとして復元
- 7 日以上経過したリカバリスナップショットは自動的にクリーンアップ
- 通常の終了ではセッションはキャプチャされません。VMark は先に未保存のドキュメントを保存するよう求めます（[タブとウィンドウを閉じる](/ja/guide/tab-navigation#タブとウィンドウを閉じる)を参照）。それでも、ワークスペースの開いていたタブは次にそのワークスペースを開いたときに戻ります（[セッションの復元](/ja/guide/workspace-management#セッションの復元)を参照）

設定は不要です。セッションリカバリは常にアクティブです。

## ステータスバー

ステータスバーはウィンドウの下部にあります（`F7` で非表示）。左側にはタブストリップ——[開いているタブの切り替え](/ja/guide/tab-navigation#開いているタブの切り替え)を参照——と、*「ソースモードで開きました（大きなファイル）。」* のような短い通知が表示されます。右側には、左から順に次のものがあります：

| インジケーター | 表示内容 | クリック |
|---|---|---|
| 自動保存 | 保存アイコンと、ドキュメントが自動保存されてからの経過時間。数秒後にフェードします | — |
| カウント | 単語数と文字数（スペースは数えません）。選択がある場合は *選択 / 合計* | **文字数カウント** のポップオーバーを開きます：単語数、文字数、スペースを除く文字数、CJK 文字数、句読点を除く文字数 |
| Lint | 前回の [Lint](#markdown-lint) 実行で見つかった ⊗ エラーまたは ⚠ 警告。ない場合は非表示 | 次の問題にジャンプします |
| AI | Genie の実行中は経過秒数付きの *考え中...* と、キャンセル用の ×。その後 *完了*、またはエラーと 失敗したリクエストをもう一度実行する **再試行** と **閉じる**。再実行できるものがない場合 (プロバイダー未設定など) は再試行は表示されません | — |
| MCP | 衛星アイコン。AI クライアントが接続していると色が付きます。正常に動作していないときは *off*、*…*、*error* の語が表示されます。ツールチップには接続中のクライアントが表示されます | **設定 → インテグレーション** を開きます |
| MCP リスナー | このウィンドウのリクエストリスナーが再試行を尽くしても起動できなかったときの警告「このウィンドウではMCPを利用できません」。MCP サーバーが動作していても、AI クライアントはこのウィンドウに届きません。VMark を再起動して再試行してください | — |
| MCP 履歴 | フォーカス中のドキュメントの AI バージョン数を示す履歴アイコン。変更が記録されていないときは警告色になります。パネルには各バージョンを誰が作ったかが表示され、**この版を復元** と **この変更の前の状態に復元** があり、[以前のチェックポイント](/ja/guide/mcp-setup#編集チェックポイント) も含まれます | パネルを開きます |
| ターミナル | — | ターミナルを表示または非表示にします |
| モード | 現在のモード——ソースまたは WYSIWYG（GitHub Actions のワークフローファイルでは非表示） | モードを切り替えます |
| ロック | ドキュメントが読み取り専用かどうか | 読み取り専用を切り替えます |

ブラウザタブがアクティブな間、右側は非表示になります。非表示にしたステータスバーは、AI Genie が進捗を報告している間やブラウザタブがアクティブな間、自動的に再表示されます。

## 編集の詳細

設定なしで機能するいくつかの動作：

- **エディタがフォーカスを失っても選択は表示されたままです。** ターミナル、サイドバー、ポップアップをクリックしても、選択したテキストには薄いハイライトが残るため、コマンドや AI ツールが何に作用するかを確認できます。ソースモードではマルチカーソル選択のすべての範囲が表示されます。
- **インラインコードの左端で入力すると、その内側に入ります。** WYSIWYG モードでカーソルがインラインコードの直前にある場合——どのようにそこに移動したかにかかわらず——次の文字はコードの外ではなくコードの一部になります。
- **入力メソッド（IME）は安全です。** 中国語、日本語、韓国語の入力メソッドで変換している間と、変換の確定後 50 ms の間は、エディタのショートカットや自動変換が発動しません。そのため、Enter を押して候補を確定しても段落が分割されることはありません。取り消しとやり直しは引き続き機能します。Enter で確定した韓国語の音節では、新しい行も開始されます。確定したテキストの前に残ったローマ字は削除され、空のテーブルセルに確定した文字は入力したとおりに残ります。情報のトーストは変換が終わるまで待ちますが、エラーと警告はすぐに表示されます。MCP 経由の AI クライアントによる編集は、拒否される（クライアントが再試行します）か、変換が終わるまで保留されます。ディスク上のファイルの変更も待機するため、いずれも変換中のテキストを上書きしません。
- **視差効果を減らす設定が尊重されます。** OS のアクセシビリティ設定 *視差効果を減らす* がオンの場合、VMark はアニメーションとトランジションをオフにし、スムーズスクロールの代わりに即座にスクロールします（タイプライターモードを含む）。VMark に別の設定はありません。同様に、システムの *透明度を下げる* 設定は背景のぼかしをオフにします。

## 表示とフォーカス

### フォーカスモード（`F8`）

フォーカスモードは現在編集中のブロック以外をすべて暗くし、視覚的なノイズを減らして単一の段落に集中できるようにします。アクティブなブロックは完全な不透明度でハイライトされ、周囲のコンテンツは薄い色にフェードします。`F8` で切り替えます——WYSIWYG モードとソースモードの両方で機能し、切り替えるまで持続します。

### タイプライターモード（`F9`）

タイプライターモードはアクティブな行をビューポートの垂直方向の中央に保持するため、ドキュメントが下にスクロールする間も目が固定位置に留まります——物理的なタイプライターで入力するのと同様です。`F9` で切り替えます。両方の編集モードで機能し、わずかなカーソル移動での不安定な調整を避けるため、小さなしきい値でスムーズスクロールを使用します。

### フォーカス + タイプライターの組み合わせ

フォーカスモードとタイプライターモードは同時に有効にできます。合わせると、完全に気が散らない執筆環境を提供します：周囲のブロックが暗くなり、*かつ*現在の行が画面の中央に固定されます。

### ワードラップ（`Alt + Z`）

`Alt + Z` でソフトラインラップを切り替えます。有効にすると、長い行は水平スクロールの代わりにエディタ幅で折り返します。この設定はセッション間で持続します。

### 読み取り専用モード（`F10`）

ドキュメントをロックして誤編集を防止します。`F10` で切り替えます。有効な場合、すべてのキーボード入力とフォーマットコマンドがブロックされます——スクロール、テキスト選択、コピーは引き続き可能です。完成したドキュメントのレビューや、別のタブで執筆しながらコンテンツを参照するのに便利です。

### アウトラインパネル（`Ctrl + Shift + 1`）

アウトラインパネルは、ドキュメントの見出し構造をサイドバーの折りたたみ可能なツリーとして表示します。`Ctrl + Shift + 1` で開きます。

- 任意の見出しをクリックしてエディタをそのセクションにスクロール
- 見出しグループを折りたたみ/展開して、ドキュメントの特定の部分に集中
- スクロールや入力に応じて、現在アクティブな見出しがハイライト
- 見出しの追加、削除、名前変更に合わせてリアルタイム更新
- 長いタイトルは 2 行に折り返され、ホバーすると全体が表示されます
- パネル上部のフィルター入力で、テキストがクエリに一致する見出しにツリーを絞り込めます（大文字と小文字を区別せず、パスが見えるよう祖先は保持されます）。`Esc` でクリアします。

### ズーム

設定を開かずにエディタのフォントサイズを調整：

| アクション | ショートカット |
|-----------|--------------|
| ズームイン | `Mod + =` |
| ズームアウト | `Mod + -` |
| デフォルトにリセット | `Mod + 0` |

ズームはエディタのフォントサイズを 2px 単位で変更します（範囲：12px〜32px）。**設定 > 外観** にある同じフォントサイズの値を変更するため、キーボードズームと設定スライダーは常に同期しています。

## テキストユーティリティ

VMark はフォーマットメニューで利用可能なテキストクリーンアップとフォーマットのユーティリティを含みます：

### テキストクリーンアップ（フォーマット → テキストクリーンアップ）

- **末尾のスペースを削除**：行末から空白を削除
- **空白行を折りたたむ**：複数の空白行を 1 つに減らす

**末尾のスペースを削除** と **空白行を折りたたむ** は、フェンスで囲まれたコードブロックには手を触れません。閉じられていないフェンスも同様で、その場合はドキュメントの末尾までがコードブロックとして扱われます。インデントによるコードブロックは保護されません。

### CJK フォーマット（フォーマット → CJK）

組み込みの中国語/日本語/韓国語テキストフォーマットツール。[詳細を見る →](/ja/guide/cjk-formatting)

### 画像クリーンアップ（書式 → テキストのクリーンアップ → 未使用の画像をクリーンアップ...）

アセットフォルダから孤立した画像を見つけて削除します（コマンドパレットからも使用できます）。VMark は見つかったものを表示して削除前に確認を求め、削除された画像はシステムのゴミ箱に移動します。開いているいずれかのドキュメントがまだ使用している画像（別の VMark ウィンドウの未保存の変更を含む）は保持されます。画像が未使用であることを VMark が確認できない場合（たとえば、別のウィンドウが時間内に応答しない場合）、何も削除しません。

## 統合ターミナル

複数セッション、コピー/ペースト、検索、クリック可能なファイルパスと URL、コンテキストメニュー、テーマ同期、設定可能なフォント設定を持つ組み込みターミナルパネル。`` Ctrl + ` `` で切り替えます。[詳細を見る →](/ja/guide/terminal)

## 自動更新

VMark は自動的にアップデートを確認し、アプリ内でダウンロードしてインストールできます：

- 起動時の自動更新確認
- ワンクリックのアップデートインストール
- 更新前のリリースノートプレビュー

## ワークスペースサポート

- フォルダをワークスペースとして開く
- サイドバーでのファイルツリーナビゲーション
- クイックファイル切り替え
- 最近のファイルの追跡
- セッション間でウィンドウサイズと位置を記憶
- ウィンドウの状態パネル——開いているすべてのウィンドウの Claude Code / AI のライブ状態を確認し、対応が必要なウィンドウに直接ジャンプできます。このウィンドウ、またはすべてのウィンドウ（後で開くウィンドウを含む）にピン留めすると、ウィンドウ間を移動している間も開いたままにできます

[詳細を見る →](/ja/guide/workspace-management)

## 整合性、ナレッジベース、Slidev

- **整合性と「整合性の内訳」パネル**——オプトインの来歴追跡が、各 AI 生成がどのドキュメントを読んだかを記録し、上流が変更されたときに下流のドキュメントにフラグを立て、さらにセマンティックチェック、正典（canon）の主張、コンテキストを追加します。**ウィンドウ → 整合性の内訳** から開きます。[詳細を見る →](/ja/guide/coherence)
- **ナレッジベース**——開いているワークスペースを相互リンクされたサイト（Wiki リンク、バックリンク、関係グラフ、全文検索）として `127.0.0.1` 上で提供し、パネル（`Ctrl + Shift + 4`）またはブラウザーで表示します。Slidev デッキのプレビューとエクスポートも行います。必要なコンテンツサーバーのランタイムを含むリリースビルドはまだないため、パネル、そのメニュー項目、パレットコマンド、ショートカットは、**設定 → 詳細設定 → 開発者ツール** がオンの場合を除き非表示です。[詳細を見る →](/ja/guide/knowledge-base)

## カスタマイズ

### テーマ

6 つの組み込みカラーテーマ：

- White（クリーン、ミニマル）
- Paper（温かみのあるオフホワイト）
- Mint（ソフトなグリーンティント）
- Sepia（ビンテージな外観）
- Night（ダークモード）
- Solarized（ダーク、Solarized パレット）

### フォント

以下のフォントを個別に設定：

- Latin テキスト
- CJK（中国語/日本語/韓国語）テキスト
- モノスペース（コード）

各ピッカーには、おすすめフォントの短いリスト、コンピューターにインストールされているフォント、そして任意のフォントファミリー名を入力できる **カスタム…** 項目があります。[詳細 →](/ja/guide/settings#タイポグラフィ)

モノスペースフォントは、ソースモード、コード、ターミナルで使われる前にチェックされます：選んだフォントがインストールされていない場合や、等幅でないことがわかった場合、VMark はフォントスタックに沿って次の等幅フォントにフォールバックします。これが最も重要になるのは CJK ロケールの Linux で、存在しないフォント名がプロポーショナルな CJK フォントに解決され、ターミナルのグリッドが崩れることがあるためです。

### レイアウト

以下を調整：

- フォントサイズ
- 行の高さ
- ブロックスペーシング（段落とブロック間のギャップ）
- CJK 文字間隔（CJK の読みやすさのための微妙なスペーシング）
- エディタ幅
- ブロック要素のフォントサイズ（リスト、引用、テーブル、アラート）
- 見出しの配置（左または中央）
- 画像とテーブルの配置（左または中央）

### キーボードショートカット

すべてのショートカットは設定 → ショートカットでカスタマイズできます。

## 技術的詳細

VMark はモダンな技術で構築されています：

| コンポーネント | テクノロジー |
|-------------|------------|
| デスクトップフレームワーク | Tauri v2 (Rust) |
| フロントエンド | React 19, TypeScript |
| 状態管理 | Zustand v5 |
| リッチテキストエディタ | Tiptap (ProseMirror) |
| ソースエディタ | CodeMirror 6 |
| スタイリング | Tailwind CSS v4 |

すべての処理はローカルマシン上で行われます——クラウドサービスもアカウントも不要です。
