# インラインポップアップ

VMark はリンク、画像、メディア、数式、脚注などを編集するためのコンテキストポップアップを提供します。これらのポップアップは WYSIWYG モードとソースモードの両方で一貫したキーボードナビゲーションで動作します。

## 共通キーボードショートカット

すべてのポップアップはこれらのキーボード動作を共有します：

| アクション | ショートカット |
|----------|-------------|
| 閉じる/キャンセル | `Escape` |
| 確認/保存 | `Enter` |
| フィールドをナビゲート | `Tab` / `Shift + Tab` |

## リンクポップアップ

リンクをクリックすると編集ポップアップが表示されます。カーソルはクリックした位置に留まるため、リンクテキストをそのまま編集し続けられます——入力、`Backspace`、コピー/ペーストはすべてドキュメントに対して動作します。テキストを編集するか、カーソルをリンクの外に移動すると、ポップアップはすぐに閉じます。

### 既存リンクの編集

**トリガー:** リンクをクリック、またはリンク内にカーソルを置く + `Mod + K`

クリックした場合、キーボード入力はドキュメントに残ります。リンク先を編集するには URL フィールドをクリックしてください。`Mod + K` を使うと URL フィールドに直接フォーカスが移ります。

**フィールド:**
- **URL**——リンク先を編集
- **リンク先を開く**——外部 URL はブラウザで開き、`#bookmark` リンクは見出しにジャンプし、ファイル間リンクはローカルファイルを新しいタブで開く
- **コピー**——URL をクリップボードにコピー
- **削除**——リンクを削除し、テキストを保持

**ポップアップなしで開く:** リンク上で `Cmd + Click`（Windows/Linux では `Ctrl + Click`）すると、リンク先を直接開きます。

### 新しいリンクの作成

**トリガー:** テキストを選択 + `Mod + K`

**スマートクリップボード:** クリップボードに URL が含まれている場合、自動的に入力されます。

**フィールド:**
- **URL 入力**——宛先を入力
- **確認**——Enter を押すか✓をクリック
- **キャンセル**——Escape を押すか✗をクリック

### ソースモード

- リンク上で **`Cmd + Click`**（Windows/Linux では `Ctrl + Click`）→ 外部 URL はブラウザで開き、`#bookmark` リンクは見出しにジャンプし、ローカルファイルパスは新しいタブでファイルを開く
- `[text](url)` 構文を **クリック** → 編集ポップアップを表示。カーソルは Markdown 内に留まるので、そのまま入力を続けられる
- リンク内で **`Mod + K`** → URL フィールドにフォーカスした状態で編集ポップアップを表示

::: tip ブックマークリンク
`#` で始まるリンクはブックマーク（内部見出しリンク）として扱われます。「開く」はブラウザを開く代わりに見出しにジャンプします。
:::

::: tip ファイル間リンク
ローカルファイルを指すリンクは、対象ファイルを新しいタブで開きます。リンクに `#fragment` が含まれている場合は、その見出しの位置に移動します。`../appendix/cards.md` や `./notes.md` のような相対パスは、現在のドキュメントのディレクトリを基準に解決されます。絶対パス（macOS/Linux では `/Users/me/notes/a.md`、Windows では `C:\notes\a.md`）は、指定したファイルをそのまま開きます。ネットワークパス（`\\server\share\…`）はリンクからは開きません。ドキュメントが無題の場合は、絶対パスのみ開くことができます。
:::

## 見出しピッカー（ブックマークリンク）

**トリガー:** `Alt + Mod + B`（ブックマークリンク）、**挿入 → リンク → ブックマーク**、またはユニバーサルツールバーのリンクグループ

ブックマークリンクは、同じドキュメント内の見出しを指します（`[text](#heading-id)`）。アンカーを入力する代わりに、ピッカーがドキュメント内のすべての見出しをレベルに応じてインデントして一覧表示し、上部に絞り込み用のフィールドを備えています。

**動作:**
- `↑`/`↓` で一覧を移動し、`Enter` でリンクを挿入、`Escape` で閉じる
- テキストを選択している場合は選択範囲がリンクテキストになり、選択がない場合は見出し自体のテキストがリンクとして挿入される
- ドキュメントに見出しがない場合や、絞り込みに一致するものがない場合は、ポップアップがその旨を表示する

## メディアポップアップ（画像、ビデオ、オーディオ）

すべてのメディアタイプ——画像、ビデオ、オーディオ——を編集するための統合ポップアップ。

### 編集ポップアップ

**トリガー:** 任意のメディア要素（画像、ビデオ、オーディオ）をダブルクリック

**すべてのメディアタイプに共通のフィールド:**
- **ソース**——ファイルパスまたは URL

**タイプ固有のフィールド:**

| フィールド | 画像 | ビデオ | オーディオ |
|---------|-----|------|---------|
| Alt テキスト | はい | — | — |
| タイトル | — | はい | はい |
| ポスター | — | はい | — |
| サイズ | 読み取り専用 | — | — |
| インライン/ブロック切り替え | はい（リンク付き画像を除く） | — | — |

**ボタン:**
- **参照**——ファイルシステムからファイルを選択
- **コピー**——ソースパスをクリップボードにコピー
- **削除**——メディア要素を削除

**ショートカット:**
- `Mod + Shift + I`——新しい画像を挿入
- `Enter`——変更を保存
- `Escape`——ポップアップを閉じる

### ソースモード

ソースモードでは、画像構文 `![alt](path)` をクリックすると同じメディアポップアップが開きます。

ソースモードでは、メディアのフローティング **プレビュー**——画像、またはネイティブ再生コントロール付きのビデオやオーディオのプレーヤー——も表示されます。プレビューは、カーソルが `![alt](path)` の中にあるとき（テキストを選択していない場合）と、マウスが構文の上にホバーしたときに表示され、カーソルによるプレビューがホバーによるものより優先されます。パスは、認識される画像、ビデオ、オーディオの拡張子で終わる（または `data:image/` URL である）必要があります。メディアポップアップが開いている間、プレビューは非表示になります。

## 画像コンテキストメニュー

WYSIWYG モードで画像を右クリックすると、クイックアクション付きのコンテキストメニューが開きます（ダブルクリックの編集ポップアップとは別です）。

**トリガー:** 任意の画像を右クリック

**アクション:**
| アクション | 説明 |
|---------|-----|
| 画像を変更 | ファイルピッカーを開いて画像を置き換える |
| 画像を削除 | ドキュメントから画像を削除する |
| パスをコピー | 画像のソースパスをクリップボードにコピー |
| Finder で表示 | ファイルマネージャーで画像ファイルの場所を開く（ラベルはプラットフォームに応じて変わります） |

`Escape` を押すとアクションを実行せずにコンテキストメニューを閉じます。

## 数式ポップアップ

ライブプレビュー付きで LaTeX 数式を編集します。

**トリガー:**
- **WYSIWYG:** インライン数式 `$...$` をクリック
- **ソース:** 空でない `$...$`、`$$...$$` ブロック、または ` ```latex ` / ` ```math ` ブロック内にカーソルを置く

**フィールド:**
- **LaTeX 入力**——数式を編集
- **プレビュー**——リアルタイムのレンダリングプレビュー
- **エラー表示**——役立つ構文ヒント付きで LaTeX エラーを表示

**ショートカット:**
- `Mod + Enter`——保存して閉じる
- `外側をクリック`——保存して閉じる（編集内容を確定）
- `Escape`——キャンセルして閉じる（編集内容を破棄）
- `Shift + Backspace`——インライン数式を削除（空でない場合も動作、WYSIWYG のみ）
- `Alt + Mod + M`——新しいインライン数式を挿入

::: tip エラーヒント
LaTeX の構文エラーがある場合、ポップアップは欠けている括弧、未知のコマンド、バランスの取れていない区切り記号などの役立つ提案を表示します。
:::

::: info ソースモード
ソースモードでも WYSIWYG と同じ編集可能な数式ポップアップが使えます——LaTeX 入力用テキストエリアの下にライブ KaTeX プレビューが表示されます。カーソルが任意の数式構文（空でない `$...$`、`$$...$$`、または ` ```latex ` / ` ```math `）に入ると自動的にポップアップが開きます。`Mod + Enter` で保存、`Escape` でキャンセルします。行末に入力された空の `$$` はプレーンテキストとして扱われ——入力途中のブロック数式の区切り記号である可能性が高いため——ポップアップは開きません。
:::

## 脚注ポップアップ

インラインで脚注コンテンツを編集します。

**トリガー:**
- **WYSIWYG:** 脚注参照 `[^1]` にホバー
- **ソース:** 脚注参照または脚注定義にホバー、またはクリック

**フィールド:**
- **コンテンツ**——複数行の脚注テキスト（自動リサイズ）
- **定義にジャンプ**——脚注の定義にジャンプ
- **削除**——脚注を削除

**動作:**
- 新しい脚注はコンテンツフィールドにオートフォーカスします
- 入力するにつれてテキストエリアが拡大します

## Wiki リンクポップアップ

内部ドキュメント接続のための Wiki スタイルリンクを編集します。

**トリガー:**
- **WYSIWYG:** `[[target]]` にホバー（300ms の遅延）
- **ソース:** Wiki リンク構文をクリック

**フィールド:**
- **ターゲット**——ワークスペース相対パス（`.md` 拡張子は自動処理）
- **参照**——ワークスペースからファイルを選択
- **開く**——リンクされたドキュメントを開く
- **コピー**——ターゲットパスをコピー
- **削除**——Wiki リンクを削除

## テーブルコンテキストメニュー

素早いテーブル編集アクション。

**トリガー:**
- **WYSIWYG:** テーブルセルを右クリック（同じアクションはツールバーにもあり、キーボードショートカットも使えます）
- **ソース:** テーブルセルを右クリック

**アクション:**
| アクション | 説明 |
|---------|-----|
| 上/下に行を挿入 | カーソル位置に行を追加 |
| 左/右に列を挿入 | カーソル位置に列を追加 |
| 行を削除 | 現在の行を削除 |
| 列を削除 | 現在の列を削除 |
| テーブルを削除 | テーブル全体を削除 |
| 列を左/中央/右に整列 | 現在の列の整列を設定 |
| すべてを左/中央/右に整列 | すべての列の整列を設定 |
| テーブルをフォーマット | テーブル列を自動整列（Markdown を整形） |
| 幅に合わせる / 自然な幅 | WYSIWYG のみ：このテーブルをエディターの幅に固定し、列幅を内容に比例させる。または自然な幅に戻す |

## スペルチェックポップアップ

提案でスペルエラーを修正します。

**トリガー:**
- 誤ったスペルの単語（赤いアンダーライン）を右クリック

**アクション:**
- **提案**——クリックして提案に置換
- **辞書に追加**——誤りとしてマークするのを停止

## ドラッグによるテキストの移動

WYSIWYG モードでは、マウスで選択範囲を移動できます。選択したテキストを押してドラッグし——ドロップカーソルが着地点を示します——離します。移動は 1 回で元に戻せる単一の操作です（`Mod + Z` で元に戻ります）。ドラッグ中に `Escape` を押すか、ウィンドウのフォーカスが外れるとキャンセルされます。デスクトップシェルがブラウザのネイティブなドラッグイベントを横取りするため、VMark はこれを独自に実装しています。そのため、これはシステムのドラッグ&ドロップではなくマウスジェスチャーです。

## モード比較

| 要素 | WYSIWYG での編集 | ソース |
|-----|--------------|------|
| リンク | クリック / `Mod+K` / 開くには `Cmd+Click` | クリック / `Mod+K` / 開くには `Cmd+Click` |
| 画像 | ダブルクリック | `![](path)` をクリック |
| ビデオ | ダブルクリック | — |
| オーディオ | ダブルクリック | — |
| 数式 | クリック | カーソルが数式内 → ポップアップ |
| 脚注 | ホバー | 直接編集 |
| Wiki リンク | ホバー | クリック |
| テーブル | ツールバー | 右クリックメニュー |
| スペルチェック | 右クリック | 右クリック |

## ポップアップナビゲーションのヒント

### フォーカスの流れ
1. 最初の入力フィールドにフォーカスしてポップアップが開く
2. `Tab` でフィールドとボタンを前方に移動
3. `Shift + Tab` で後方に移動
4. フォーカスはポップアップ内でラップする

### 素早い編集
- 単純な URL 変更の場合：編集して `Enter` を押す
- キャンセルする場合：任意のフィールドから `Escape` を押す
- 複数行コンテンツ（脚注、数式）の場合：`Mod + Enter` で保存

### マウスの動作
- ポップアップの外側をクリックして閉じる。デフォルトの動作では、保存されていない変更は**破棄**されます。数式ポップアップは例外で、外側をクリックすると編集を**確定**します（[数式ポップアップ](#数式ポップアップ)セクションを参照）
- ホバーポップアップ（脚注、Wiki）は表示前に 300ms の遅延がある
- マウスをポップアップに戻すと開いたままにする
