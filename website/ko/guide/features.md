# 기능

VMark는 사람과 AI가 함께 작업하는 일반 텍스트 워크스페이스입니다. 중심은 마크다운이지만 (WYSIWYG, 소스 미리보기, 소스 모드 제공), 워크스페이스는 YAML, JSON, TOML, Mermaid, SVG, HTML과 9가지 코드 뷰어 형식도 엽니다 — 전체 목록은 [지원 형식](/ko/guide/formats)을 참조하세요.

## 에디터 모드

### 리치 텍스트 모드 (WYSIWYG)

기본 편집 모드는 진정한 "보이는 대로 얻는" 경험을 제공합니다:

- 타이핑하면서 실시간 서식 미리보기
- 커서 호버 시 인라인 문법 표시
- 직관적인 툴바와 컨텍스트 메뉴
- 원활한 마크다운 문법 입력

### 소스 모드

전체 구문 강조와 함께 원시 마크다운 편집으로 전환합니다:

- CodeMirror 6 기반 에디터
- 완전한 구문 강조
- 수식, 링크, 이미지, 위키 링크, 미디어를 위한 인터랙티브 팝업——WYSIWYG 와 동일한 편집 경험
- 스마트 붙여넣기——웹 페이지와 Word 문서의 HTML 이 자동으로 깔끔한 Markdown 으로 변환
- 클립보드 이미지 붙여넣기——스크린샷과 복사된 이미지가 에셋 폴더에 저장되고 `![](path)` 로 삽입
- 코드 펜스 인식 멀티 커서와 CJK 단어 경계 지원
- 고급 사용자에게 적합

`F6`으로 모드를 전환합니다.

### 분할 보기 (소스 + 미리 보기)

왼쪽에서 원시 마크다운 소스를 편집하는 동안 오른쪽에서 **실시간 읽기 전용 WYSIWYG
미리보기** 가 갱신됩니다 — 미리보기가 *바로* WYSIWYG 렌더러이므로, 리치 텍스트 모드에서
보이는 것과 어긋나는 일이 없습니다. 서식 명령과 툴바는 소스 창에 적용되며, 구분선을 끌거나
(또는 구분선에서 화살표 키를 사용해) 크기를 조정합니다.

- `Shift + F6`, **보기 → 마크다운 분할 보기**, 또는 명령 팔레트 ("마크다운 분할 보기 전환")
  로 세션마다 전환합니다
- **설정 → 마크다운 → 레이아웃 → 기본적으로 소스/미리보기 분할** 에서 마크다운 파일의
  기본값으로 지정할 수 있습니다

기본값은 여전히 WYSIWYG이며, 분할은 선택 사항입니다. 세 가지 보기는 서로 배타적입니다 —
`F6`은 소스를, `Shift + F6`은 분할을 전환하며 각각 WYSIWYG로 돌아옵니다 — 따라서 보기
사이의 전환은 언제나 키 한 번이면 됩니다.

**보기** 메뉴는 세 가지 모드 — **WYSIWYG 모드**, **소스 코드 모드**, **마크다운 분할 보기**
— 를 체크 표시 그룹으로 보여 주므로, 활성 모드가 항상 보이고 상호 배타성이 명확합니다.
**자동 줄 바꿈** 과 **줄 번호** 는 소스 에디터에만 적용되므로 WYSIWYG 모드에서는 회색으로
비활성화됩니다.

### 읽기 위치

문서에서 읽던 위치는 문서를 떠나도 유지됩니다. 다른 탭으로 전환했다가 돌아오거나, 소스 모드나
분할 보기를 전환하거나, 디스크에서 파일이 다시 로드되어도 맨 위가 아니라 읽던 곳으로
돌아옵니다.

각 화면은 자신의 위치를 따로 기억하므로, 같은 파일에서도 리치 텍스트와 소스가 서로 다른
위치를 유지합니다. 같은 화면으로 돌아올 때(탭 전환, 파일 다시 로드)는 커서가 다른 곳에 있어도
스크롤해 두었던 위치로 돌아오며, 커서는 놓아 둔 자리에 그대로 남습니다. 리치 텍스트와 소스 사이를
전환할 때는 커서가 있으면 커서를 따라갑니다. 그래야 두 화면 사이에서 같은 단락이 화면에 유지되기 때문입니다.

위치는 문서별, 세션별로 기억되며 — 탭을 닫으면 잊힙니다.

### 모드 간 실행 취소

실행 취소와 다시 실행은 WYSIWYG ⇄ 소스 경계를 넘나듭니다. 모드를 전환할 때마다 체크포인트가 기록되며, 현재 에디터 자체의 기록이 다 소진되면 `Mod + Z`가 그 체크포인트를 따라 계속 진행합니다 — 지금 있는 보기를 바꾸지 않고 이전 내용을 복원합니다. 다시 실행은 같은 체인을 앞으로 따라가며, 새 편집으로 버린 분기에 대한 다시 실행은 작업 위에 적용되지 않고 거부됩니다. 이 체인은 탭별로 유지되며 탭을 닫으면 지워집니다.

### 대용량 파일

VMark는 1 MB가 넘는 파일을 1초 이내에 열기 위해 자동으로 소스 모드로 열고, 5 MB를 넘는 파일은 다루기 전에 경고하며, 50 MB를 넘는 파일은 거부합니다. 임계값과 설정은 [대용량 파일](./large-files.md) 가이드를 참조하세요.

### 소스 미리보기

WYSIWYG 모드를 벗어나지 않고 단일 블록의 원시 마크다운을 편집합니다. `F5`를 눌러 커서 위치의 블록에 대한 소스 미리보기를 엽니다.

**레이아웃:**
- 블록 유형 레이블과 동작 버튼이 있는 헤더 바
- 블록의 마크다운 소스를 보여주는 CodeMirror 에디터
- 원래 블록이 흐릿한 미리보기로 표시됨 (실시간 미리보기가 켜져 있을 때)

**컨트롤:**
| 동작 | 단축키 |
|------|--------|
| 변경사항 저장 | `Cmd/Ctrl + Enter` |
| 취소 (되돌리기) | `Escape` |
| 실시간 미리보기 토글 | 눈 아이콘 클릭 |

**실시간 미리보기:**
- **꺼짐 (기본값):** 자유롭게 편집, 저장 시에만 변경사항 적용
- **켜짐:** 타이핑하면서 즉시 변경사항 적용, 미리보기가 아래에 표시

**제외된 블록:**
일부 블록은 자체 편집 메커니즘이 있어 소스 미리보기를 건너뜁니다:
- 코드 블록 (Mermaid, LaTeX 포함) — 더블 클릭으로 편집
- 블록 이미지 — 이미지 팝업 사용
- 프론트매터, HTML 블록, 수평선

소스 미리보기는 시각적 에디터에 머물면서 정밀한 마크다운 편집 (표 문법 수정, 목록 들여쓰기 조정)에 유용합니다.

## 멀티 커서 편집

여러 위치를 동시에 편집합니다 — VMark는 WYSIWYG 및 소스 모드 모두에서 완전한 멀티 커서를 지원합니다.

| 동작 | 단축키 |
|------|--------|
| 다음 일치에 커서 추가 | `Mod + D` |
| 일치 건너뛰고 다음으로 이동 | `Mod + Shift + D` |
| 모든 항목 선택 | `Mod + Shift + L` |
| 위/아래에 커서 추가 | `Mod + Alt + 위/아래` |
| 클릭으로 커서 추가 | `Alt + 클릭` |
| 마지막 커서 실행 취소 | `Alt + Mod + Z` |
| 단일 커서로 축소 | `Escape` |

모든 표준 편집 (타이핑, 삭제, 클립보드, 탐색)이 각 커서에서 독립적으로 작동합니다. 일반 텍스트에서는 `Mod + D`와 `Mod + Shift + L`이 문서 전체를 검색하고, 코드 블록 안에서는 해당 블록 안에서만 검색합니다. `Alt + Mod + Shift + L`은 현재 블록 안의 모든 일치 항목만 선택합니다.

[자세히 알아보기 →](/ko/guide/multi-cursor)

## 스마트 전체 선택

WYSIWYG 모드에서 `Mod + A`는 곧바로 문서 전체로 넘어가지 않고 선택 영역을 컨테이너 단위로 한 단계씩 넓힙니다. 테이블 안에서는 셀, 행, 테이블, 문서 순으로 선택합니다. `Mod + Z`는 확장을 한 단계 되돌리고, `Escape`는 선택 영역을 커서로 축소합니다.

소스 모드에서 `Mod + A`는 먼저 감싸고 있는 블록 — 코드 펜스, 테이블, 인용문 또는 목록 — 을 선택한 다음 문서 전체를 선택합니다. 여기서도 `Mod + Z`로 확장을 한 단계 되돌릴 수 있습니다.

이 단축키는 에디터에 속하며 사용자 정의할 수 없습니다.

## 자동 쌍 및 탭 탈출

여는 괄호, 따옴표 또는 백틱을 입력하면 VMark가 닫는 쌍을 자동 삽입합니다. **Tab** 을 눌러 화살표 키를 누르는 대신 닫는 문자를 건너뜁니다.

- 괄호: `()` `[]` `{}`
- 따옴표: `""` `''` `` ` ` ``
- CJK: `「」` `『』` `（）` `【】` `《》` `〈〉`
- 중괄호 따옴표: `""` `''`
- WYSIWYG의 서식 마크: **굵게**, *기울임꼴*, `코드`, ~~취소선~~, 링크

쌍이 비어있을 때 Backspace는 두 문자를 모두 삭제합니다. 자동 쌍과 탭 괄호 점프는 모두 **코드 블록 및 인라인 코드 내에서 비활성화** 됩니다 — 코드의 괄호는 그대로 유지됩니다. **설정 → 에디터** 에서 구성 가능합니다.

[자세히 알아보기 →](/ko/guide/tab-navigation)

## 텍스트 서식

### 기본 스타일

- **굵게**, *기울임꼴*, <u>밑줄</u>, ~~취소선~~
- `인라인 코드`, ==하이라이트==
- 아래첨자 및 위첨자
- 미리보기 팝업이 있는 링크, 위키 링크, 북마크 링크
- 인라인 편집이 가능한 각주
- HTML 주석 토글 (`Mod + /`)
- 서식 지우기 명령

### 텍스트 변환

서식 → 변환을 통해 텍스트 케이스를 빠르게 변경합니다:

| 변환 | 단축키 |
|------|--------|
| 대문자 | `Ctrl + Shift + U` (macOS) / `Alt + Shift + U` (Win/Linux) |
| 소문자 | `Ctrl + Shift + L` (macOS) / `Alt + Shift + L` (Win/Linux) |
| 제목 케이스 | `Ctrl + Shift + T` (macOS) / `Alt + Shift + T` (Win/Linux) |
| 케이스 토글 | — |

### 블록 요소

- 단축키로 쉽게 조작 가능한 제목 1-6 (레벨 늘리기/줄이기: `Mod + Alt + ]`/`[`)
- 인용문 (중첩 지원)
- 구문 강조가 있는 코드 블록
- 순서 있는, 순서 없는, 작업 목록
- 목록 유형 순환: 단락을 글머리 기호, 번호 매기기, 작업 목록 순으로 변환
- 목록 해제: 활성 목록 유형을 다시 클릭하면 목록 서식이 제거됩니다
- 코드로 변환: 코드 블록 동작은 커서 위치의 목록 전체 — 또는 여러 블록에 걸친 선택 영역 (단락, 제목, 목록) — 을 블록이나 목록 항목마다 한 줄씩인 하나의 코드 블록으로 바꿉니다
- 수평선
- 완전한 편집 지원이 있는 테이블

### 강제 줄 바꿈

단락 내에서 강제 줄 바꿈을 삽입하려면 `Shift + Enter`를 누릅니다.
VMark는 최대 호환성을 위해 기본적으로 두 칸 스타일을 사용합니다.
**설정 > 에디터 > 공백** 에서 구성합니다.

### 줄 작업

편집 → 줄을 통한 강력한 줄 조작:

| 동작 | 단축키 |
|------|--------|
| 줄 위로 이동 | `Alt + 위` |
| 줄 아래로 이동 | `Alt + 아래` |
| 줄 복제 | `Shift + Alt + 아래` |
| 줄 삭제 | `Mod + Shift + K` |
| 줄 합치기 | `Mod + J` |
| 빈 줄 제거 | — |
| 줄 오름차순 정렬 | `F4` _(소스 모드 전용)_ |
| 줄 내림차순 정렬 | `Shift + F4` _(소스 모드 전용)_ |

정렬은 일반 텍스트 줄을 대상으로 하므로 소스 모드에서만 사용할 수 있습니다.

## 테이블

완전한 기능의 테이블 편집:

- 메뉴 또는 단축키로 테이블 삽입
- 행과 열 추가/삭제
- 셀 정렬 (왼쪽, 가운데, 오른쪽)
- 열은 내용에 맞게 자동으로 크기가 조정되며, 넓은 테이블은 가로로 스크롤됩니다
- 너비에 맞춤 — 내용에 비례하는 열로 테이블을 에디터 너비에 고정합니다 (설정 → 마크다운, 또는 오른쪽 클릭으로 테이블별 지정)
- 빠른 작업을 위한 컨텍스트 툴바
- 키보드 탐색 — `Tab` / `Shift + Tab`으로 셀 사이를 이동하고, 화살표 키는 가장자리에서 테이블을 벗어나며, `Mod + Enter` / `Mod + Shift + Enter`로 아래 / 위에 행을 추가합니다

## 이미지

포괄적인 이미지 지원:

- 파일 대화 상자를 통해 삽입
- 파일 시스템에서 드래그 앤 드롭
- 클립보드에서 붙여넣기
- 프로젝트 에셋 폴더에 자동 복사
- 더블 클릭하여 소스 경로와 대체 텍스트 편집 — 이미지 크기는 읽기 전용으로 표시
- 오른쪽 클릭으로 이미지 변경, 이미지 삭제, 경로 복사, Finder에서 보기 (Windows에서는 탐색기에서 보기, Linux에서는 파일 관리자에서 보기)
- 인라인과 블록 표시 간 전환

## 비디오 및 오디오

HTML5 태그를 사용한 완전한 미디어 지원:

- 툴바 파일 선택기를 통해 비디오 및 오디오 삽입
- 에디터로 미디어 파일 드래그 앤 드롭
- 프로젝트 `.assets/` 폴더에 자동 복사
- 클릭으로 소스 경로, 제목, 포스터 (비디오) 편집
- 개인 정보 보호 강화 iframe으로 YouTube 삽입 지원
- 이미지 문법 폴백: `![](file.mp4)` 자동으로 비디오로 승격
- 유형별 색상 테두리가 있는 소스 모드 데코레이션
- [자세히 알아보기 →](/ko/guide/media-support)

## Frontmatter 패널

WYSIWYG 모드에서 소스 모드로 전환하지 않고 YAML frontmatter 를 직접 편집합니다.

- **기본 접힘**——frontmatter 가 있으면 문서 상단에 작은 "Frontmatter" 레이블이 표시됩니다
- **클릭하여 펼치기**——YAML 내용을 위한 일반 텍스트 에디터가 열립니다
- **`Mod + Enter`**——변경 사항을 저장하고 패널을 접습니다
- **`Escape`**——마지막 저장 값으로 되돌리고 접습니다
- **블러 자동 저장**——다른 곳을 클릭하면 짧은 지연 후 변경 사항이 자동으로 저장됩니다

패널은 에디터 히스토리에 실행 취소 포인트를 생성하므로, `Mod + Z`로 언제든 frontmatter 변경 사항을 되돌릴 수 있습니다.

### 수학 방정식

KaTeX 기반 LaTeX 렌더링:

- 인라인 수학: `$E = mc^2$`
- 디스플레이 수학: `$$...$$` 블록
- ChatGPT 스타일 구분 기호는 열기/붙여넣기 시 인식되어 `$` 형식으로
  정규화됩니다: `\( ... \)`는 인라인 수학이 되고, 단독으로 있는 `\[ ... \]`는
  디스플레이 블록이 됩니다
- `$$` 블록은 빈 줄 전에 닫혀야 합니다 (pandoc의 규칙) — 닫히지 않은
  `$$`는 뒤따르는 단락을 삼키는 대신 리터럴 텍스트로 렌더링됩니다.
  닫는 기호 바로 앞의 빈 줄은 괜찮습니다 (비어 있는
  `$$` … `$$` 블록은 수학 블록으로 유지됩니다)
- 완전한 LaTeX 문법 지원
- 문법 힌트가 있는 유용한 오류 메시지

## 검색 및 바꾸기

`Mod + F`로 찾기 바를 엽니다. 창 하단의 바에서 열리며 WYSIWYG 및 소스 모드 모두에서 작동합니다.

**탐색:**

| 동작 | 단축키 |
|------|--------|
| 다음 일치 찾기 | `Enter` 또는 `Mod + G` |
| 이전 일치 찾기 | `Shift + Enter` 또는 `Mod + Shift + G` |
| 찾기에 선택 사용 | `Mod + E` |
| 찾기 바 닫기 | `Escape` |

**검색 옵션** — 찾기 바의 버튼으로 토글:

- **대소문자 구분** — 정확한 문자 대소문자 일치
- **전체 단어** — 부분 문자열이 아닌 완전한 단어만 일치
- **정규 표현식** — 정규식 패턴 사용 (먼저 설정에서 활성화)

**바꾸기:**

바꾸기 필드는 찾기 필드 옆에 있습니다 — 두 필드는 항상 표시되며, `Tab`으로 서로 오갈 수 있습니다. 대체 텍스트를 입력한 다음 **바꾸기** (단일 일치) 또는 **모두 바꾸기** (한 번에 모든 일치)를 사용합니다. 일치 카운터는 현재 위치와 전체 수를 표시하므로 (예: "3/12") 지금 어디에 있는지 항상 알 수 있습니다.

## 마크다운 린트

VMark에는 문서의 일반적인 구문 오류와 접근성 문제를 검사하는 내장 마크다운 린터가 포함되어 있습니다. **설정 > 마크다운 > 린트** 에서 활성화합니다.

**사용 방법:**

| 동작 | 단축키 |
|------|--------|
| 린트 검사 실행 | `Alt + Mod + V` |
| 다음 문제로 이동 | `F2` |
| 이전 문제로 이동 | `Shift + F2` |

린트 검사를 실행하면 진단 결과가 인라인 하이라이트와 여백 마커로 표시됩니다. 문제가 없으면 토스트 알림으로 문서가 깨끗함을 확인합니다. 문제는 오류 또는 경고로 분류됩니다.

**검사되는 규칙 (총 13개):**

- 정의되지 않은 참조 링크
- 테이블 열 수 불일치
- 역순 링크 문법 `(텍스트)[url]` (올바른 형식: `[텍스트](url)`)
- 제목의 `#` 뒤에 공백 누락
- 강조 마커 안의 공백
- 빈 링크 텍스트 또는 빈 링크 URL
- 중복 링크/이미지 정의
- 사용하지 않는 링크/이미지 정의
- 레벨을 건너뛰는 제목 레벨 증가 (예: H1에서 H3)
- 대체 텍스트가 없는 이미지 (접근성)
- 닫히지 않은 펜스 코드 블록
- 깨진 프래그먼트 링크 (`#앵커`가 어떤 제목과도 일치하지 않음)

린트 결과는 입력하는 동안 갱신되지 않습니다. 소스 모드에서는 편집하면 결과가 지워집니다. WYSIWYG 모드에서는 편집하면 하이라이트는 사라지지만, 상태 바의 문제 수와 `F2` / `Shift + F2` 이동 대상은 검사를 다시 실행하거나 탭을 닫을 때까지 마지막 실행 결과로 유지됩니다. `Alt + Mod + V`로 언제든 검사를 다시 실행할 수 있습니다.

## 유니버설 툴바

에디터 하단에 고정된 서식 툴바로, WYSIWYG와 소스 모드 모두에서 모든 서식 작업에 빠르게 접근할 수 있습니다.

- **토글:** `Mod + Shift + B`로 툴바를 열고 포커스를 줍니다. 다시 누르면 툴바를 표시한 채로 에디터에 포커스를 돌려줍니다.
- **키보드 탐색:** `왼쪽`/`오른쪽` 화살표로 그룹 간 이동. `Enter` 또는 `Space`로 드롭다운 메뉴를 엽니다. 화살표 키로 메뉴 내 탐색.
- **2단계 Escape:** 드롭다운 메뉴가 열려 있으면 `Escape`가 먼저 메뉴를 닫습니다. `Escape`를 다시 누르면 전체 툴바가 닫힙니다.
- **세션 기억:** 툴바는 현재 세션에서 마지막으로 포커스된 버튼을 기억하여, 다시 포커스할 때 그 위치에서 이어갑니다.
- **AI 지니 단축키:** 툴바에는 지니 선택기를 여는 AI 지니 버튼이 포함되어 있습니다 (`Mod + Y`).

## 에디터 컨텍스트 메뉴

에디터 어디에서나 (WYSIWYG 또는 소스 모드) 오른쪽 클릭하면 자주 쓰는 동작이 담긴 컨텍스트 메뉴가 열립니다.

- **클립보드:** 잘라내기, 복사, 붙여넣기, 모두 선택. macOS에서는 네이티브 클립보드 파이프라인을 사용하므로, 서식 있는 콘텐츠 (예: 브라우저에서 복사한 HTML) 를 붙여넣어도 서식이 유지됩니다 — `Mod + V`와 동일합니다.
- **인라인 서식:** 굵게, 기울임꼴, 취소선, 인라인 코드. 커서 위치에서 활성화된 마크에는 체크 표시가 붙습니다.
- **블록 작업:** 제목 수준과 목록 유형 하위 메뉴, 인용문, 코드 블록 — 체크 표시가 현재 블록을 반영합니다.
- **링크:** 일반 텍스트에서는 링크 삽입, 기존 링크에서는 이 영역이 링크 편집, 링크 복사, 링크 제거로 바뀝니다.
- **상황 인식:** 테이블 안에서는 대신 전용 테이블 메뉴가 나타나고, 이미지를 오른쪽 클릭하면 이미지 메뉴가 열리며, 코드 블록 안에서는 클립보드 동작만 제공됩니다. 마크다운이 아닌 파일 (JSON, YAML, …) 에는 클립보드 전용의 축소된 메뉴가 표시됩니다.
- **선택 영역 처리:** 선택 영역 안에서 오른쪽 클릭하면 선택이 유지되고, 다른 곳에서 오른쪽 클릭하면 먼저 커서가 그곳으로 이동합니다 (macOS 관례).
- **키보드:** 화살표 키로 이동하고 (비활성 항목은 건너뜀), `Right`/`Left`로 하위 메뉴에 들어가고 나오며, `Escape`는 하위 메뉴를 먼저 닫고 그다음 메뉴를 닫습니다. 단축키 힌트는 사용자 정의 키 바인딩을 반영합니다.

## 명령 팔레트

`Mod + Shift + P`를 누르면 명령 팔레트가 열립니다. 검색어가 비어 있으면 사용 가능한 모든 명령이 카테고리별로 묶여 나열됩니다 — 파일, 워크스페이스, 보기, 내보내기, 서식, 제목, 목록, 테이블, 줄, 선택, 변환, CJK, 린트, 기록, AI 등. 입력하면 필터링되고 일치도 순으로 정렬됩니다. `↑`/`↓`로 이동하고, `Enter`로 명령을 실행하며, `Escape` (또는 배경 클릭) 로 닫습니다. 지금 적용되는 명령만 표시됩니다 — 열린 문서가 없으면 에디터 명령이, 워크스페이스가 없으면 워크스페이스 명령이 사라집니다 — 그리고 명령은 팔레트를 연 창에서 실행됩니다. 이 가이드의 페이지들은 팔레트 명령 이름을 따옴표로 표기합니다 ("마크다운 분할 보기 전환", "정합성 내역", "창 상태"). 팔레트에는 메뉴 항목이 없으며, 단축키는 **설정 → 단축키** 에서 변경할 수 있습니다.

## 내보내기 옵션

VMark는 문서를 공유하기 위한 유연한 내보내기 옵션을 제공합니다.

### HTML 내보내기

**파일 → 내보내기 → HTML** 은 `index.html` (연결된 `assets/` 폴더 포함) 과 `standalone.html` (모든 것이 내장됨) 을 모두 담은 폴더를 만듭니다 — 고를 모드는 없으며, 필요에 맞는 파일을 사용하면 됩니다.

내보낸 HTML에는 설정, 목차, 이미지 라이트박스 등에 대한 대화형 컨트롤이 있는 [**VMark Reader**](/ko/guide/export#vmark-reader)가 포함됩니다.

[내보내기에 대해 자세히 알아보기 →](/ko/guide/export)

### PDF 내보내기

**파일 → 내보내기 → PDF** 는 VMark 자체 내보내기 대화 상자를 엽니다 — 페이지 크기 (A4, Letter, A3, Legal) 와 방향, 여백 프리셋 또는 끌어서 조정하는 사용자 지정 여백 상자, 글꼴 크기, 줄 높이, 라틴 및 CJK 글꼴, 스타일 프리셋, 페이지 번호 — 그런 다음 macOS, Windows, Linux에서 PDF를 기록하며, 뷰어 사이드바에서 클릭할 수 있는 제목 개요가 포함됩니다. **인쇄** (`Cmd/Ctrl + P`) 는 시스템 인쇄 대화 상자를 거치는 별도의 경로입니다. [자세히 알아보기 →](/ko/guide/export#인쇄-pdf-내보내기)

### HTML로 복사

다른 앱에 붙여넣기 위해 서식 있는 콘텐츠를 복사합니다 (`Cmd/Ctrl + Shift + C`).

### 복사 형식

기본적으로 WYSIWYG에서 복사하면 클립보드에 일반 텍스트 (서식 없음)가 들어갑니다. **설정 > 에디터 > 동작** 에서 **마크다운** 복사 형식을 활성화하면 대신 `text/plain`에 마크다운 문법이 들어갑니다 — 제목은 `#`를 유지하고, 링크는 URL을 유지합니다. 터미널, 코드 에디터 또는 채팅 앱에 붙여넣을 때 유용합니다.

## 문서 히스토리

VMark는 문서의 스냅샷을 자동으로 저장하여 이전 버전을 복구할 수 있습니다.

- 구성 가능한 간격의 **자동 저장**이 백그라운드에서 스냅샷을 캡처
- **문서별 히스토리**가 VMark의 애플리케이션 데이터 폴더에 로컬로 저장 — 인덱스 파일 하나와 스냅샷마다 Markdown 파일 하나
- `Ctrl + Shift + 3`으로 히스토리 사이드바를 열어 이전 버전 탐색
- 스냅샷은 **날짜별로 그룹화**되며 각 버전의 정확한 저장 시간이 타임스탬프로 표시
- 스냅샷 옆의 복원 버튼을 클릭하여 이전 버전을 **복원** (확인 대화 상자로 실수 복원 방지)
- 더 이상 필요하지 않은 개별 스냅샷을 휴지통 버튼으로 **삭제**
- 복원 전에 현재 내용이 새 스냅샷으로 저장되므로 작업을 잃지 않습니다
- 히스토리에는 문서가 파일로 저장되어 있어야 합니다 (제목 없는 문서에는 히스토리가 없음)
- **설정 > 일반** 에서 히스토리 추적을 활성화 또는 비활성화

## 세션 복구 (Hot Exit)

VMark가 업데이트 설치를 위해 다시 시작되거나 예기치 않게 종료되면 작업 내용이 보존되고 다음 실행 시 복원됩니다.

**업데이트 재시작 시 저장되는 내용:**
- 모든 열린 탭과 그 내용 (저장되지 않은 변경 사항 포함)
- 커서 위치 및 실행 취소/다시 실행 히스토리
- UI 레이아웃: 사이드바 상태, 개요 표시 여부, 소스/포커스/타이프라이터 모드, 터미널 상태
- 창 위치 및 크기
- 활성 워크스페이스 및 파일 탐색기 설정

**작동 방식:**
- 다시 시작하여 업데이트를 설치하도록 선택하면 VMark가 먼저 모든 창의 전체 세션 상태를 캡처
- 재실행 시 탭이 떠난 상태 그대로 복원되며, 변경된 (저장되지 않은) 문서는 해당 표시와 함께 복원
- 저장되지 않은 변경 사항은 10초마다 복구 스냅샷에도 기록됩니다. 예기치 않게 종료된 후에는 다음 실행 시 VMark가 이를 저장되지 않은 탭으로 복원
- 7일이 지난 복구 스냅샷은 자동으로 정리
- 일반 종료에서는 세션을 캡처하지 않으며, VMark가 먼저 저장되지 않은 문서를 저장할지 묻습니다 ([탭과 창 닫기](/ko/guide/tab-navigation#탭과-창-닫기) 참조). 워크스페이스에서 열어 둔 탭은 다음에 그 워크스페이스를 열 때 다시 나타납니다 ([세션 복원](/ko/guide/workspace-management#세션-복원) 참조)

설정이 필요 없습니다. 세션 복구는 항상 활성 상태입니다.

## 상태 표시줄

상태 표시줄은 창 아래쪽을 따라 있습니다 (`F7`로 숨김). 왼쪽에는 탭 스트립 — [열린 탭 사이 전환](/ko/guide/tab-navigation#열린-탭-사이-전환) 참조 — 과 *"소스 모드로 열림(큰 파일)."* 같은 짧은 알림이 있습니다. 오른쪽에는 왼쪽부터 순서대로 다음이 있습니다:

| 표시기 | 표시 내용 | 클릭 |
|---|---|---|
| 자동 저장 | 저장 아이콘과 문서가 자동 저장된 지 얼마나 지났는지. 몇 초 후 사라짐 | — |
| 개수 | 단어와 문자 수 (공백 제외). 선택 영역이 있으면 *선택 / 전체* | **글자 수** 팝오버 열기: 단어, 문자, 공백 제외 문자, CJK 문자, 문장 부호 제외 문자 |
| 린트 | 마지막 [린트](#마크다운-린트) 실행에서 발견된 ⊗ 오류 또는 ⚠ 경고. 없으면 숨김 | 다음 문제로 이동 |
| AI | 지니가 실행되는 동안 경과 초가 표시된 *생각 중...* 과 취소용 ×. 그다음 *완료*, 또는 실패한 요청을 다시 실행하는 **다시 시도** 와 **닫기** 가 있는 오류. 다시 실행할 것이 없으면 (예: 공급자 미설정) 다시 시도가 표시되지 않습니다 | — |
| MCP | 위성 아이콘. AI 클라이언트가 연결되면 색이 입혀지고, 정상적으로 실행 중이 아니면 *off*, *…*, *error* 라는 단어가 표시됨. 도구 설명에 연결된 클라이언트 이름이 표시됨 | **설정 → 통합** 열기 |
| MCP 기록 | 이 탭에 대한 AI 쓰기 목록 (최신 순). 각 항목에 **이 쓰기 이전 상태로 복원** 이 있음. 휴지통 버튼은 묻지 않고 탭의 기록을 지움 | 목록 열기 |
| 터미널 | — | 터미널 표시 또는 숨기기 |
| 모드 | 현재 모드 — 소스 또는 WYSIWYG (GitHub Actions 워크플로우 파일에서는 숨김) | 모드 전환 |
| 잠금 | 문서가 읽기 전용인지 여부 | 읽기 전용 전환 |

브라우저 탭이 활성화되어 있는 동안에는 오른쪽이 숨겨집니다. 숨긴 상태 표시줄은 AI 지니가 진행 상황을 보고하거나 브라우저 탭이 활성화되어 있는 동안 저절로 다시 나타납니다.

## 편집 세부 사항

설정 없이 동작하는 몇 가지 동작:

- **에디터가 포커스를 잃어도 선택 영역이 보입니다.** 터미널, 사이드바, 팝업을 클릭해도 선택한 텍스트가 더 옅은 강조로 유지되므로, 명령이나 AI 도구가 무엇에 작용할지 볼 수 있습니다. 소스 모드는 멀티 커서 선택의 모든 범위를 표시합니다.
- **인라인 코드의 왼쪽 가장자리에서 입력하면 코드 안으로 들어갑니다.** WYSIWYG 모드에서 커서가 인라인 코드 스팬 바로 앞에 있으면 — 어떻게 그 위치에 왔든 — 다음 문자는 코드 밖이 아니라 코드에 합쳐집니다.
- **입력기 (IME) 를 안전하게 사용할 수 있습니다.** 중국어, 일본어, 한국어 입력기로 조합하는 동안과 조합이 끝난 후 50 ms 동안에는 에디터 단축키와 자동 변환이 실행되지 않으므로, 후보를 확정하려고 Enter를 눌러도 단락이 함께 나뉘지 않습니다. 실행 취소와 다시 실행은 계속 동작합니다. Enter로 확정한 한글 음절은 새 줄도 시작합니다. 확정된 텍스트 앞에 남은 로마자 입력은 제거되며, 빈 테이블 셀에 확정된 문자는 입력한 그대로 유지됩니다. 정보성 토스트는 조합이 끝날 때까지 기다리고, 오류와 경고는 즉시 표시됩니다. MCP를 통한 AI 클라이언트의 편집은 거부되거나 (클라이언트가 다시 시도합니다) 조합이 끝날 때까지 보류되고, 디스크의 파일 변경도 기다리므로 어느 쪽도 아직 조합 중인 텍스트를 덮어쓰지 않습니다.
- **동작 줄이기를 존중합니다.** 운영 체제의 *동작 줄이기* 손쉬운 사용 설정이 켜져 있으면, VMark는 애니메이션과 전환 효과를 끄고 부드럽게 스크롤하는 대신 즉시 스크롤합니다 (타이프라이터 모드 포함). VMark에는 별도의 설정이 없습니다. 시스템의 *투명도 줄이기* 설정도 마찬가지로 배경 흐림을 끕니다.

## 보기 및 포커스

### 포커스 모드 (`F8`)

포커스 모드는 현재 편집 중인 블록을 제외한 모든 블록을 흐리게 하여 단일 단락에 집중할 수 있도록 시각적 노이즈를 줄입니다. 활성 블록은 전체 불투명도로 강조되고 주변 콘텐츠는 흐릿한 색상으로 바랩니다. `F8`로 토글합니다 — WYSIWYG 및 소스 모드 모두에서 작동하며 토글을 끄기 전까지 유지됩니다.

### 타이프라이터 모드 (`F9`)

타이프라이터 모드는 활성 줄을 뷰포트의 세로 중앙에 유지하여 문서가 아래로 스크롤되는 동안 눈이 고정된 위치에 머무르게 합니다 — 마치 실제 타이프라이터처럼. `F9`로 토글합니다. 두 편집 모드에서 모두 작동하며 커서 이동 시 흔들림을 방지하기 위해 작은 임계값이 있는 부드러운 스크롤을 사용합니다.

### 포커스 + 타이프라이터 조합

포커스 모드와 타이프라이터 모드를 동시에 활성화할 수 있습니다. 함께 사용하면 완전히 방해 없는 글쓰기 환경을 제공합니다: 주변 블록은 흐릿하고 *현재 줄은 화면 중앙에 유지됩니다*.

### 자동 줄 바꿈 (`Alt + Z`)

`Alt + Z`로 소프트 줄 바꿈을 토글합니다. 활성화하면 긴 줄이 가로로 스크롤하는 대신 에디터 너비에서 줄 바꿈됩니다. 설정은 세션 간에 유지됩니다.

### 읽기 전용 모드 (`F10`)

문서를 잠가 실수 편집을 방지합니다. `F10`으로 토글합니다. 활성화되면 모든 키보드 입력과 서식 명령이 차단됩니다 — 스크롤, 텍스트 선택, 복사는 여전히 가능합니다. 완성된 문서를 검토하거나 다른 탭에서 글을 쓰면서 내용을 참조할 때 유용합니다.

### 개요 패널 (`Ctrl + Shift + 1`)

개요 패널은 문서의 제목 구조를 사이드바의 접을 수 있는 트리로 표시합니다. `Ctrl + Shift + 1`로 엽니다.

- 제목을 클릭하여 해당 섹션으로 에디터 스크롤
- 제목 그룹을 접고 펼쳐 문서의 특정 부분에 집중
- 스크롤하거나 입력할 때 현재 활성 제목이 강조 표시
- 제목을 추가, 제거 또는 이름을 변경하면 실시간 업데이트
- 긴 제목은 두 줄로 줄 바꿈되며, 마우스를 올리면 전체가 표시됨
- 패널 상단의 필터 입력란은 텍스트가 검색어와 일치하는 제목만 남도록 트리를 좁힙니다 (대소문자 구분 없음, 경로가 보이도록 상위 제목은 유지). `Esc`를 누르면 지워집니다.

### 확대/축소

설정을 열지 않고 에디터 글꼴 크기를 조정합니다:

| 동작 | 단축키 |
|------|--------|
| 확대 | `Mod + =` |
| 축소 | `Mod + -` |
| 기본값으로 재설정 | `Mod + 0` |

확대/축소는 에디터 글꼴 크기를 2px 단위로 변경합니다 (범위: 12px ~ 32px). **설정 > 외관** 에 있는 동일한 글꼴 크기 값을 수정하므로, 키보드 확대/축소와 설정 슬라이더가 항상 동기화됩니다.

## 텍스트 유틸리티

VMark에는 서식 메뉴에서 사용할 수 있는 텍스트 정리 및 서식 유틸리티가 포함됩니다:

### 텍스트 정리 (서식 → 텍스트 정리)

- **후행 공백 제거**: 줄 끝의 공백 제거
- **빈 줄 축소**: 여러 빈 줄을 하나로 줄이기

### CJK 서식 (서식 → CJK)

내장된 중국어/일본어/한국어 텍스트 서식 도구. [자세히 알아보기 →](/ko/guide/cjk-formatting)

### 이미지 정리 (서식 → 텍스트 정리 → 미사용 이미지 정리...)

에셋 폴더에서 고아 이미지를 찾아 제거합니다 (명령 팔레트에서도 사용할 수 있습니다). VMark는 찾은 항목을 보여 주고 삭제 전에 확인을 요청하며, 삭제된 이미지는 시스템 휴지통으로 이동합니다. 열려 있는 문서가 사용 중인 이미지 — 다른 VMark 창의 저장되지 않은 변경 사항 포함 — 는 유지됩니다. 이미지가 사용되지 않는다는 것을 VMark가 확인할 수 없으면 (예: 다른 창이 제때 응답하지 않는 경우) 아무것도 삭제하지 않습니다.

## 정합성, 지식 베이스 및 Slidev

- **정합성 및 내역 보기** — 선택적으로 켜는 출처 추적 기능으로, 각 AI 생성이 어떤 문서를 읽었는지 기록하고, 상위 문서가 바뀌면 하위 문서에 표시하며, 그 위에 의미 검사, 정본 주장 (canon claim), 컨텍스트를 더합니다. **창 → 정합성 내역** 에서 엽니다. [자세히 알아보기 →](/ko/guide/coherence)
- **지식 베이스** — 열린 워크스페이스를 상호 링크된 사이트 (위키 링크, 백링크, 관계 그래프, 전체 텍스트 검색)로 `127.0.0.1`에서 제공하며, 패널 (`Ctrl + Shift + 4`) 또는 브라우저에서 볼 수 있고, Slidev 덱을 미리 보고 내보냅니다. 필요한 콘텐츠 서버 런타임이 아직 어떤 릴리스 빌드에도 포함되어 있지 않으므로, **설정 → 고급 → 개발자 도구** 가 켜져 있지 않으면 패널, 메뉴 항목, 팔레트 명령, 단축키가 숨겨집니다. [자세히 알아보기 →](/ko/guide/knowledge-base)

## 사용자 정의

### 테마

여섯 가지 내장 색상 테마:

- White (깔끔하고 미니멀한)
- Paper (따뜻한 오프화이트)
- Mint (부드러운 녹색 계열)
- Sepia (빈티지 룩)
- Night (다크 모드)
- Solarized (다크, Solarized 팔레트)

### 폰트

다음에 대한 별도 폰트 구성:

- 라틴 텍스트
- CJK (중국어/일본어/한국어) 텍스트
- 모노스페이스 (코드)

각 선택기에는 짧은 추천 폰트 목록, 컴퓨터에 설치된 폰트, 그리고 원하는 폰트 패밀리 이름을 직접 입력하는 **사용자 지정…** 항목이 있습니다. [자세히 →](/ko/guide/settings#타이포그래피)

모노스페이스 폰트는 소스 모드, 코드, 터미널에서 사용되기 전에 검사됩니다: 선택한 폰트가 설치되어 있지 않거나 실제로는 고정폭이 아니라면, VMark는 폰트 스택을 따라 고정폭인 다음 폰트로 대체합니다. 이는 CJK 로캘의 Linux에서 특히 중요합니다. 그렇지 않으면 없는 폰트 이름이 비례폭 CJK 폰트로 해석되어 터미널의 격자가 깨질 수 있기 때문입니다.

### 레이아웃

다음을 조정합니다:

- 폰트 크기
- 줄 높이
- 블록 간격 (단락과 블록 사이의 간격)
- CJK 자간 (CJK 가독성을 위한 미묘한 간격)
- 에디터 너비
- 블록 요소 폰트 크기 (목록, 인용문, 테이블, 알림)
- 제목 정렬 (왼쪽 또는 가운데)
- 이미지 및 테이블 정렬 (왼쪽 또는 가운데)

### 키보드 단축키

설정 → 단축키에서 모든 단축키를 사용자 정의할 수 있습니다.

## 기술적 세부 사항

VMark는 최신 기술로 구축되었습니다:

| 구성 요소 | 기술 |
|---------|------|
| 데스크톱 프레임워크 | Tauri v2 (Rust) |
| 프론트엔드 | React 19, TypeScript |
| 상태 관리 | Zustand v5 |
| 리치 텍스트 에디터 | Tiptap (ProseMirror) |
| 소스 에디터 | CodeMirror 6 |
| 스타일링 | Tailwind CSS v4 |

모든 처리는 로컬 컴퓨터에서 이루어집니다 — 클라우드 서비스나 계정이 필요하지 않습니다.
