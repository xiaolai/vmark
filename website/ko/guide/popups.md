# 인라인 팝업

VMark는 링크, 이미지, 미디어, 수식, 각주 등을 편집하기 위한 컨텍스트 팝업을 제공합니다. 이 팝업들은 WYSIWYG 모드와 소스 모드 모두에서 일관된 키보드 탐색으로 작동합니다.

## 공통 키보드 단축키

모든 팝업은 다음 키보드 동작을 공유합니다:

| 동작 | 단축키 |
|------|--------|
| 닫기/취소 | `Escape` |
| 확인/저장 | `Enter` |
| 필드 이동 | `Tab` / `Shift + Tab` |

## 링크 팝업

링크를 클릭하면 편집 팝업이 표시됩니다. 커서는 클릭한 위치에 그대로 남으므로 링크 텍스트를 계속 편집할 수 있습니다 — 입력, `Backspace`, 복사/붙여넣기 모두 문서에 적용됩니다. 텍스트를 편집하거나 커서를 링크 밖으로 옮기면 팝업이 바로 닫힙니다.

### 기존 링크 편집

**트리거:** 링크 클릭, 또는 링크 안에 커서 위치 + `Mod + K`

클릭하면 키보드 입력은 문서에 그대로 남습니다. 링크 대상을 편집하려면 URL 필드를 클릭하세요. `Mod + K`는 포커스를 URL 필드로 바로 옮깁니다.

**필드:**
- **URL** — 링크 대상 편집
- **대상 열기** — 외부 URL은 브라우저에서 열고, `#bookmark` 링크는 제목으로 이동하며, 파일 간 링크는 로컬 파일을 새 탭에서 엽니다
- **복사** — URL을 클립보드에 복사
- **삭제** — 링크 제거, 텍스트 유지

**팝업 없이 열기:** 링크 위에서 `Cmd + Click`(Windows/Linux에서는 `Ctrl + Click`)하면 대상이 바로 열립니다.

### 새 링크 만들기

**트리거:** 텍스트 선택 + `Mod + K`

**스마트 클립보드:** 클립보드에 URL이 있으면 자동으로 채워집니다.

**필드:**
- **URL 입력** — 대상 입력
- **확인** — Enter 누르거나 ✓ 클릭
- **취소** — Escape 누르거나 ✗ 클릭

### 소스 모드

- **`Cmd + Click`** (Windows/Linux에서는 `Ctrl + Click`) 링크 위 → 외부 URL은 브라우저에서 열기, `#bookmark` 링크는 제목으로 이동, 로컬 파일 경로는 새 탭에서 파일 열기
- **Click** `[text](url)` 구문 위 → 편집 팝업 표시, 커서는 마크다운 안에 남아 있어 계속 입력 가능
- **`Mod + K`** 링크 안 → URL 필드에 포커스가 있는 편집 팝업 표시

::: tip 북마크 링크
`#`으로 시작하는 링크는 북마크 (내부 제목 링크)로 처리됩니다. 열기는 브라우저를 열지 않고 제목으로 이동합니다.
:::

::: tip 파일 간 링크
로컬 파일을 가리키는 링크는 대상 파일을 새 탭에서 열며, 링크에 `#fragment`가 있으면 해당 제목 위치로 이동합니다. `../appendix/cards.md`나 `./notes.md` 같은 상대 경로는 현재 문서의 디렉터리를 기준으로 해석됩니다. 절대 경로(macOS/Linux의 `/Users/me/notes/a.md`, Windows의 `C:\notes\a.md`)는 지정한 파일을 그대로 엽니다. 네트워크 경로(`\\server\share\…`)는 링크에서 열리지 않습니다. 제목 없는 문서에서는 절대 경로만 열 수 있습니다.
:::

## 제목 선택기 (북마크 링크)

**트리거:** `Alt + Mod + B`(북마크 링크), **삽입 → 링크 → 북마크**, 또는 범용 도구 모음의 링크 그룹

북마크 링크는 같은 문서의 제목을 가리킵니다(`[text](#heading-id)`). 앵커를 직접 입력하는 대신, 선택기는 문서의 모든 제목을 수준별로 들여쓰기하여 나열하고 맨 위에 필터 필드를 표시합니다.

**동작:**
- `↑`/`↓`로 목록을 이동하고, `Enter`로 링크를 삽입하며, `Escape`로 닫습니다
- 텍스트를 선택한 상태라면 선택 영역이 링크 텍스트가 되고, 선택 영역이 없으면 제목 자체의 텍스트가 링크로 삽입됩니다
- 문서에 제목이 없거나 필터와 일치하는 항목이 없으면 팝업에 그렇게 표시됩니다

## 미디어 팝업 (이미지, 비디오, 오디오)

모든 미디어 유형 — 이미지, 비디오, 오디오 — 편집을 위한 통합 팝업.

### 편집 팝업

**트리거:** 미디어 요소 더블클릭 (이미지, 비디오, 또는 오디오)

**공통 필드 (모든 미디어 유형):**
- **소스** — 파일 경로 또는 URL

**유형별 필드:**

| 필드 | 이미지 | 비디오 | 오디오 |
|------|-------|-------|-------|
| 대체 텍스트 | 예 | — | — |
| 제목 | — | 예 | 예 |
| 포스터 | — | 예 | — |
| 치수 | 읽기 전용 | — | — |
| 인라인/블록 토글 | 예(링크된 이미지 제외) | — | — |

**버튼:**
- **찾아보기** — 파일 시스템에서 파일 선택
- **복사** — 소스 경로를 클립보드에 복사
- **삭제** — 미디어 요소 제거

**단축키:**
- `Mod + Shift + I` — 새 이미지 삽입
- `Enter` — 변경 사항 저장
- `Escape` — 팝업 닫기

### 소스 모드

소스 모드에서 `![alt](path)` 이미지 구문을 클릭하면 동일한 미디어 팝업이 열립니다.

소스 모드는 미디어의 플로팅 **미리보기**도 표시합니다 — 이미지, 또는 기본 재생 컨트롤이 있는 비디오나 오디오 플레이어입니다. 커서가 `![alt](path)` 안에 있을 때(선택한 텍스트 없이)와 마우스를 구문 위에 올렸을 때 나타나며, 커서의 미리보기가 호버 미리보기보다 우선합니다. 경로는 인식되는 이미지, 비디오 또는 오디오 확장자로 끝나야 합니다(또는 `data:image/` URL이어야 합니다). 미디어 팝업이 열려 있는 동안에는 미리보기가 숨겨집니다.

## 이미지 컨텍스트 메뉴

WYSIWYG 모드에서 이미지를 오른쪽 클릭하면 빠른 작업이 포함된 컨텍스트 메뉴가 열립니다 (더블클릭 편집 팝업과 별도).

**트리거:** 이미지에서 오른쪽 클릭

**동작:**
| 동작 | 설명 |
|------|------|
| 이미지 변경 | 이미지를 교체할 파일 선택기 열기 |
| 이미지 삭제 | 문서에서 이미지 제거 |
| 경로 복사 | 이미지 소스 경로를 클립보드에 복사 |
| Finder에서 표시 | 파일 관리자에서 이미지 파일 위치 열기 (플랫폼에 따라 레이블 변경) |

`Escape`를 눌러 작업 없이 컨텍스트 메뉴를 닫습니다.

## 수식 팝업

실시간 미리보기로 LaTeX 수식 표현식을 편집합니다.

**트리거:**
- **WYSIWYG:** 인라인 수식 `$...$` 클릭
- **소스:** 비어 있지 않은 `$...$`, `$$...$$` 블록, 또는 ` ```latex ` / ` ```math ` 블록 내에 커서 위치

**필드:**
- **LaTeX 입력** — 수식 표현식 편집
- **미리보기** — 실시간 렌더링 미리보기
- **오류 표시** — 도움이 되는 구문 힌트와 함께 LaTeX 오류 표시

**단축키:**
- `Mod + Enter` — 저장 및 닫기
- `Click outside` — 저장 및 닫기 (편집 내용 확정)
- `Escape` — 취소 및 닫기 (편집 내용 폐기)
- `Shift + Backspace` — 인라인 수식 삭제 (비어 있지 않을 때도 작동, WYSIWYG 전용)
- `Alt + Mod + M` — 새 인라인 수식 삽입

::: tip 오류 힌트
LaTeX 구문 오류가 있으면 팝업이 누락된 중괄호, 알 수 없는 명령, 불균형 구분자 등 도움이 되는 제안을 표시합니다.
:::

::: info 소스 모드
소스 모드에서도 WYSIWYG 모드와 동일한 편집 가능한 수식 팝업을 제공합니다 — LaTeX 입력을 위한 텍스트 영역과 아래에 실시간 KaTeX 미리보기가 표시됩니다. 커서가 수식 구문(비어 있지 않은 `$...$`, `$$...$$`, 또는 ` ```latex ` / ` ```math `) 안에 들어가면 팝업이 자동으로 열립니다. `Mod + Enter`로 저장하거나 `Escape`로 취소합니다. 줄 끝에 입력한 빈 `$$`는 일반 텍스트로 처리되며 — 입력 중인 블록 수식 구분자일 가능성이 높으므로 — 팝업을 열지 않습니다.
:::

## 각주 팝업

각주 내용을 인라인으로 편집합니다.

**트리거:**
- **WYSIWYG:** 각주 참조 `[^1]` 위에 마우스 올리기
- **소스:** 각주 참조나 각주 정의 위에 마우스를 올리거나 클릭

**필드:**
- **내용** — 여러 줄 각주 텍스트 (자동 크기 조정)
- **정의로 이동** — 각주 정의로 이동
- **삭제** — 각주 제거

**동작:**
- 새 각주는 내용 필드에 자동 포커스
- 입력하면 텍스트 영역이 확장됨

## 위키 링크 팝업

내부 문서 연결을 위한 위키 스타일 링크를 편집합니다.

**트리거:**
- **WYSIWYG:** `[[target]]` 위에 마우스 올리기 (300ms 지연)
- **소스:** 위키 링크 구문 클릭

**필드:**
- **대상** — 워크스페이스 상대 경로 (`.md` 확장자 자동 처리)
- **찾아보기** — 워크스페이스에서 파일 선택
- **열기** — 연결된 문서 열기
- **복사** — 대상 경로 복사
- **삭제** — 위키 링크 제거

## 표 컨텍스트 메뉴

빠른 표 편집 동작.

**트리거:**
- **WYSIWYG:** 표 셀에서 오른쪽 클릭 (같은 동작을 툴바와 키보드 단축키로도 사용할 수 있음)
- **소스:** 표 셀에서 오른쪽 클릭

**동작:**
| 동작 | 설명 |
|------|------|
| 위/아래에 행 삽입 | 커서 위치에 행 추가 |
| 왼쪽/오른쪽에 열 삽입 | 커서 위치에 열 추가 |
| 행 삭제 | 현재 행 제거 |
| 열 삭제 | 현재 열 제거 |
| 표 삭제 | 전체 표 제거 |
| 열 왼쪽/가운데/오른쪽 정렬 | 현재 열의 정렬 설정 |
| 모두 왼쪽/가운데/오른쪽 정렬 | 모든 열의 정렬 설정 |
| 표 서식 | 표 열 자동 정렬 (마크다운 미화) |
| 너비에 맞춤 / 원래 너비 | WYSIWYG 전용: 내용에 비례하는 열 너비로 이 표를 에디터 너비에 고정하거나, 원래 너비로 되돌림 |

## 맞춤법 검사 팝업

제안 사항으로 맞춤법 오류를 수정합니다.

**트리거:**
- 잘못 쓴 단어 (빨간 밑줄) 오른쪽 클릭

**동작:**
- **제안 사항** — 클릭하여 제안으로 대체
- **사전에 추가** — 더 이상 잘못 쓴 것으로 표시하지 않음

## 드래그로 텍스트 이동

WYSIWYG 모드에서는 마우스로 선택 영역을 이동할 수 있습니다. 선택한 텍스트를 누르고 드래그한 다음 — 놓일 위치가 드롭 커서로 표시됩니다 — 놓으면 됩니다. 이동은 한 번에 실행 취소할 수 있는 단일 단계입니다(`Mod + Z`로 되돌림). 드래그 중에 `Escape`를 누르거나 창이 포커스를 잃으면 취소됩니다. 데스크톱 셸이 브라우저의 기본 드래그 이벤트를 가로채기 때문에 VMark가 이 기능을 직접 구현하며, 그래서 시스템 드래그 앤 드롭이 아니라 마우스 제스처로 동작합니다.

## 팝업 탐색 팁

### 포커스 흐름
1. 팝업이 첫 번째 입력에 포커스를 맞추고 열립니다
2. `Tab`이 필드와 버튼을 앞으로 이동합니다
3. `Shift + Tab`이 뒤로 이동합니다
4. 포커스가 팝업 안에서 순환합니다

### 빠른 편집
- 간단한 URL 변경의 경우: 편집 후 `Enter` 누르기
- 취소의 경우: 어떤 필드에서든 `Escape` 누르기
- 여러 줄 내용 (각주, 수식)의 경우: 저장하려면 `Mod + Enter` 사용

### 마우스 동작
- 팝업 외부를 클릭하면 닫힙니다. 기본 동작은 저장하지 않은 변경 사항을 **폐기**하는 것입니다. 수식 팝업은 예외로, 외부를 클릭하면 편집 내용을 **확정**합니다([수식 팝업](#수식-팝업) 섹션 참고).
- 호버 팝업 (각주, 위키)은 표시 전 300ms 지연이 있습니다
- 마우스를 팝업으로 돌아가면 열린 상태 유지
