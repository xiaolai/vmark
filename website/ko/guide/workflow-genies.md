# 워크플로 지니

**워크플로 지니**는 지니 폴더에 `.yml` 또는 `.yaml` 파일로 저장된 [지니 워크플로](/ko/guide/workflows)(다단계 YAML 파이프라인)입니다. 마크다운 지니와 똑같이 지니 피커(`Mod + Y`)와 **편집 → 지니**에 표시되며, 선택하면 단일 프롬프트를 보내는 대신 워크플로 엔진을 통해 파이프라인 전체를 실행합니다.

## 요구 사항

| 요구 사항 | 이유 |
|-------------|-----|
| **설정 → 고급 → 개발자 도구**를 켠 다음 **워크플로 엔진** 켜기 | 엔진은 기본적으로 꺼져 있습니다. 엔진이 꺼져 있어도 피커에는 워크플로 지니가 계속 표시되지만, 실행하면 "워크플로 엔진이 설정에서 꺼져 있습니다" 오류와 함께 실패합니다 |
| 열린 워크스페이스 | `action/save-file` 같은 액션 단계는 워크스페이스 루트를 기준으로 경로를 해석합니다. 워크스페이스가 없으면 VMark는 토스트를 표시하고 실행을 시작하지 않습니다 |
| 구성된 [AI 제공자](/ko/guide/ai-providers) | 지니 단계는 마크다운 지니와 같은 활성 제공자를 호출합니다 |

## 작성하기

YAML 파일을 지니 폴더(**편집 → 지니 → 지니 폴더 열기**) 아래 아무 곳에나 두세요. 마크다운 지니와 마찬가지로 하위 폴더는 카테고리가 됩니다. 피커는 파일 이름을 지니 이름으로, YAML의 `description`(없으면 `name`)을 보조 줄로 표시합니다. 워크플로 지니의 범위는 문서 전체입니다. 실행에는 작업할 선택 영역이 없으므로 각 단계가 자체 `with: { input: … }`를 제공하며, 호출되는 마크다운 지니는 이를 변경 없이 `{{content}}` 자리 표시자에 바인딩합니다.

번들된 `triage-and-translate.yml` 샘플을 바로 출발점으로 쓸 수 있습니다. 폴더에 복사한 다음 시드 텍스트를 바꾸세요. 샘플의 위치, 전체 YAML 스키마, 표현식, 승인, 단계별 모델과 시간 제한은 모두 [지니 워크플로](/ko/guide/workflows)에 설명되어 있으며, 워크플로 지니의 실행은 평소처럼 진행되고 승인 대화상자도 나타나지만, 실시간 단계 그래프는 표시되지 않으며 워크플로 패널에서 취소할 수도 없습니다(실행 중에는 패널의 실행이 엔진이 사용 중이라고 알립니다). 또한 패널은 이 실행에 대해 "파일 복원"을 제공하지 않습니다.

단일 프롬프트 마크다운 지니 형식은 [AI 지니](/ko/guide/ai-genies)를 참고하세요.
