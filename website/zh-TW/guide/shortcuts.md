# 鍵盤快捷鍵

VMark 以鍵盤優先的工作流程設計。大多數快捷鍵均可在設定中自訂。少數基本快捷鍵為固定值：多重游標選擇器 `Mod+D`（選取下一個符合項目）與 `Mod+Shift+L`（選取所有符合項目），以及全域的還原/重做綁定。其他多重游標快捷鍵（跳過符合項目、軟性還原游標、在上方/下方新增游標）均可自訂。標示為 _(情境感知)_ 的快捷鍵由編輯器內部針對特定結構處理（例如切換任務核取方塊），不會出現在自訂註冊表中。

## 符號說明

- **Mod** = macOS 上的 Cmd，Windows/Linux 上的 Ctrl
- **Alt** = macOS 上的 Option

## macOS 上的功能鍵

VMark 使用功能鍵（F2–F10）進行快速模式切換。在 macOS 上，這些鍵預設對應至系統功能（亮度、音量等）。

**不按住 Fn 鍵直接使用 F 鍵：**

1. 開啟 **系統設定** → **鍵盤**
2. 啟用 **「將 F1、F2 等鍵用作標準功能鍵」**

或者，按住 **Fn** 鍵再按 F2–F10，以觸發 VMark 快捷鍵。

::: tip
如果你偏好將系統功能保留在 F 鍵上，可以在設定（`Mod + ,`）中自訂 VMark 快捷鍵，使用不同的按鍵組合。
:::

在 Windows 和 Linux 上，切換隱藏檔案使用 `Ctrl + H`。

在 Windows 和 Linux 上，切換側邊欄使用 `Alt + Shift + 0`，因為在那裡 `Mod` 就是 Ctrl——macOS 的組合鍵 `Ctrl + Shift + 0` 會與段落的 `Mod + Shift + 0` 衝突。

::: tip 新增瀏覽器分頁
`Alt + Mod + Shift + B` 會開啟一個內嵌瀏覽器分頁，此命令也出現在**檔案**選單中。在 macOS 上，內嵌瀏覽器預設為開啟；若你在**設定 → 進階 → 內嵌瀏覽器**中將它關閉，該選單項目會被隱藏（而非變灰），直到你重新開啟為止。瀏覽器僅支援 macOS，因此該項目永遠不會出現在 Windows 或 Linux 上。

它是一個真正的選單項目，而不只是鍵盤綁定，這一點很重要：一旦網頁取得鍵盤焦點，瀏覽器引擎會在 VMark 看到按鍵之前就先攔下，因此應用程式內的快捷鍵無法觸發。選單快速鍵則由 macOS 本身派送，所以在你瀏覽網頁時仍然有效。
:::

## 智慧 Tab 導覽

Tab 和 Shift+Tab 具有情境感知功能——可在括號、引號、格式標記與連結之間快速跳脫。

| 情境 | Tab 操作 |
|------|----------|
| 位於 `)`、`]`、`}`、引號之前 | 跳過右括號字元 |
| 位於中日韓文括號 `」`、`』` 等之前 | 跳過右括號 |
| 位於 **粗體**、*斜體*、`程式碼` 之內 | 跳至格式之後 |
| 位於連結之內 | 跳至連結之後 |

| 情境 | Shift+Tab 操作 |
|------|----------------|
| 位於 `(`、`[`、`{`、引號之後 | 跳至左括號之前 |
| 位於中日韓文括號 `「`、`『` 等之後 | 跳至左括號之前 |
| 位於 **粗體**、*斜體*、`程式碼` 之內 | 跳至格式之前 |
| 位於連結之內 | 跳至連結之前 |

::: tip
完整指南請參閱[智慧 Tab 導覽](/zh-TW/guide/tab-navigation)，包含中日韓文括號、彎引號與設定說明。
:::

## 終端機

當整合終端機取得焦點時：

| 操作 | 快捷鍵 |
|------|--------|
| 切換終端機 | `` Ctrl + ` `` |
| 聚焦終端機或編輯器 | `` Ctrl + Shift + ` ``（Windows/Linux 上為 `` Alt + Shift + ` ``） |
| 複製 | `Mod + C`（有選取範圍時）；Linux 上也可用 `Ctrl + Shift + C` 或 `Ctrl + Insert` |
| 貼上 | `Mod + V`；Linux 上也可用 `Ctrl + Shift + V` 或 `Shift + Insert` |
| 全選（僅限終端機輸出） | `Mod + A`（Linux 上為 `Ctrl + Shift + A`） |
| 清除 | `Mod + K`（Linux 上為 `Ctrl + Shift + K`） |
| 搜尋 | `Mod + F`（Linux 上為 `Ctrl + Shift + F`） |
| 切換至工作階段 1–5 | `Mod + 1` 至 `Mod + 5` |
| 放大終端機字型 | `Mod + =` |
| 縮小終端機字型 | `Mod + -` |
| 終端機字型恢復預設大小 | `Mod + 0` |
| 上一個命令提示字元 | `Mod + ↑` |
| 下一個命令提示字元 | `Mod + ↓` |
| 在輸入列中換行（Claude Code 及類似工具） | `Shift + Enter` |

當終端機取得焦點時，`Mod + =`、`Mod + -` 和 `Mod + 0` 會調整終端機的字型大小，而非編輯器的字型大小。

提示字元導覽會在捲動緩衝區中的命令提示字元之間跳轉，需要 Shell 整合（zsh 或 bash）。

在 macOS 上，終端機也會將常用的文字編輯組合鍵轉換給 Shell：

| 操作 | 快捷鍵 |
|------|--------|
| 向左 / 向右移動一個單字 | `Option + ←` / `Option + →` |
| 移至行首 / 行尾 | `Cmd + ←` / `Cmd + →` |
| 刪除輸入列（傳送 `Ctrl + U`） | `Cmd + Backspace` |

在 macOS 上，`Ctrl + A`、`Ctrl + R` 和 `Ctrl + W` 等 `Ctrl` 組合鍵會直接傳送給 Shell。

在 Linux 上，終端機遵循 Linux 終端機的慣例：單純的 `Ctrl` + 字母組合鍵交給 Shell，因此 `Ctrl + A`、`Ctrl + E`、`Ctrl + K`、`Ctrl + F`、`Ctrl + U`、`Ctrl + W` 等 readline 按鍵與其他 Linux 終端機中一樣可用；終端機本身的操作改用 `Ctrl + Shift`：`Ctrl + Shift + A` 全選，`Ctrl + Shift + K` 清除，`Ctrl + Shift + F` 搜尋，`Ctrl + Shift + C` / `Ctrl + Shift + V` 複製和貼上。`Ctrl + Insert` 和 `Shift + Insert` 也能複製和貼上。有兩個單純的 `Ctrl` 組合鍵仍由終端機處理：`Ctrl + C` 複製選取內容（沒有選取範圍時傳送 SIGINT），`Ctrl + V` 貼上。`Ctrl + 1` 至 `Ctrl + 5` 仍用於切換工作階段。

當終端機搜尋列開啟時：

| 操作 | 快捷鍵 |
|------|--------|
| 下一個符合項目 | `Enter` |
| 上一個符合項目 | `Shift + Enter` |
| 關閉搜尋 | `Escape` |

::: tip
`Mod + C` 在沒有選取範圍時，會向正在執行的程序傳送 SIGINT。完整指南請參閱[整合終端機](/zh-TW/guide/terminal)。
:::

## 自訂快捷鍵

1. 使用 `Mod + ,` 開啟設定
2. 導覽至 **快捷鍵** 分頁（在搜尋框中輸入文字，即可依名稱、類別、說明或按鍵篩選）
3. 點選快捷鍵旁顯示的按鍵——若尚未設定按鍵，則點選 **未指派**
4. 按下你想要的按鍵組合，然後點選 **指定**（`Escape` 可取消）

在你指定組合鍵之前，對話框會先發出警告：

- **衝突**——該組合鍵已被另一個快捷鍵使用，對話框會列出其名稱。你仍可選擇 **仍要指定**。
- **不支援**——VMark 無法使用該組合鍵，因此無法指定。請換一個。

已自訂的快捷鍵會以醒目方式標示，並提供 **重設為預設值** 按鈕。**全部重設** 會在確認後恢復所有預設值。**匯出** 會將你的快捷鍵儲存為 JSON 檔案（`vmark-shortcuts.json`），**匯入** 則會載入此類檔案；若檔案中有任何項目無效，將不會匯入任何內容，並列出問題所在。

::: tip
快捷鍵在適用時會與選單快捷鍵同步，因此選單項目會顯示你自訂的快捷鍵。
:::
