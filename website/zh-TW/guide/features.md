# 功能特色

VMark 是人類與 AI 協作的純文字工作區。Markdown 是核心（提供所見即所得、原始碼預覽與原始碼模式），但工作區也能開啟 YAML、JSON、TOML、Mermaid、SVG、HTML 以及 9 種程式碼檢視器格式——完整清單請參閱[支援的格式](/zh-TW/guide/formats)。

## 編輯模式

### 富文字模式（所見即所得）

預設的編輯模式提供真正的「所見即所得」體驗：

- 輸入時即時格式預覽
- 游標懸停時顯示行內語法
- 直觀的工具列與右鍵選單
- 無縫的 Markdown 語法輸入

### 原始碼模式

切換至帶有完整語法高亮的原始 Markdown 編輯：

- 由 CodeMirror 6 驅動的編輯器
- 完整語法高亮
- 互動式彈窗，支援數學、連結、圖片、Wiki 連結與媒體——與 WYSIWYG 相同的編輯體驗
- 智慧貼上——來自網頁和 Word 文件的 HTML 自動轉換為乾淨的 Markdown
- 剪貼簿圖片貼上——截圖和複製的圖片會儲存至資產資料夾，並以 `![](path)` 插入
- 具備程式碼圍欄感知的多重游標，支援 CJK 分詞
- 適合進階使用者

使用 `F6` 在兩種模式之間切換。

### 分割檢視（原始碼 + 預覽）

在左側編輯原始 Markdown，右側則有**即時、唯讀的所見即所得預覽**同步更新——預覽*就是*所見即所得渲染器，因此它永遠不會與你在富文字模式中看到的內容產生落差。格式指令與工具列作用於原始碼窗格；拖曳分隔線（或在分隔線上使用方向鍵）即可調整大小。

- 以 `Shift + F6`、**檢視 → Markdown 分割檢視**或命令面板（「切換 Markdown 分割檢視」）依工作階段切換
- 在**設定 → Markdown → 版面 → 預設分割原始碼/預覽**中將它設為 Markdown 檔案的預設值

所見即所得仍是預設值；分割檢視需選擇性啟用。這三種檢視互斥——`F6` 切換原始碼、`Shift + F6` 切換分割，兩者都會回到所見即所得——因此在它們之間切換永遠只需一次按鍵。

**檢視**選單以帶勾選標記的群組顯示這三種模式——**所見即所得模式**、**原始碼模式**、**Markdown 分割檢視**——因此目前的模式永遠清楚可見，互斥關係也一目了然。**自動換行**與**行號**只適用於原始碼編輯器，因此在所見即所得模式中會呈現灰色。

### 閱讀位置

離開文件後，你在文件中的位置會被保留。切換到另一個分頁再回來、切換原始碼模式或分割檢視，或檔案從磁碟重新載入，都會讓你回到原本閱讀的位置——而不是回到頂端。

每個介面各自記住自己的位置，因此富文字與原始碼在同一個檔案中保有各自的位置。回到同一個介面時（切換分頁，或檔案重新載入），即使游標在別處，也會回到你上次捲動到的位置；游標則留在你放下它的地方。在富文字與原始碼之間切換時，若有游標則以游標為準，因為正是游標讓同一段落在兩種介面之間保持在視野中。

位置依文件與工作階段分別記錄——關閉分頁即會遺忘。

### 跨模式復原

復原與重做可跨越所見即所得 ⇄ 原始碼的邊界。每次切換模式都會記錄一個檢查點，當目前編輯器自身的歷史記錄用盡時，`Mod + Z` 會繼續沿著這些檢查點往回——還原先前的內容，但不會切換你目前所在的檢視。重做沿著同一條鏈往前；若你已透過新的編輯放棄了某個分支，對該分支的重做會被拒絕，而不會覆蓋你的工作。這條鏈依分頁保存，並在分頁關閉時清除。

### 大型檔案

VMark 會自動以原始碼模式開啟超過 1 MB 的檔案，以在一秒內完成開啟；在處理超過 5 MB 的檔案前會發出警告；並拒絕開啟超過 50 MB 的檔案。門檻與設定請參閱[大型檔案](./large-files.md)指南。

### 原始碼預覽

無需離開所見即所得模式，即可編輯單一區塊的原始 Markdown。按 `F5` 開啟游標所在區塊的原始碼預覽。

**版面配置：**
- 標頭列，顯示區塊類型標籤與操作按鈕
- CodeMirror 編輯器，顯示區塊的 Markdown 原始碼
- 原始區塊以淡化預覽的形式顯示（當即時預覽開啟時）

**控制項：**
| 操作 | 快捷鍵 |
|------|--------|
| 儲存變更 | `Cmd/Ctrl + Enter` |
| 取消（還原） | `Escape` |
| 切換即時預覽 | 點選眼睛圖示 |

**即時預覽：**
- **關閉（預設）：** 自由編輯，變更僅在儲存時套用
- **開啟：** 輸入時立即套用變更，預覽顯示於下方

**排除的區塊：**
某些區塊有自己的編輯機制，不適用原始碼預覽：
- 程式碼區塊（包括 Mermaid、LaTeX）——雙擊以編輯
- 區塊圖片——使用圖片彈出視窗
- 前置資料、HTML 區塊、水平線

原始碼預覽適合在視覺編輯器中進行精確的 Markdown 編輯（修正表格語法、調整清單縮排）。

## 多重游標編輯

同時編輯多個位置——VMark 在所見即所得與原始碼模式中均支援完整的多重游標。

| 操作 | 快捷鍵 |
|------|--------|
| 在下一個符合項目新增游標 | `Mod + D` |
| 跳過符合項目，跳至下一個 | `Mod + Shift + D` |
| 選取所有符合項目 | `Mod + Shift + L` |
| 在上方/下方新增游標 | `Mod + Alt + 上/下` |
| 點擊新增游標 | `Alt + 點擊` |
| 還原上一個游標 | `Alt + Mod + Z` |
| 收合至單一游標 | `Escape` |

所有標準編輯操作（輸入、刪除、剪貼簿、導覽）都可在每個游標上獨立進行。在一般文字中，`Mod + D` 與 `Mod + Shift + L` 會搜尋整份文件；在程式碼區塊內則只在該區塊中搜尋。`Alt + Mod + Shift + L` 只會選取目前區塊內的所有符合項目。

[了解更多 →](/zh-TW/guide/multi-cursor)

## 智慧全選

在所見即所得模式中，`Mod + A` 會逐層擴大選取範圍，而不是直接跳到整份文件：在表格內，會依序選取儲存格、列、表格，最後是整份文件。`Mod + Z` 可退回一層擴展，`Escape` 則將選取收合為游標。

在原始碼模式中，`Mod + A` 會先選取所在的區塊——程式碼圍欄、表格、引言或清單——然後才是整份文件；在此同樣可用 `Mod + Z` 退回一層擴展。

此按鍵綁定屬於編輯器本身，無法自訂。

## 自動配對與 Tab 跳脫

當你輸入左括號、引號或反引號時，VMark 會自動插入對應的右括號。按 **Tab** 可跳過右括號字元，無需移動至方向鍵。

- 括號：`()` `[]` `{}`
- 引號：`""` `''` `` ` ` ``
- 中日韓文：`「」` `『』` `（）` `【】` `《》` `〈〉`
- 彎引號：`""` `''`
- 所見即所得中的格式標記：**粗體**、*斜體*、`程式碼`、~~刪除線~~、連結

在配對為空時，Backspace 會刪除兩個字元。自動配對與 Tab 括號跳脫在 **程式碼區塊與行內程式碼內均停用**——程式碼中的括號保持字面形式。可在 **設定 → 編輯器** 中設定。

[了解更多 →](/zh-TW/guide/tab-navigation)

## 文字格式

### 基本樣式

- **粗體**、*斜體*、<u>底線</u>、~~刪除線~~
- `行內程式碼`、==高亮==
- 下標與上標
- 連結、Wiki 連結與書籤連結（含預覽彈出視窗）
- 腳注（支援行內編輯）
- HTML 注解切換（`Mod + /`）
- 清除格式指令

### 文字轉換

透過「格式 → 轉換」快速變更文字大小寫：

| 轉換 | 快捷鍵 |
|------|--------|
| 全部大寫 | `Ctrl + Shift + U`（macOS）/ `Alt + Shift + U`（Win/Linux） |
| 全部小寫 | `Ctrl + Shift + L`（macOS）/ `Alt + Shift + L`（Win/Linux） |
| 標題大小寫 | `Ctrl + Shift + T`（macOS）/ `Alt + Shift + T`（Win/Linux） |
| 大小寫切換 | — |

### 區塊元素

- 標題 1-6，支援快捷鍵（使用 `Mod + Alt + ]`/`[` 增減層級）
- 引言（支援巢狀）
- 帶語法高亮的程式碼區塊
- 有序、無序與任務清單
- 循環切換清單類型：將段落依序轉換為項目符號清單、編號清單或任務清單
- 關閉清單：再次點擊目前作用中的清單類型，即可移除清單格式
- 轉換為程式碼：程式碼區塊操作會把游標所在的整個清單——或任何跨多個區塊的選取範圍（段落、標題、清單）——轉換為單一程式碼區塊，每個區塊或清單項目各佔一行
- 水平線
- 表格（完整編輯支援）

### 強制換行

在段落內按 `Shift + Enter` 插入強制換行。VMark 預設使用雙空格格式以確保最大相容性。可在 **設定 > 編輯器 > 空白字元** 中設定。

### 行操作

透過「編輯 → 行」進行強大的行操作：

| 操作 | 快捷鍵 |
|------|--------|
| 向上移動行 | `Alt + 上` |
| 向下移動行 | `Alt + 下` |
| 複製行 | `Shift + Alt + 下` |
| 刪除行 | `Mod + Shift + K` |
| 合併行 | `Mod + J` |
| 移除空白行 | — |
| 升序排列行 | `F4` _（僅限原始碼模式）_ |
| 降序排列行 | `Shift + F4` _（僅限原始碼模式）_ |

排序作用於純文字行，因此僅在原始碼模式中提供。

## 表格

完整的表格編輯功能：

- 透過選單或快捷鍵插入表格
- 新增/刪除列與欄
- 儲存格對齊（靠左、置中、靠右）
- 欄寬依內容自動調整；過寬的表格可水平捲動
- 符合寬度——將表格固定為編輯器寬度，欄寬依內容比例分配（在設定 → Markdown 中設定，或透過右鍵對個別表格設定）
- 快速操作的右鍵工具列
- 鍵盤導覽——`Tab` / `Shift + Tab` 在儲存格間移動，方向鍵在表格邊緣時會離開表格，`Mod + Enter` / `Mod + Shift + Enter` 在下方 / 上方新增一列

## 圖片

完整的圖片支援：

- 透過檔案對話框插入
- 從檔案系統拖放
- 從剪貼簿貼上
- 自動複製至專案資產資料夾
- 雙擊編輯來源路徑與替代文字——圖片的尺寸以唯讀方式顯示
- 按右鍵可使用變更圖片、刪除圖片、複製路徑與在 Finder 中顯示（Windows 上為在檔案總管中顯示，Linux 上為在檔案管理員中顯示）
- 切換行內與區塊顯示

## 影片與音訊

使用 HTML5 標籤的完整媒體支援：

- 透過工具列檔案選擇器插入影片和音訊
- 拖放媒體檔案至編輯器
- 自動複製至專案的 `.assets/` 資料夾
- 點擊編輯來源路徑、標題與封面圖（影片）
- YouTube 嵌入支援，使用隱私增強型 iframe
- 圖片語法自動升級：`![](file.mp4)` 自動升級為影片
- 原始碼模式中，以類型專用彩色邊框裝飾
- [了解更多 →](/zh-TW/guide/media-support)

## Frontmatter 面板

在 WYSIWYG 模式中直接編輯 YAML frontmatter，無需切換至原始碼模式。

- **預設收合**——當文件包含 frontmatter 時，文件頂部會顯示一個小型「Frontmatter」標籤
- **點擊展開**——開啟純文字編輯器以編輯 YAML 內容
- **`Mod + Enter`**——儲存變更並收合面板
- **`Escape`**——還原至上次儲存的值並收合
- **失焦自動儲存**——點擊其他區域時，變更會在短暫延遲後自動儲存

面板會在編輯器歷史記錄中建立一個復原點，因此隨時可以用 `Mod + Z` 復原 frontmatter 變更。

## 特殊內容

### 資訊框

GitHub 風格 Markdown 提示框：

- NOTE - 一般資訊
- TIP - 實用建議
- IMPORTANT - 重要資訊
- WARNING - 潛在問題
- CAUTION - 危險操作

### 可折疊段落

使用 `<details>` HTML 元素建立可展開的內容區塊。

### 數學公式

KaTeX 驅動的 LaTeX 渲染：

- 行內數學：`$E = mc^2$`
- 展示數學：`$$...$$` 區塊
- ChatGPT 風格的分隔符號會在開啟或貼上時被辨識，並正規化為 `$` 形式：`\( ... \)` 會變成行內數學，獨立成行的 `\[ ... \]` 會變成展示區塊
- `$$` 區塊必須在空白行之前結束（pandoc 的規則）——未結束的 `$$` 會以字面文字呈現，而不會吞掉其後的段落。結束符號正前方的空白行沒有問題（空的 `$$` … `$$` 區塊仍是數學區塊）
- 完整 LaTeX 語法支援
- 帶有語法提示的友善錯誤訊息

### 圖表

支援即時預覽的 Mermaid 圖表：

- 流程圖、序列圖、甘特圖
- 類別圖、狀態圖、ER 圖
- 原始碼模式中的即時預覽面板（可拖曳、調整大小、縮放）
- [了解更多 →](/zh-TW/guide/mermaid)

支援相同預覽介面的 Graphviz DOT：

- ` ```dot ` 與 ` ```graphviz ` 圍欄區塊在本機渲染（WASM）
- 與 Mermaid 圖表相同的平移、縮放與 PNG 匯出
- [了解更多 →](/zh-TW/guide/graphviz)

### SVG 圖形

透過 ` ```svg ` 程式碼區塊行內渲染原始 SVG：

- 即時渲染，支援平移、縮放與 PNG 匯出
- 在所見即所得與原始碼模式中均支援即時預覽
- 適合 AI 生成的圖表與自訂插圖
- [了解更多 →](/zh-TW/guide/svg)

### 行內目錄

在單獨一行輸入 `[TOC]`，或選擇 **插入 → 目錄**，即可插入即時更新的目錄（此選單項目沒有預設快捷鍵；可在 設定 → 快捷鍵 中指定）：

- 依文件標題自動產生，並正確呈現巢狀層級
- 點擊任一標題即可直接捲動至該處
- 編輯時即時更新
- 可在所見即所得與匯出（HTML/PDF）中渲染，並可在原始碼模式中完整往返轉換

## 搜尋與取代

使用 `Mod + F` 開啟尋找列。它會在視窗底部的列中開啟，在所見即所得與原始碼模式中均可使用。

**導覽：**

| 操作 | 快捷鍵 |
|------|--------|
| 尋找下一個符合項目 | `Enter` 或 `Mod + G` |
| 尋找上一個符合項目 | `Shift + Enter` 或 `Mod + Shift + G` |
| 使用選取內容作為搜尋 | `Mod + E` |
| 關閉尋找列 | `Escape` |

**搜尋選項**——透過尋找列中的按鈕切換：

- **區分大小寫**——符合確切的字母大小寫
- **全字符合**——僅符合完整單字，不符合子字串
- **正規表示式**——使用 regex 模式（需先在設定中啟用）

**取代：**

取代欄位位於尋找欄位旁——兩者始終可見，按 `Tab` 即可從一個欄位移到另一個。輸入取代文字，然後使用 **取代**（單一符合）或 **全部取代**（一次取代所有符合）。符合計數器顯示當前位置與總數（如「3 / 12」），讓你隨時掌握位置。

## Markdown 檢查

VMark 內建 Markdown 語法檢查器，可檢查文件中常見的語法錯誤和無障礙問題。在 **設定 > Markdown > 檢查** 中啟用。

**使用方式：**

| 操作 | 快捷鍵 |
|------|--------|
| 執行檢查 | `Alt + Mod + V` |
| 跳至下一個問題 | `F2` |
| 跳至上一個問題 | `Shift + F2` |

執行檢查後，診斷結果以行內高亮和邊欄標記的形式顯示。如果沒有發現問題，會彈出通知確認文件無誤。問題分為錯誤和警告兩類。

**檢查規則（共 13 條）：**

- 未定義的參考連結
- 表格欄數不一致
- 連結語法倒寫 `(text)[url]`（應為 `[text](url)`）
- 標題 `#` 後缺少空格
- 強調標記內部有空格
- 連結文字或連結 URL 為空
- 重複的連結/圖片定義
- 未使用的連結/圖片定義
- 標題層級跳級（如從 H1 到 H3）
- 圖片缺少替代文字（無障礙）
- 未關閉的圍欄程式碼區塊
- 無效的片段連結（`#anchor` 與任何標題不符合）

檢查結果不會在輸入時更新。在原始碼模式中，編輯文件會清除結果。在所見即所得模式中，編輯會移除高亮標記，但狀態列中的問題數量以及 `F2` / `Shift + F2` 的跳轉目標會保留上次執行的結果，直到你再次執行檢查或關閉分頁為止。可隨時使用 `Alt + Mod + V` 重新執行檢查。

## 通用工具列

固定在編輯器底部的格式化工具列，在所見即所得與原始碼模式下均可快速存取所有格式化操作。

- **切換：** `Mod + Shift + B` 開啟工具列並取得焦點。再次按下可在保持工具列可見的同時將焦點返回編輯器。
- **鍵盤導覽：** 使用 `左`/`右` 方向鍵在群組之間移動。`Enter` 或 `Space` 開啟下拉選單。方向鍵在選單內導覽。
- **兩步 Escape：** 如果下拉選單已開啟，`Escape` 先關閉選單。再次按 `Escape` 關閉整個工具列。
- **工作階段記憶：** 工具列記住目前工作階段中最後取得焦點的按鈕，重新取得焦點時從上次位置繼續。
- **AI 精靈捷徑：** 工具列包含一個 AI 精靈按鈕，可開啟精靈選擇器（`Mod + Y`）。

## 編輯器右鍵選單

在編輯器中的任何位置（所見即所得或原始碼模式）按右鍵，即可開啟包含常用操作的右鍵選單。

- **剪貼簿：** 剪下、複製、貼上與全選。在 macOS 上，這些操作使用原生剪貼簿管線，因此貼上豐富內容（例如從瀏覽器複製的 HTML）時會保留其格式——與 `Mod + V` 完全相同。
- **行內格式：** 粗體、斜體、刪除線與行內程式碼，以勾選標記顯示游標處作用中的標記。
- **區塊操作：** 標題層級與清單類型子選單、引言與程式碼區塊——勾選標記反映目前的區塊。
- **連結：** 在一般文字上提供插入連結；在既有連結上，此區段會換成編輯連結、複製連結與移除連結。
- **情境感知：** 在表格內會改為顯示專用的表格選單；在圖片上按右鍵會開啟圖片選單；在程式碼區塊內只提供剪貼簿操作。非 Markdown 檔案（JSON、YAML…）則會顯示精簡的純剪貼簿選單。
- **選取處理：** 在選取範圍內按右鍵會保留選取；在其他位置按右鍵則會先將游標移到該處（macOS 慣例）。
- **鍵盤：** 方向鍵用於導覽（會略過停用的項目），`右`/`左` 進入與離開子選單，`Escape` 先關閉子選單，再關閉選單。快捷鍵提示會反映你自訂的按鍵綁定。

## 命令面板

按 `Mod + Shift + P` 開啟命令面板。查詢為空時，它會依類別分組列出所有可用指令——檔案、工作區、檢視、匯出、格式、標題、清單、表格、行、選取、轉換、CJK、檢查、歷史記錄、AI 等等；輸入文字即可依符合程度篩選與排序。`↑`/`↓` 移動，`Enter` 執行指令，`Escape`（或點擊背景）關閉。只會顯示目前適用的指令——沒有開啟文件時編輯器指令會消失，沒有工作區時工作區指令也會消失——而指令會在你開啟面板的那個視窗中執行。本指南各頁面會以引號標示其命令面板指令（「切換 Markdown 分割檢視」、「明細檢視」、「視窗狀態」）。命令面板沒有選單項目；其快捷鍵可在**設定 → 快捷鍵**中自訂。

## 文件歷史記錄

VMark 會自動儲存文件快照，方便你恢復到早期版本。

- 可設定間隔的**自動儲存**在背景中擷取快照
- **每份文件的獨立歷史記錄**儲存在本機 VMark 的應用程式資料資料夾中——一個索引檔，加上每個快照各一個 Markdown 檔
- 使用 `Ctrl + Shift + 3` 開啟歷史記錄側邊欄，瀏覽過去的版本
- 快照按**日期分組**，顯示每個版本儲存的確切時間戳記
- 點選任何快照旁的還原按鈕**還原**到先前版本（確認對話框防止意外還原）
- 使用垃圾桶按鈕**刪除**不再需要的個別快照
- 在任何還原之前，目前內容會儲存為新快照，因此你永遠不會遺失工作
- 歷史記錄要求文件已儲存為檔案（未命名文件沒有歷史記錄）
- 在 **設定 > 一般** 中啟用或停用歷史記錄追蹤

## 工作階段復原（Hot Exit）

當 VMark 為安裝更新而重新啟動，或程式意外結束時，你的工作會被保留，並在下次啟動時復原。

**更新重新啟動時儲存的內容：**
- 所有開啟的分頁及其內容（包括未儲存的變更）
- 游標位置和復原/重做歷史記錄
- UI 版面：側邊欄狀態、大綱可見性、原始碼/專注/打字機模式、終端機狀態
- 視窗位置和大小
- 目前的工作區和檔案總管設定

**運作方式：**
- 當你選擇重新啟動並安裝更新時，VMark 會先擷取所有視窗的完整工作階段狀態
- 重新啟動時，分頁恢復到你離開時的狀態，已修改（未儲存）的文件會相應標記
- 未儲存的變更也會每 10 秒寫入復原快照一次。意外結束後，VMark 會在下次啟動時將其還原為未儲存的分頁
- 超過 7 天的復原快照會自動清理
- 一般結束不會擷取工作階段：VMark 會先請你儲存未儲存的文件（請參閱[關閉分頁與視窗](/zh-TW/guide/tab-navigation#關閉分頁與視窗)）。下次開啟工作區時，該工作區開啟的分頁仍會回來（請參閱[工作階段還原](/zh-TW/guide/workspace-management#工作階段還原)）

無需設定。工作階段復原始終處於啟用狀態。

## 編輯細節

一些無需任何設定即可運作的行為：

- **編輯器失去焦點時，選取範圍仍然可見。** 點擊進入終端機、側邊欄或彈出視窗時，選取的文字會保留較淡的醒目標示，讓你看得出指令或 AI 工具將作用於哪些內容。原始碼模式會顯示多重游標選取的每一個範圍。
- **在行內程式碼左邊緣輸入時，文字會進入程式碼內。** 在所見即所得模式中，當游標正好位於行內程式碼之前——無論你是如何移到那裡的——下一個字元都會加入程式碼，而不會落在程式碼之外。
- **輸入法（IME）是安全的。** 當你使用中文、日文或韓文輸入法組字時，以及組字結束後的 50 ms 內，編輯器快捷鍵與自動轉換都不會觸發，因此按 Enter 選字不會同時分割段落。復原與重做仍可使用。以 Enter 確認的韓文音節也會同時開始新的一行。已送出文字前殘留的羅馬拼音會被移除，送入空白表格儲存格的字元也會保持原樣。資訊類通知會等到組字結束才顯示；錯誤與警告則立即顯示。AI 用戶端透過 MCP 送來的編輯會被拒絕（由用戶端重試）或暫緩到組字結束，磁碟上檔案的變更也會等待，因此都不會覆寫你仍在組字的文字。
- **尊重減少動態效果。** 當作業系統的*減少動態效果*輔助使用設定開啟時，VMark 會關閉其動畫與轉場效果，並改為立即捲動而非平滑捲動（包括打字機模式）。VMark 中沒有另外的設定。系統的*減少透明度*設定同樣會關閉背景模糊。

## 檢視與專注

### 專注模式（`F8`）

專注模式會將游標所在區塊以外的所有區塊淡化，減少視覺干擾，讓你專注於單一段落。當前區塊以全不透明度高亮顯示，周圍內容則淡化為柔和色彩。使用 `F8` 切換——在所見即所得與原始碼模式中均可使用，並持續至你手動關閉。

### 打字機模式（`F9`）

打字機模式將當前行保持在視窗垂直中央，使你的視線固定在一個位置，文件在下方滾動——就像在實體打字機上打字一樣。使用 `F9` 切換。在兩種編輯模式中均可使用，採用平滑捲動並設有小閾值，避免在輕微游標移動時出現抖動。

### 同時啟用專注與打字機模式

專注模式與打字機模式可同時啟用。兩者結合提供完全無干擾的寫作環境：周圍區塊淡化，*同時*當前行置中顯示。

### 自動換行（`Alt + Z`）

使用 `Alt + Z` 切換軟換行。啟用後，長行在編輯器寬度處換行，而非水平捲動。設定會跨工作階段保留。

### 唯讀模式（`F10`）

鎖定文件以防止意外編輯。使用 `F10` 切換。啟用後，所有鍵盤輸入和格式化指令都會被封鎖——但仍然可以捲動、選取文字和複製。適合在審閱已完成的文件時使用，或在另一個分頁撰寫時參考內容。

### 大綱面板（`Ctrl + Shift + 1`）

大綱面板在側邊欄中以可折疊的樹狀結構顯示文件的標題結構。使用 `Ctrl + Shift + 1` 開啟。

- 點選任何標題可將編輯器捲動到該區段
- 折疊和展開標題群組，專注於文件的特定部分
- 捲動或輸入時，目前活動的標題會高亮顯示
- 新增、刪除或重新命名標題時即時更新
- 過長的標題會換成兩行，游標懸停時顯示完整內容
- 面板頂端的篩選輸入框會將樹狀結構縮小至文字符合查詢的標題（不分大小寫，並保留上層標題，讓路徑保持可見）。按 `Esc` 清除。

### 縮放

無需開啟設定即可調整編輯器字型大小：

| 操作 | 快捷鍵 |
|------|--------|
| 放大 | `Mod + =` |
| 縮小 | `Mod + -` |
| 重設為預設值 | `Mod + 0` |

縮放以 2px 為單位變更編輯器字型大小（範圍：12px 至 32px）。它修改的是 **設定 > 外觀** 中相同的字型大小值，因此鍵盤縮放和設定滑桿始終保持同步。

## 一致性、知識庫與 Slidev

- **一致性與明細檢視**——選擇性啟用的來源追蹤會記錄每次 AI 生成讀取了哪些文件，在上游文件變更時標示下游文件，並在此之上加入語意檢查、正典設定與情境。可從 **視窗 → 一致性明細** 開啟。[了解更多 →](/zh-TW/guide/coherence)
- **知識庫**——將開啟的工作區以交叉連結的網站形式（Wiki 連結、反向連結、關係圖、全文搜尋）在 `127.0.0.1` 上提供，可在面板（`Ctrl + Shift + 4`）或瀏覽器中檢視，並可預覽與匯出 Slidev 簡報。目前沒有任何正式版建置包含它所需的內容伺服器執行環境，因此除非開啟 **設定 → 進階 → 開發者工具**，否則面板、其選單項目、命令面板指令與快捷鍵都會隱藏。[了解更多 →](/zh-TW/guide/knowledge-base)

## 自訂設定

### 主題

六款內建色彩主題：

- 白色（清爽、簡潔）
- 紙張（暖白色）
- 薄荷（柔和綠色調）
- 棕褐（復古風格）
- 夜間（深色模式）
- Solarized（深色，Solarized 配色）

### 字型

可分別設定以下字型：

- 拉丁文（英文）
- 中日韓文字型
- 等寬字型（程式碼）

每個選擇器都提供一小份推薦字型清單、電腦上已安裝的字型，以及一個 **自訂…** 項目，可在其中輸入任何字型家族名稱。[詳細說明 →](/zh-TW/guide/settings#字型設計)

等寬字型在原始碼模式、程式碼與終端機中使用之前會先經過檢查：如果你選擇的字型沒有安裝，或其實不是等寬字型，VMark 會沿著字型堆疊退回到下一個符合條件的字型。這在使用 CJK 語系的 Linux 上最為重要，因為缺少的字型名稱可能會被解析為比例寬度的 CJK 字型，進而破壞終端機的格線。

### 版面

可調整：

- 字型大小
- 行距
- 區塊間距（段落與區塊之間的間距）
- 中日韓文字元間距（提升中日韓文可讀性的細微間距）
- 編輯器寬度
- 區塊元素字型大小（清單、引言、表格、提示框）
- 標題對齊（靠左或置中）
- 圖片與表格對齊（靠左或置中）

### 鍵盤快捷鍵

所有快捷鍵均可在「設定 → 快捷鍵」中自訂。

## 技術細節

VMark 以現代技術構建：

| 元件 | 技術 |
|------|------|
| 桌面框架 | Tauri v2（Rust） |
| 前端 | React 19、TypeScript |
| 狀態管理 | Zustand v5 |
| 富文字編輯器 | Tiptap（ProseMirror） |
| 原始碼編輯器 | CodeMirror 6 |
| 樣式 | Tailwind CSS v4 |

所有處理均在你的本機電腦上進行——無需雲端服務，無需帳號。
