# 内联弹窗

VMark 为编辑链接、图片、媒体、数学公式、脚注等内容提供上下文弹窗。这些弹窗在所见即所得模式和源码模式中均可使用，并支持一致的键盘导航。

## 通用键盘快捷键

所有弹窗共享以下键盘行为：

| 操作 | 快捷键 |
|------|--------|
| 关闭/取消 | `Escape` |
| 确认/保存 | `Enter` |
| 在字段间导航 | `Tab` / `Shift + Tab` |

## 链接弹窗

点击链接会显示其编辑弹窗。光标会停留在点击的位置，因此可以继续编辑链接文本——输入、`Backspace` 和复制/粘贴都作用于文档。一旦编辑文本或将光标移出链接，弹窗就会立即关闭。

### 编辑已有链接

**触发方式：** 点击链接，或将光标放在链接内 + `Mod + K`

点击后键盘焦点仍留在文档中；点击 URL 字段即可编辑链接目标。`Mod + K` 会直接将焦点移到 URL 字段。

**字段：**
- **URL**——编辑链接目标
- **打开目标**——外部 URL 在浏览器中打开；`#bookmark` 链接跳转到对应标题；跨文件链接则在新标签页中打开本地文件
- **复制**——将 URL 复制到剪贴板
- **删除**——移除链接，保留文本

**不经弹窗直接打开：** 在链接上 `Cmd + Click`（Windows/Linux 上为 `Ctrl + Click`）可直接打开其目标。

### 创建新链接

**触发方式：** 选中文本 + `Mod + K`

**智能剪贴板：** 如果剪贴板中有 URL，会自动填入。

**字段：**
- **URL 输入**——输入目标地址
- **确认**——按 Enter 或点击 ✓
- **取消**——按 Escape 或点击 ✗

### 源码模式

- **`Cmd + Click`**（Windows/Linux 上为 `Ctrl + Click`）链接 → 外部 URL 在浏览器中打开，`#bookmark` 链接跳转到对应标题，本地文件路径则在新标签页中打开该文件
- **点击** `[text](url)` 语法 → 显示编辑弹窗；光标仍留在 Markdown 中，可以继续输入
- 在链接内按 **`Mod + K`** → 显示编辑弹窗，焦点位于 URL 字段

::: tip 书签链接
以 `#` 开头的链接会被视为书签（内部标题链接）。打开时跳转到对应标题，而不是打开浏览器。
:::

::: tip 跨文件链接
指向本地文件的链接会在新标签页中打开目标文件；若链接带有 `#fragment`，则会定位到对应标题。`../appendix/cards.md` 或 `./notes.md` 这类相对路径会相对于当前文档所在目录解析。绝对路径（macOS/Linux 上的 `/Users/me/notes/a.md`，Windows 上的 `C:\notes\a.md`）会精确打开其指向的文件。网络路径（`\\server\share\…`）不会通过链接打开。如果文档尚未命名，则只能打开绝对路径。
:::

## 标题选择器（书签链接）

**触发方式：** `Alt + Mod + B`（书签链接）、**插入 → 链接 → 书签**，或通用工具栏的链接组

书签链接指向同一文档中的某个标题（`[text](#heading-id)`）。无需手动输入锚点，选择器会列出文档中的所有标题，按层级缩进，顶部带有一个筛选输入框。

**行为：**
- `↑`/`↓` 在列表中移动，`Enter` 插入链接，`Escape` 关闭
- 有选中文本时，选中内容成为链接文本；没有选区时，插入标题本身的文本作为链接
- 当文档中没有标题，或没有任何项匹配筛选条件时，弹窗会给出相应提示

## 媒体弹窗（图片、视频、音频）

用于编辑所有媒体类型——图片、视频和音频——的统一弹窗。

### 编辑弹窗

**触发方式：** 双击任意媒体元素（图片、视频或音频）

**所有媒体类型的通用字段：**
- **来源**——文件路径或 URL

**类型专属字段：**

| 字段 | 图片 | 视频 | 音频 |
|------|------|------|------|
| 替代文本 | 是 | — | — |
| 标题 | — | 是 | 是 |
| 封面图 | — | 是 | — |
| 尺寸 | 只读 | — | — |
| 内联/块级切换 | 是（带链接的图片除外） | — | — |

**按钮：**
- **浏览**——从文件系统选择文件
- **复制**——将来源路径复制到剪贴板
- **删除**——移除媒体元素

**快捷键：**
- `Mod + Shift + I`——插入新图片
- `Enter`——保存更改
- `Escape`——关闭弹窗

### 源码模式

在源码模式中，点击图片语法 `![alt](path)` 会打开相同的媒体弹窗。

源码模式还会显示媒体的浮动**预览**——图片，或带有原生播放控件的视频、音频播放器。当光标位于 `![alt](path)` 内（且未选中文本）时，以及鼠标悬停在该语法上时，都会出现预览；光标触发的预览优先于悬停触发的预览。路径必须以可识别的图片、视频或音频扩展名结尾（或者是 `data:image/` URL）。媒体弹窗打开期间，预览会隐藏。

## 图片右键菜单

在所见即所得模式中右键点击图片会打开一个快捷操作菜单（与双击编辑弹窗分开）。

**触发方式：** 右键点击任意图片

**操作：**
| 操作 | 描述 |
|------|------|
| 更换图片 | 打开文件选择器以替换图片 |
| 删除图片 | 从文档中移除图片 |
| 复制路径 | 将图片来源路径复制到剪贴板 |
| 在访达中显示 | 在文件管理器中打开图片文件所在位置（标签会根据平台自动适配） |

按 `Escape` 关闭右键菜单而不执行任何操作。

## 数学公式弹窗

带有实时预览的 LaTeX 数学表达式编辑器。

**触发方式：**
- **所见即所得：** 点击内联数学公式 `$...$`
- **源码：** 将光标放在非空的 `$...$`、`$$...$$` 块，或 ` ```latex ` / ` ```math ` 块内

**字段：**
- **LaTeX 输入**——编辑数学表达式
- **预览**——实时渲染预览
- **错误显示**——显示 LaTeX 错误及有用的语法提示

**快捷键：**
- `Mod + Enter`——保存并关闭
- `Click outside`（点击外部）——保存并关闭（提交你的编辑）
- `Escape`——取消并关闭（丢弃你的编辑）
- `Shift + Backspace`——删除内联数学公式（即使非空也有效，仅 WYSIWYG 模式）
- `Alt + Mod + M`——插入新内联数学公式

::: tip 错误提示
当出现 LaTeX 语法错误时，弹窗会显示有用的建议，例如缺少花括号、未知命令或括号不匹配。
:::

::: info 源码模式
源码模式提供与所见即所得模式相同的可编辑数学弹窗——用于 LaTeX 输入的文本区域，下方显示实时 KaTeX 预览。当光标进入任何数学语法（非空的 `$...$`、`$$...$$` 或 ` ```latex ` / ` ```math `）时弹窗自动打开。按 `Mod + Enter` 保存，按 `Escape` 取消。在行尾输入的空 `$$` 会被视为普通文本——它很可能是一个尚未输完的块级公式定界符——不会打开弹窗。
:::

## 脚注弹窗

内联编辑脚注内容。

**触发方式：**
- **所见即所得：** 悬停在脚注引用 `[^1]` 上
- **源码：** 悬停或点击脚注引用或脚注定义

**字段：**
- **内容**——多行脚注文本（自动调整高度）
- **跳转到定义**——跳转到脚注定义处
- **删除**——移除脚注

**行为：**
- 新脚注自动聚焦到内容字段
- 文本区域随输入自动扩展

## Wiki 链接弹窗

编辑用于内部文档连接的 Wiki 风格链接。

**触发方式：**
- **所见即所得：** 悬停在 `[[target]]` 上（300ms 延迟）
- **源码：** 点击 wiki 链接语法

**字段：**
- **目标**——工作区相对路径（自动处理 `.md` 扩展名）
- **浏览**——从工作区选择文件
- **打开**——打开链接文档
- **复制**——复制目标路径
- **删除**——移除 wiki 链接

## 表格上下文菜单

快速表格编辑操作。

**触发方式：**
- **所见即所得：** 右键点击表格单元格（同样的操作也可通过工具栏和键盘快捷键使用）
- **源码：** 右键点击表格单元格

**操作：**
| 操作 | 描述 |
|------|------|
| 在上方/下方插入行 | 在光标处添加行 |
| 在左侧/右侧插入列 | 在光标处添加列 |
| 删除行 | 移除当前行 |
| 删除列 | 移除当前列 |
| 删除表格 | 移除整个表格 |
| 列左对齐/居中/右对齐 | 设置当前列的对齐方式 |
| 全部左对齐/居中/右对齐 | 设置所有列的对齐方式 |
| 格式化表格 | 自动对齐表格列（美化 Markdown） |
| 适应宽度 / 自然宽度 | 仅限所见即所得：将此表格固定为编辑器宽度并按内容比例分配列宽，或恢复为其自然宽度 |

## 拼写检查弹窗

通过建议修复拼写错误。

**触发方式：**
- 右键点击拼写错误的单词（红色下划线）

**操作：**
- **建议**——点击以替换为建议内容
- **添加到词典**——停止将其标记为拼写错误

## 拖动移动文本

在所见即所得模式中，可以用鼠标移动选区：在选中的文本上按下鼠标并拖动——一个放置光标会显示文本将落在何处——然后松开。这次移动是一个可撤销的单步操作（`Mod + Z` 可将其放回原处）。拖动过程中按 `Escape`，或让窗口失去焦点，即可取消。VMark 自行实现了这一功能，因为桌面外壳会拦截浏览器原生的拖动事件，所以它是一个鼠标手势，而不是系统级的拖放。

| 元素 | 所见即所得编辑 | 源码 |
|------|--------------|------|
| 链接 | 点击 / `Mod+K` / `Cmd+Click` 打开 | 点击 / `Mod+K` / `Cmd+Click` 打开 |
| 图片 | 双击 | 点击 `![](path)` |
| 视频 | 双击 | — |
| 音频 | 双击 | — |
| 数学公式 | 点击 | 光标在公式中 → 弹窗 |

| 表格 | 工具栏 | 右键菜单 |
| 拼写检查 | 右键 | 右键 |

## 弹窗导航技巧

### 焦点流程
1. 弹窗打开时第一个输入框获得焦点
2. `Tab` 向前移动到各字段和按钮
3. `Shift + Tab` 向后移动
4. 焦点在弹窗内循环

### 快速编辑
- 简单的 URL 修改：编辑后按 `Enter`
- 取消：从任意字段按 `Escape`
- 多行内容（脚注、数学公式）：使用 `Mod + Enter` 保存

### 鼠标行为
- 点击弹窗外部即可关闭。默认行为是**丢弃**未保存的更改；数学公式弹窗是例外，点击外部时会**提交**编辑（参见[数学公式弹窗](#数学公式弹窗)一节）。
- 悬停弹窗（脚注、Wiki 链接）显示前有 300ms 延迟
- 将鼠标移回弹窗可保持其打开状态
