# 键盘快捷键

VMark 专为键盘优先的工作流而设计。大多数快捷键可在设置中自定义。少数原语是固定的：多光标选择器 `Mod+D`（选择下一个出现位置）和 `Mod+Shift+L`（选择所有出现位置），以及全局的撤销/重做绑定。其他多光标快捷键（跳过出现位置、软撤销光标、向上/向下添加光标）均可配置。标记为 _（上下文感知）_ 的快捷键由编辑器内部针对特定结构处理（例如任务列表复选框切换），不在自定义注册表中暴露。

## 符号说明

- **Mod** = macOS 上的 Cmd，Windows/Linux 上的 Ctrl
- **Alt** = macOS 上的 Option

## macOS 上的功能键

VMark 使用功能键（F2–F10）进行快速模式切换。在 macOS 上，这些键默认映射到系统功能（亮度、音量等）。

**不按 Fn 直接使用 F 键：**

1. 打开**系统设置** → **键盘**
2. 启用 **“将 F1、F2 等键用作标准功能键”**

或者，按住 **Fn** 键的同时按 F2–F10 来触发 VMark 快捷键。

::: tip
如果你希望保留系统功能键，可以在设置中（`Mod + ,`）将 VMark 快捷键自定义为其他按键组合。
:::

::: tip Windows/Linux 注意事项
在 Windows 和 Linux 上，切换隐藏文件使用 `Ctrl + H`。

在 Windows 和 Linux 上，切换侧边栏使用 `Alt + Shift + 0`，因为那里的 `Mod` 就是 Ctrl——macOS 上的组合键 `Ctrl + Shift + 0` 会与段落的 `Mod + Shift + 0` 冲突。
:::

::: tip 新建浏览器标签页
`Alt + Mod + Shift + B` 会打开一个内嵌浏览器标签页，它也出现在**文件**菜单中。内嵌浏览器在 macOS 上默认开启；如果你在**设置 → 高级 → 内嵌浏览器**中将其关闭，该菜单项会被隐藏（而不是变灰），直到你重新开启。浏览器仅支持 macOS，因此该菜单项在 Windows 和 Linux 上永远不会出现。

它是一个真正的菜单项，而不仅仅是一个键盘绑定，这一点很重要：一旦网页获得了键盘焦点，浏览器引擎会在 VMark 看到按键之前就将其消费掉，因此应用内快捷键无法触发。菜单加速键由 macOS 本身分发，所以在你浏览网页时它依然有效。
:::

## 智能 Tab 导航

Tab 和 Shift+Tab 具有上下文感知能力——可以跳出括号、引号、格式标记和链接。

| 上下文 | Tab 操作 |
|--------|---------|
| 在 `)`、`]`、`}`、引号之前 | 跳过闭合字符 |

| 在链接内部 | 跳至链接之后 |

| 上下文 | Shift+Tab 操作 |

| 在链接内部 | 跳到链接之前 |

集成终端获得焦点时：

| 操作 | 快捷键 |
|------|--------|
| 切换终端 | `` Ctrl + ` `` |

| 复制 | `Mod + C`（有选中文本时）；Linux 上也可用 `Ctrl + Shift + C` 或 `Ctrl + Insert` |
| 粘贴 | `Mod + V`；Linux 上也可用 `Ctrl + Shift + V` 或 `Shift + Insert` |
| 全选（仅终端输出） | `Mod + A`（Linux 上为 `Ctrl + Shift + A`） |
| 清除 | `Mod + K`（Linux 上为 `Ctrl + Shift + K`） |
| 搜索 | `Mod + F`（Linux 上为 `Ctrl + Shift + F`） |
| 切换到会话 1–5 | `Mod + 1` 至 `Mod + 5` |
| 增大终端字号 | `Mod + =` |
| 减小终端字号 | `Mod + -` |
| 恢复终端默认字号 | `Mod + 0` |
| 上一个命令提示符 | `Mod + ↑` |
| 下一个命令提示符 | `Mod + ↓` |
| 在输入行中换行（Claude Code 等工具） | `Shift + Enter` |

终端获得焦点时，`Mod + =`、`Mod + -` 和 `Mod + 0` 调整的是终端的字号，而不是编辑器的字号。

提示符导航可在回滚缓冲区中的命令提示符之间跳转，需要 Shell 集成（zsh 或 bash）。

在 macOS 上，终端还会把常用的文本编辑组合键转换给 Shell：

| 操作 | 快捷键 |
|------|--------|
| 向左 / 向右移动一个单词 | `Option + ←` / `Option + →` |
| 移动到行首 / 行尾 | `Cmd + ←` / `Cmd + →` |
| 删除输入行（发送 `Ctrl + U`） | `Cmd + Backspace` |

在 macOS 上，`Ctrl + A`、`Ctrl + R`、`Ctrl + W` 等 `Ctrl` 组合键会直接发送给 Shell。

在 Linux 上，终端遵循 Linux 终端的通行惯例：单纯的 `Ctrl` + 字母组合键交给 Shell，因此 `Ctrl + A`、`Ctrl + E`、`Ctrl + K`、`Ctrl + F`、`Ctrl + U`、`Ctrl + W` 等 readline 按键与其他 Linux 终端中一样可用；终端自身的操作改用 `Ctrl + Shift`：`Ctrl + Shift + A` 全选，`Ctrl + Shift + K` 清除，`Ctrl + Shift + F` 搜索，`Ctrl + Shift + C` / `Ctrl + Shift + V` 复制和粘贴。`Ctrl + Insert` 和 `Shift + Insert` 同样可以复制和粘贴。有两个单纯的 `Ctrl` 组合键仍由终端处理：`Ctrl + C` 复制选中内容（无选中内容时发送 SIGINT），`Ctrl + V` 粘贴。`Ctrl + 1` 至 `Ctrl + 5` 仍用于切换会话。

| 操作 | 快捷键 |
|------|--------|
| 下一个匹配 | `Enter` |
| 上一个匹配 | `Shift + Enter` |
| 关闭搜索 | `Escape` |

::: tip
无选中内容时 `Mod + C` 会向运行中的进程发送 SIGINT。完整指南请参阅[集成终端](/zh-CN/guide/terminal)。
:::

## 自定义快捷键

1. 使用 `Mod + ,` 打开设置
2. 导航到**快捷键**选项卡（在搜索框中输入内容，可按名称、类别、描述或按键筛选）
3. 点击快捷键旁显示的按键——若尚未分配按键，则点击**未分配**
4. 按下你想要的按键组合，然后点击**确认**（`Escape` 取消）

在你分配组合键之前，对话框会给出警告：

- **冲突**——该组合键已被另一个快捷键使用，对话框会指明是哪一个。你仍然可以选择**强制确认**。
- **不支持**——VMark 无法使用该组合键，因此不能分配。请换一个。

自定义过的快捷键会被高亮显示，并出现一个**重置为默认值**按钮。**全部重置**会在确认后恢复所有默认设置。**导出**会将你的快捷键保存为 JSON 文件（`vmark-shortcuts.json`），**导入**则加载这样的文件；如果文件中有任何条目无效，则不会导入任何内容，并列出存在的问题。

::: tip
快捷键在适用情况下会与菜单加速键同步，因此菜单项会显示你自定义的快捷键。
:::
