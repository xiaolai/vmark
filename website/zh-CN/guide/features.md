# 功能特性

VMark 是人类与 AI 协作的纯文本工作空间。Markdown 是核心（支持所见即所得、源码预览和源码三种模式），但该工作空间也能打开 YAML、JSON、TOML、Mermaid、SVG、HTML 以及 9 种代码查看器格式——完整列表参见[支持的格式](/zh-CN/guide/formats)。

## 编辑模式

### 富文本模式（所见即所得）

默认编辑模式提供真正的"所见即所得"体验：

- 输入时实时格式化预览
- 光标悬停时内联显示语法
- 直观的工具栏和上下文菜单
- 无缝的 Markdown 语法输入

### 源码模式

切换到带完整语法高亮的原始 Markdown 编辑：

- 由 CodeMirror 6 驱动的编辑器
- 完整语法高亮
- 数学公式、链接、图片、Wiki 链接和媒体的交互式弹窗——与所见即所得模式体验一致
- 智能粘贴——从网页和 Word 文档复制的 HTML 自动转换为干净的 Markdown
- 剪贴板图片粘贴——截图和复制的图片保存到资产文件夹，以 `![](path)` 格式插入
- 支持代码围栏感知的多光标编辑，支持中日韩词边界
- 适合高级用户

使用 `F6` 在两种模式间切换。

### 分屏视图（源码 + 预览）

在左侧编辑原始 Markdown 源码，右侧同时更新一个**实时、只读的所见即所得预览**——该预览*就是*所见即所得渲染器，因此永远不会与你在富文本模式中看到的内容出现偏差。格式化命令和工具栏作用于源码窗格；拖动分隔条（或在其上使用方向键）即可调整大小。

- 使用 `Shift + F6`、**视图 → Markdown 分屏视图** 或命令面板（“切换 Markdown 分屏视图”）按会话切换
- 在 **设置 → Markdown → 布局 → 默认拆分源码/预览** 中将其设为 Markdown 文件的默认视图

所见即所得仍是默认模式；分屏需手动启用。三种视图互斥——`F6` 切换源码模式，`Shift + F6` 切换分屏，各自都会返回所见即所得——因此在它们之间切换始终只需一次按键。

**视图** 菜单将三种模式——**所见即所得模式**、**源代码模式**、**Markdown 分屏视图**——显示为一组带勾选标记的选项，因此当前模式始终可见，互斥关系也一目了然。**自动换行** 和 **行号** 仅作用于源码编辑器，因此在所见即所得模式下显示为灰色。

### 阅读位置

离开文档后，你在文档中的位置会被保留。切换到另一个标签页再切回来、切换源码模式或分屏视图，或文件从磁盘重新加载，都会把你带回原来阅读的位置——而不是文档顶部。

每个界面各自记住自己的位置，因此富文本和源码在同一文件中保留各自的位置。回到同一个界面时（切换标签页，或文件重新加载），即使光标在别处，也会回到你上次滚动到的位置；光标则留在你放下它的地方。在富文本与源码之间切换时，如果有光标，则以光标为准，因为正是光标让同一段落在两种界面之间保持可见。

位置按文档、按会话保存——关闭标签页后即被遗忘。

### 跨模式撤销

撤销和重做可以跨越所见即所得 ⇄ 源码的边界。每次切换模式都会记录一个检查点，当前编辑器自身的历史耗尽后，`Mod + Z` 会继续沿这些检查点回退——恢复较早的内容，而不切换你当前所在的视图。重做沿同一链条向前推进；如果你已通过新的编辑放弃了某个分支，针对该分支的重做会被拒绝，而不是覆盖你的工作。该链条按标签页保存，并在标签页关闭时清除。

### 大文件

VMark 会以源码模式自动打开大文件，以实现亚秒级打开 —— 包括超过 1 MB 的文件，或估算块数达到 1,200 以上的 Markdown ——；在处理超过 5 MB 的文件前发出警告；并拒绝打开超过 50 MB 的文件。阈值和设置参见[大文件](./large-files.md)指南。

### 源码预览

在不离开所见即所得模式的情况下，编辑单个块的原始 Markdown。按 `F5` 可为光标所在块打开源码预览。

**布局：**
- 标题栏：包含块类型标签和操作按钮
- CodeMirror 编辑器：显示该块的 Markdown 源码
- 原始块显示为淡化预览（实时预览开启时）

**操作：**
| 操作 | 快捷键 |
|------|--------|
| 保存更改 | `Cmd/Ctrl + Enter` |
| 取消（还原） | `Escape` |
| 切换实时预览 | 点击眼睛图标 |

**实时预览：**
- **关闭（默认）：** 自由编辑，仅在保存时应用更改
- **开启：** 输入时立即应用更改，并在下方显示预览

**排除的块：**
某些块有自己的编辑机制，不使用源码预览：
- 代码块（包括 Mermaid、LaTeX）——双击即可编辑
- 块图片——使用图片弹窗
- 前置元数据、HTML 块、水平分割线

源码预览适合在可视化编辑器中进行精确的 Markdown 编辑（修复表格语法、调整列表缩进等）。

## 多光标编辑

同时编辑多个位置——VMark 在所见即所得和源码模式下均支持完整的多光标功能。

| 操作 | 快捷键 |
|------|--------|
| 在下一匹配处添加光标 | `Mod + D` |
| 跳过匹配，跳至下一个 | `Mod + Shift + D` |
| 选择所有出现位置 | `Mod + Shift + L` |
| 在上方/下方添加光标 | `Mod + Alt + Up/Down` |
| 点击添加光标 | `Alt + Click` |
| 撤销最后添加的光标 | `Alt + Mod + Z` |
| 合并为单个光标 | `Escape` |

所有标准编辑操作（输入、删除、剪贴板、导航）在每个光标处独立执行。在正文中，`Mod + D` 和 `Mod + Shift + L` 会搜索整个文档；在代码块内，它们只在该代码块中查找。`Alt + Mod + Shift + L` 仅选择当前块中的所有匹配项。

[了解更多 →](/zh-CN/guide/multi-cursor)

## 智能全选

在所见即所得模式中，`Mod + A` 会逐层扩大选区，而不是直接跳到整个文档：在表格内，它依次选择单元格、行、表格，最后是整个文档。`Mod + Z` 可将扩展回退一步，`Escape` 会将选区折叠为光标。

在源码模式中，`Mod + A` 会先选择所在的块——代码围栏、表格、引用块或列表——然后是整个文档；在这里 `Mod + Z` 同样可以回退一步扩展。

此快捷键由编辑器内置，不可自定义。

## 自动配对与 Tab 跳出

当你输入开括号、引号或反引号时，VMark 会自动插入对应的闭合字符。按 **Tab** 可跳过闭合字符，无需伸手去按方向键。

- 括号：`()` `[]` `{}`
- 引号：`""` `''` `` ` ` ``
- 中日韩：`「」` `『』` `（）` `【】` `《》` `〈〉`
- 弯引号：`""` `''`
- 所见即所得中的格式标记：**粗体**、*斜体*、`代码`、~~删除线~~、链接

当配对为空时，按 Backspace 会同时删除两个字符。在代码块和内联代码中，自动配对和 Tab 括号跳出均 **禁用**——代码中的括号保持原样。可在 **设置 → 编辑器** 中配置。

[了解更多 →](/zh-CN/guide/tab-navigation)

## Frontmatter 面板

在所见即所得模式中直接编辑 YAML frontmatter，无需切换到源码模式。

- **默认折叠**——当文档包含 frontmatter 时，顶部显示一个小的"Frontmatter"标签
- **点击展开**——打开一个纯文本编辑器编辑 YAML 内容
- **`Mod + Enter`**——保存更改并折叠面板
- **`Escape`**——还原到上次保存的值并折叠
- **失焦自动保存**——点击其他位置时，更改会在短暂延迟后自动保存

面板会在编辑器历史中创建撤销点，因此你可以随时使用 `Mod + Z` 还原 frontmatter 更改。

## 特殊内容

### 信息框

GitHub 风格的 Markdown 提示块：

- NOTE——一般信息
- TIP——有用的建议
- IMPORTANT——关键信息
- WARNING——潜在问题
- CAUTION——危险操作

### 可折叠区块

使用 `<details>` HTML 元素创建可展开的内容块。

### 数学公式

KaTeX 驱动的 LaTeX 渲染：

- 内联数学：`$E = mc^2$`
- 显示数学：`$$...$$` 块
- 打开或粘贴时会识别 ChatGPT 风格的分隔符，并规范化为 `$` 形式：`\( ... \)` 变为行内数学公式，独立的 `\[ ... \]` 变为显示块
- `$$` 块必须在空行之前闭合（pandoc 的规则）——未闭合的 `$$` 会按字面文本渲染，而不会吞掉其后的段落。闭合符之前紧邻的空行没有问题（空的 `$$` … `$$` 块仍是数学块）
- 完整 LaTeX 语法支持
- 带有语法提示的友好错误信息

### 图表

Mermaid 图表支持与实时预览：

- 流程图、时序图、甘特图
- 类图、状态图、ER 图
- 源码模式下的实时预览面板（可拖动、调整大小、缩放）
- [了解更多 →](/zh-CN/guide/mermaid)

Graphviz DOT 支持，提供相同的预览界面：

- ` ```dot ` 和 ` ```graphviz ` 围栏代码块本地渲染（WASM）
- 与 Mermaid 图表一样支持平移、缩放和 PNG 导出
- [了解更多 →](/zh-CN/guide/graphviz)

### SVG 图形

通过 ` ```svg ` 代码块内联渲染原始 SVG：

- 即时渲染，支持平移、缩放和 PNG 导出
- 在所见即所得和源码模式下均支持实时预览
- 非常适合 AI 生成的图表和自定义插图
- [了解更多 →](/zh-CN/guide/svg)

### 内联目录

选择 **插入 → 目录**，即可在任一模式下立即插入实时目录（该菜单项没有默认快捷键；可在 设置 → 快捷键 中分配）。你也可以在单独一行写 `[TOC]`：在源码模式下，这一行本身就是目录；而在 WYSIWYG 中，手动输入的 `[TOC]` 会一直是普通文本，直到文档被重新解析——例如切换到源码模式再切回来，或重新打开文件之后。夹在其他文字中的 `[TOC]` 永远不会被转换：

- 根据文档标题自动生成，并正确嵌套
- 点击任意标题即可直接滚动到该位置
- 编辑时实时更新
- 在所见即所得、导出（HTML/PDF）中渲染，并可在源码模式中干净地往返转换

## 搜索与替换

使用 `Mod + F` 打开查找栏。它在窗口底部的栏中打开，在所见即所得和源码模式下均可使用。

**导航：**

| 操作 | 快捷键 |
|------|--------|
| 查找下一个匹配 | `Enter` 或 `Mod + G` |
| 查找上一个匹配 | `Shift + Enter` 或 `Mod + Shift + G` |
| 用选中内容查找 | `Mod + E` |
| 关闭查找栏 | `Escape` |

**搜索选项**——通过查找栏中的按钮切换：

- **区分大小写**——匹配精确的字母大小写
- **全词匹配**——仅匹配完整单词，不匹配子字符串
- **正则表达式**——使用正则模式（需先在设置中启用）

**替换：**

替换字段位于查找字段旁边——两者始终可见，按 `Tab` 可从一个移到另一个。输入替换文本，然后使用 **替换**（单个匹配）或 **全部替换**（一次替换所有匹配）。匹配计数器显示当前位置和总数（如"3/12"），让你始终知道自己在哪里。

## Markdown 检查

VMark 内置 Markdown 语法检查器，可检查文档中常见的语法错误和无障碍问题。在 **设置 > Markdown > 检查** 中启用。

**使用方法：**

| 操作 | 快捷键 |
|------|--------|
| 运行检查 | `Alt + Mod + V` |
| 跳转到下一个问题 | `F2` |
| 跳转到上一个问题 | `Shift + F2` |

运行检查后，诊断结果以内联高亮和边栏标记的形式显示。如果没有发现问题，将弹出通知确认文档无误。问题分为错误和警告两类。

**检查规则（共 13 条）：**

- 未定义的引用链接
- 表格列数不匹配
- 链接语法倒写 `(文字)[链接]`（应为 `[文字](链接)`）
- 标题 `#` 后缺少空格
- 强调标记内部有空格
- 链接文字或链接 URL 为空
- 重复的链接/图片定义
- 未使用的链接/图片定义
- 标题级别跳级（如从 H1 到 H3）
- 图片缺少替代文字（无障碍）
- 未闭合的围栏代码块
- 无效的片段链接（`#锚点` 与任何标题不匹配）

检查结果不会随输入而更新。在源码模式中，任何编辑都会清除结果。在所见即所得模式中，编辑会移除高亮，但状态栏中的问题计数以及 `F2` / `Shift + F2` 的跳转目标会保留上一次运行的结果，直到你再次运行检查或关闭该标签页。可随时使用 `Alt + Mod + V` 重新运行检查。

## 通用工具栏

固定在编辑器底部的格式化工具栏，在所见即所得和源码模式下均可快速访问所有格式化操作。

- **切换：** `Mod + Shift + B` 打开工具栏并聚焦。再次按下可在保持工具栏可见的同时将焦点返回编辑器。
- **键盘导航：** 使用 `左`/`右` 方向键在组之间移动。`Enter` 或 `Space` 打开下拉菜单。方向键在菜单内导航。
- **两步 Escape：** 如果下拉菜单已打开，`Escape` 先关闭菜单。再次按 `Escape` 关闭整个工具栏。
- **会话记忆：** 工具栏记住当前会话中最后聚焦的按钮，重新聚焦时从上次位置继续。
- **AI 精灵快捷方式：** 工具栏包含一个 AI 精灵按钮，可打开精灵选择器（`Mod + Y`）。

## 编辑器上下文菜单

在编辑器中任意位置（所见即所得或源码模式）右键点击，即可打开包含常用操作的上下文菜单。

- **剪贴板：** 剪切、复制、粘贴和全选。在 macOS 上，它们使用原生剪贴板管线，因此粘贴富文本内容（例如从浏览器复制的 HTML）会保留格式——与 `Mod + V` 完全相同。
- **行内格式：** 粗体、斜体、删除线和行内代码，勾选标记显示光标处当前生效的格式。
- **块操作：** 标题级别和列表类型子菜单、引用块和代码块——勾选标记反映当前块。
- **链接：** 在普通文本上显示插入链接；在已有链接上，该部分会换成编辑链接、复制链接和移除链接。
- **上下文感知：** 在表格内会改为显示专用的表格菜单；右键点击图片会打开图片菜单；在代码块内只提供剪贴板操作。非 Markdown 文件（JSON、YAML 等）只有精简的剪贴板菜单。
- **选区处理：** 在选区内右键点击会保留选区；在其他位置右键点击会先把光标移到该处（macOS 惯例）。
- **键盘：** 方向键用于导航（会跳过禁用项），`Right`/`Left` 进入和离开子菜单，`Escape` 先关闭子菜单再关闭菜单。快捷键提示会反映你自定义的按键绑定。

## 命令面板

按 `Mod + Shift + P` 打开命令面板。查询为空时，它会按类别分组列出所有可用命令——文件、工作区、视图、导出、格式化、标题、列表、表格、行、选区、转换、中日韩、检查、历史、AI 等；输入即可筛选并按匹配程度排序。`↑`/`↓` 移动，`Enter` 执行命令，`Escape`（或点击背景）关闭。只显示当前适用的命令——没有打开文档时编辑器命令会消失，没有打开工作区时工作区命令会消失——命令会在你打开面板的那个窗口中执行。本指南各页面以引号标注其命令面板命令（“切换 Markdown 分屏视图”“一致性明细”“窗口状态”）。命令面板没有菜单项；其快捷键可在 **设置 → 快捷键** 中自定义。

## 文档历史

VMark 自动保存文档快照，方便你恢复到早期版本。

- 可配置间隔的**自动保存**在后台捕获快照
- **每文档独立历史记录**保存在本地的 VMark 应用数据文件夹中——一个索引文件，外加每个快照一个 Markdown 文件
- 使用 `Ctrl + Shift + 3` 打开历史侧边栏，浏览过去的版本
- 快照按**日期分组**，显示每个版本保存的确切时间戳
- 点击任何快照旁的还原按钮**还原**到以前的版本（确认对话框防止意外恢复）
- 使用垃圾箱按钮**删除**不再需要的单个快照
- 在任何还原之前，当前内容会被保存为新快照，因此你永远不会丢失工作
- 历史记录要求文档已保存为文件（未命名文档没有历史记录）
- 在 **设置 → 文件与图片 → 保存**（**保留文档历史记录**）中启用或禁用历史记录追踪

## 会话恢复（Hot Exit）

当 VMark 为安装更新而重启，或程序意外退出时，你的工作会被保留，并在下次启动时恢复。

**更新重启时保存的内容：**
- 所有打开的标签页及其内容（包括未保存的更改）
- 光标位置和撤销/重做历史
- UI 布局：侧边栏状态、大纲可见性、源码/专注/打字机模式、终端状态
- 窗口位置和大小
- 当前工作区和文件资源管理器设置

**工作原理：**
- 当你选择重启并安装更新时，VMark 会先捕获所有窗口的完整会话状态
- 重新启动时，标签页恢复到你离开时的状态，已修改（未保存）的文档会相应标记
- 未保存的更改还会每 10 秒写入一次恢复快照。意外退出后，VMark 会在下次启动时将它们恢复为未保存的标签页
- 超过 7 天的恢复快照会自动清理
- 普通退出不会捕获会话：VMark 会先要求你保存未保存的文档（参见[关闭标签页和窗口](/zh-CN/guide/tab-navigation#关闭标签页和窗口)）。工作区中打开的标签页仍会在你下次打开该工作区时恢复（参见[会话恢复](/zh-CN/guide/workspace-management#会话恢复)）

无需配置。会话恢复始终处于活动状态。

## 编辑细节

以下几项行为无需任何设置即可生效：

- **编辑器失去焦点时选区仍然可见。** 点击进入终端、侧边栏或弹窗时，选中的文本会保留较淡的高亮，让你看到命令或 AI 工具将作用于哪些内容。源码模式会显示多光标选区的每一个范围。
- **在行内代码左边缘输入的内容会进入代码内部。** 在所见即所得模式中，当光标恰好位于行内代码片段之前时——无论你是怎么到达那里的——下一个字符都会加入代码，而不是落在代码之外。
- **输入法（IME）是安全的。** 在你使用中文、日文或韩文输入法组字期间，以及组字结束后的 50 毫秒内，编辑器快捷键和自动转换都不会触发，因此按 Enter 确认候选词时不会同时拆分段落。撤销和重做仍然有效。用 Enter 确认的韩文音节也会开始新的一行。已提交文本前残留的罗马字会被移除，提交到空表格单元格中的字符会按输入保留。信息类提示会等到组字结束后再显示；错误和警告会立即显示。AI 客户端通过 MCP 发来的编辑会被拒绝（由客户端重试）或暂缓到组字结束，磁盘上文件的改动也会等待，因此都不会覆盖你仍在组字的文本。
- **尊重减少动态效果设置。** 当操作系统的*减少动态效果*辅助功能设置开启时，VMark 会关闭其动画和过渡效果，并改为即时滚动而非平滑滚动（包括打字机模式）。VMark 中没有单独的设置。系统的*降低透明度*设置同样会关闭背景模糊。

## 视图与专注

### 专注模式（`F8`）

专注模式会淡化除当前编辑块之外的所有块，减少视觉干扰，让你专注于单个段落。当前活动块以全不透明度高亮显示，周围内容淡化为低调颜色。使用 `F8` 切换——在所见即所得和源码模式下均有效，直至你再次切换。

### 打字机模式（`F9`）

打字机模式将活动行保持在视口垂直居中位置，让你的眼睛固定在一个位置，文档在下方滚动——就像在实体打字机上打字一样。使用 `F9` 切换。在两种编辑模式下均有效，使用平滑滚动，小偏移量时不会产生抖动。

### 专注模式 + 打字机模式组合

专注模式和打字机模式可以同时启用。两者结合提供完全无干扰的写作环境：周围块淡化*同时*当前行保持在屏幕中央。

### 自动换行（`Alt + Z`）

使用 `Alt + Z` 切换软折行。启用后，长行在编辑器宽度处折行，而不是水平滚动。此设置跨会话持久保存。

### 只读模式（`F10`）

锁定文档以防止意外编辑。使用 `F10` 切换。启用后，所有键盘输入和格式化命令都被阻止——但仍然可以滚动、选择文本和复制。适合在审阅已完成的文档时使用，或在另一个标签页写作时参考内容。

### 大纲面板（`Ctrl + Shift + 1`）

大纲面板在侧边栏中以可折叠的树形结构显示文档的标题结构。使用 `Ctrl + Shift + 1` 打开。

- 点击任何标题可将编辑器滚动到该部分
- 折叠和展开标题组，聚焦于文档的特定部分
- 滚动或输入时，当前活动标题会高亮显示
- 添加、删除或重命名标题时实时更新
- 较长的标题会折行为两行，悬停时显示完整内容
- 面板顶部的筛选输入框可将树缩小到文本与查询匹配的标题（不区分大小写，并保留上级标题，使路径保持可见）。按 `Esc` 清除。

### 缩放

无需打开设置即可调整编辑器字体大小：

| 操作 | 快捷键 |
|------|--------|
| 放大 | `Mod + =` |
| 缩小 | `Mod + -` |
| 重置为默认值 | `Mod + 0` |

缩放以 2px 为步长更改编辑器字体大小（范围：12px 到 32px）。它修改的是 **设置 > 外观** 中相同的字体大小值，因此键盘缩放和设置滑块始终保持同步。
