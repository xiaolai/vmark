  - `20260721-terminal-input-architecture-audit.md`: root-cause audit of the terminal keyboard/IME input stack, triggered by ~18 duplication fixes in 6 months (58-agent workflow; 59 raw findings, 12 survived adversarial refutation, 34 refuted, 13 unverified — see the caveat appendix). **Root cause: VMark and xterm.js are two independent IME implementations bound to the same DOM node, and VMark registers second (`createTerminalInstance.ts:200` opens xterm before `:203` wires `setupImeComposition`), so it can only arbitrate *after* xterm has already written** — and with two provenance-free PTY write paths, "which of these two identical bytes is the duplicate?" is answerable only by proxies (80 ms grace, 150 ms window, string equality, scheduler position). Each historical fix measured one IME's timing and encoded a new proxy; the next IME refutes it. Confirmed **by execution**: deleting the #619 blanket guard leaves 591/591 tests green, and shrinking `IME_COMPOSITION_GRACE_MS` 16× (80→5) is also green — the subsystem's most consequential guard has zero coverage because no test in the repo instantiates both writers. Recommends **Channel Ownership** (xterm keeps keys, VMark takes the text channel via three verified levers: container-level `stopPropagation` on `input`, `return false` for IME keydowns, synchronous textarea clear on `compositionend`), collapsing to one writer via the public `term.input()`, with an 8-step revertible migration and a trace-replay test tier against a real `Terminal`.
  - `20260718-canon-provenance-staleness-landscape.md`: competitive/prior-art landscape for the four-capability creative-coherence stack (canon store, versioned dependency edges, staleness propagation, LLM consistency checking). Verdict: no surveyed product ships versioned edges or staleness propagation — slot open within the AI-writing/AI-video space; ComfyUI's auto-embedded provenance is the adoption pattern to copy. USD/ShotGrid, Ink & Switch lineage, academic, and agent-memory areas remain unexamined, not cleared.
  - `20260718-versioned-edges-staleness-prior-art.md`: follow-up examining the areas the first pass left open. Eight concrete design lessons; academic + temporal-KG agent-memory areas still unexamined.
  - `20260718-graphiti-agent-memory-academic-priorart.md`: pass 3 (final) — agent memory, academic NL prior art, waiver semantics. Final three-pass verdict: Zep/Graphiti is the closest system in the world (fact-level bi-temporal edges, LLM contradiction detection, episode provenance) but supersession is fully automatic — no human ratification anywhere; academic belief-revision work is weights-level only and names consequence propagation an unsolved open problem.   - `20260718-coherence-layer-conclusion.md`: **synthesis + proposal** over the three passes — the problem formalized (recursive explosion = invisible staleness over a cyclic nondeterministic graph; canon hub linearizes the pairwise blowup), the copy-vs-invent design table (Graphiti's semantic half + the VFX stack's version half; net-new: two-axis staleness, waiver objects, human-ratified supersession), design laws (edge inference not homework, greenhouse mode, zero-effort provenance), and the recommended sequence (identity untouched → dogfood → breakdown view → semantic layer → verticals as format adapters). Direction document, not a plan.
