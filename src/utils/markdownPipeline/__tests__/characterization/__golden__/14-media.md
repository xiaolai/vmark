# Media embeds

Video via image syntax:

![](clip.mp4)

Audio via image syntax:

![](recording.mp3)

Ordinary image for contrast:

![A picture](picture.png)

Explicit video tag with attributes:

<video src="movie.mp4" controls width="640"></video>

Explicit audio tag:

<audio src="podcast.mp3" controls></audio>

Text after the media block.
