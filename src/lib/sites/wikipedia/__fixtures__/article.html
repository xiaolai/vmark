Markdown

This article is about the markup language. For the marketing term, see Markdown (finance).

Markdown is a lightweight markup language for creating formatted text using a plain-text editor.[1] It is widely used for documentation, readme files, and online discussion.

  • 1 History
  • 2 Syntax

Historyedit

Markdown was created in 2004 as a plain-text formatting syntax whose largest design goal was readability. The original implementation shipped as a Perl script.

Syntaxedit

Headings, emphasis, lists, links, and code can all be expressed with ordinary punctuation characters, so a document remains publishable as plain text.
